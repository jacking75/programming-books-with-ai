# 3장. 기본적인 네트워크 프로그래밍

## TCP 연결 다루기
TCP(Transmission Control Protocol)는 신뢰성 있는 데이터 전송을 보장하는 연결 지향적 프로토콜이다.

### TCP 서버 구현
예제 코드: tokio_02

```rust
use tokio::net::{TcpListener, TcpStream};
use tokio::io::{AsyncReadExt, AsyncWriteExt};
use std::error::Error;

#[tokio::main]
async fn main() -> Result<(), Box<dyn Error>> {
    // TCP 서버 생성
    let listener = TcpListener::bind("127.0.0.1:8080").await?;
    println!("서버가 8080 포트에서 실행 중입니다");

    loop {
        // 클라이언트 연결 수락
        let (socket, addr) = listener.accept().await?;
        println!("새로운 클라이언트 연결: {}", addr);

        // 각 클라이언트를 위한 새로운 태스크 생성
        tokio::spawn(async move {
            handle_connection(socket).await
        });
    }
}

async fn handle_connection(mut socket: TcpStream) {
    let mut buffer = [0; 1024];

    loop {
        match socket.read(&mut buffer).await {
            Ok(0) => {
                println!("클라이언트가 연결을 종료했습니다");
                return;
            }
            Ok(n) => {
                // 받은 데이터를 다시 클라이언트로 전송 (에코)
                if let Err(e) = socket.write_all(&buffer[..n]).await {
                    println!("데이터 전송 중 오류 발생: {}", e);
                    return;
                }
            }
            Err(e) => {
                println!("데이터 수신 중 오류 발생: {}", e);
                return;
            }
        }
    }
}
```

### TCP 클라이언트 구현

```rust
use tokio::net::TcpStream;
use tokio::io::{AsyncReadExt, AsyncWriteExt};
use std::error::Error;

#[tokio::main]
async fn main() -> Result<(), Box<dyn Error>> {
    // 서버에 연결
    let mut stream = TcpStream::connect("127.0.0.1:8080").await?;
    println!("서버에 연결되었습니다");

    // 메시지 전송
    let message = b"Hello, Server!";
    stream.write_all(message).await?;
    println!("메시지를 전송했습니다");

    // 응답 수신
    let mut buffer = [0; 1024];
    let n = stream.read(&mut buffer).await?;
    println!("서버로부터 받은 응답: {}", String::from_utf8_lossy(&buffer[..n]));

    Ok(())
}
```
  

## UDP 통신
UDP(User Datagram Protocol)는 비연결형 프로토콜로, 데이터 전송의 신뢰성은 보장되지 않지만 빠른 전송이 가능하다.

### UDP 서버 구현

```rust
use tokio::net::UdpSocket;
use std::error::Error;

#[tokio::main]
async fn main() -> Result<(), Box<dyn Error>> {
    // UDP 소켓 바인딩
    let socket = UdpSocket::bind("127.0.0.1:8080").await?;
    println!("UDP 서버가 8080 포트에서 실행 중입니다");

    let mut buffer = [0; 1024];

    loop {
        // 데이터 수신
        let (len, addr) = socket.recv_from(&mut buffer).await?;
        println!("클라이언트 {}로부터 데이터 수신", addr);

        // 받은 데이터를 다시 전송
        socket.send_to(&buffer[..len], addr).await?;
    }
}
```

### UDP 클라이언트 구현

```rust
use tokio::net::UdpSocket;
use std::error::Error;

#[tokio::main]
async fn main() -> Result<(), Box<dyn Error>> {
    // UDP 소켓 생성
    let socket = UdpSocket::bind("127.0.0.1:0").await?;
    socket.connect("127.0.0.1:8080").await?;

    // 메시지 전송
    let message = b"Hello, UDP Server!";
    socket.send(message).await?;

    // 응답 수신
    let mut buffer = [0; 1024];
    let len = socket.recv(&mut buffer).await?;
    println!("서버로부터 받은 응답: {}", String::from_utf8_lossy(&buffer[..len]));

    Ok(())
}
```
  

## 소켓 프로그래밍 기초

### 소켓 옵션 설정

```rust
use tokio::net::TcpSocket;
use std::error::Error;

#[tokio::main]
async fn main() -> Result<(), Box<dyn Error>> {
    // TCP 소켓 생성
    let socket = TcpSocket::new_v4()?;

    // 소켓 옵션 설정
    socket.set_reuseaddr(true)?;  // 주소 재사용 허용
    socket.set_keepalive(true)?;  // keep-alive 활성화
    socket.set_send_buffer_size(8192)?;  // 송신 버퍼 크기 설정
    socket.set_recv_buffer_size(8192)?;  // 수신 버퍼 크기 설정

    // 소켓 바인딩 및 리스너로 변환
    socket.bind("127.0.0.1:8080".parse()?)?;
    let listener = socket.listen(1024)?;  // 백로그 크기 설정

    println!("서버가 설정되었습니다");
    Ok(())
}
```
  

## 에러 처리

### 커스텀 에러 타입 정의

```rust
use std::error::Error;
use std::fmt;

#[derive(Debug)]
enum NetworkError {
    ConnectionFailed(String),
    TimeoutError(String),
    IoError(std::io::Error),
}

impl fmt::Display for NetworkError {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        match self {
            NetworkError::ConnectionFailed(msg) => write!(f, "연결 실패: {}", msg),
            NetworkError::TimeoutError(msg) => write!(f, "타임아웃: {}", msg),
            NetworkError::IoError(e) => write!(f, "IO 에러: {}", e),
        }
    }
}

impl Error for NetworkError {}

// 에러 처리를 포함한 TCP 클라이언트 예제
async fn connect_with_error_handling(addr: &str) -> Result<TcpStream, NetworkError> {
    TcpStream::connect(addr)
        .await
        .map_err(|e| NetworkError::ConnectionFailed(e.to_string()))
}
```
  

## 타임아웃 처리

### tokio::time을 사용한 타임아웃 구현

```rust
use tokio::time::{timeout, Duration};
use tokio::net::TcpStream;
use std::error::Error;

#[tokio::main]
async fn main() -> Result<(), Box<dyn Error>> {
    // 3초 타임아웃으로 연결 시도
    match timeout(Duration::from_secs(3), connect_to_server()).await {
        Ok(Ok(_)) => println!("연결 성공!"),
        Ok(Err(e)) => println!("연결 실패: {}", e),
        Err(_) => println!("연결 타임아웃"),
    }

    Ok(())
}

async fn connect_to_server() -> Result<TcpStream, Box<dyn Error>> {
    let stream = TcpStream::connect("127.0.0.1:8080").await?;
    Ok(stream)
}
```

### 고급 타임아웃 패턴

```rust
use tokio::time::{timeout, sleep, Duration};
use tokio::net::TcpStream;
use std::error::Error;

#[tokio::main]
async fn main() -> Result<(), Box<dyn Error>> {
    // 재시도 로직이 포함된 연결 시도
    let mut retries = 3;
    let mut delay = Duration::from_secs(1);

    while retries > 0 {
        match timeout(Duration::from_secs(3), TcpStream::connect("127.0.0.1:8080")).await {
            Ok(Ok(stream)) => {
                println!("연결 성공!");
                return Ok(());
            }
            Ok(Err(e)) => {
                println!("연결 실패: {}", e);
            }
            Err(_) => {
                println!("연결 타임아웃");
            }
        }

        retries -= 1;
        if retries > 0 {
            println!("{}초 후 재시도...", delay.as_secs());
            sleep(delay).await;
            delay *= 2;  // 지수 백오프
        }
    }

    Err("모든 연결 시도 실패".into())
}
```

### 실전 예제: 완전한 TCP 서버

```rust
use tokio::net::{TcpListener, TcpStream};
use tokio::io::{AsyncReadExt, AsyncWriteExt};
use tokio::time::{timeout, Duration};
use std::error::Error;
use std::sync::Arc;

#[tokio::main]
async fn main() -> Result<(), Box<dyn Error>> {
    let listener = TcpListener::bind("127.0.0.1:8080").await?;
    println!("서버가 8080 포트에서 실행 중입니다");

    // 공유 상태를 위한 Arc 사용
    let connections = Arc::new(tokio::sync::Mutex::new(0));

    loop {
        let (socket, addr) = listener.accept().await?;
        let connections = Arc::clone(&connections);

        tokio::spawn(async move {
            // 연결 수 증가
            {
                let mut count = connections.lock().await;
                *count += 1;
                println!("현재 연결 수: {}", *count);
            }

            if let Err(e) = handle_connection_with_timeout(socket).await {
                println!("클라이언트 {} 처리 중 오류: {}", addr, e);
            }

            // 연결 수 감소
            let mut count = connections.lock().await;
            *count -= 1;
        });
    }
}

async fn handle_connection_with_timeout(mut socket: TcpStream) -> Result<(), Box<dyn Error>> {
    socket.set_nodelay(true)?;  // Nagle 알고리즘 비활성화

    let mut buffer = [0; 1024];

    loop {
        // 5초 타임아웃으로 데이터 읽기
        match timeout(Duration::from_secs(5), socket.read(&mut buffer)).await {
            Ok(Ok(0)) => {
                println!("클라이언트가 연결을 종료했습니다");
                return Ok(());
            }
            Ok(Ok(n)) => {
                // 데이터 처리
                let response = process_data(&buffer[..n]);

                // 3초 타임아웃으로 응답 전송
                match timeout(Duration::from_secs(3), socket.write_all(&response)).await {
                    Ok(Ok(_)) => println!("응답을 전송했습니다"),
                    Ok(Err(e)) => return Err(Box::new(e)),
                    Err(_) => return Err("응답 전송 타임아웃".into()),
                }
            }
            Ok(Err(e)) => return Err(Box::new(e)),
            Err(_) => return Err("데이터 수신 타임아웃".into()),
        }
    }
}

fn process_data(data: &[u8]) -> Vec<u8> {
    // 데이터 처리 로직
    data.to_vec()
}
```

코드 설명을 한다.

공유 상태 설정:

```rust
let connections = Arc::new(tokio::sync::Mutex::new(0));
```

- `Arc`: Atomic Reference Counting의 약자로, 스레드 간 안전한 공유를 위한 스마트 포인터
- `tokio::sync::Mutex`: 비동기 컨텍스트에서 사용하는 뮤텍스
- `new(0)`: 초기 연결 수를 0으로 설정

연결 수락 루프:

```rust
loop {
    let (socket, addr) = listener.accept().await?;
    let connections = Arc::clone(&connections);

    tokio::spawn(async move { ... });
}
```

- `listener.accept()`: 새로운 클라이언트 연결을 기다림
- `Arc::clone`: 공유 상태의 참조 카운트를 증가
- `tokio::spawn`: 새로운 비동기 태스크를 생성

연결 처리:

```rust
tokio::spawn(async move {
    {
        let mut count = connections.lock().await;
        *count += 1;
        println!("현재 연결 수: {}", *count);
    }

    if let Err(e) = handle_connection_with_timeout(socket).await {
        println!("클라이언트 {} 처리 중 오류: {}", addr, e);
    }

    let mut count = connections.lock().await;
    *count -= 1;
});
```

연결 수 관리는 다음과 같다.

- `connections.lock().await`: 뮤텍스 잠금 획득
- `*count += 1`: 연결 수 증가
- 스코프 블록 `{}`을 사용하여 lock의 수명을 최소화

#### Arc::clone 과 *count += 1
여기서 `Arc::clone`과 `*count += 1`은 서로 다른 두 가지를 카운팅한다.

1. `Arc::clone(&connections)`
   - Arc의 참조 카운트를 추적 (몇 개의 소유자가 이 데이터를 공유하는지)
   - 코드의 동시성 관리를 위한 것
   - 메모리 관리 목적

2. `*count += 1`
   - 실제 TCP 연결된 클라이언트의 수를 추적
   - 비즈니스 로직을 위한 것
   - 서버 모니터링 목적

예시로 설명한다.

```rust
// 1. 초기 상태
let connections = Arc::new(Mutex::new(0));
// Arc 참조 카운트: 1
// 클라이언트 연결 수: 0

// 2. 첫 번째 클라이언트 연결
let connections_clone = Arc::clone(&connections);
// Arc 참조 카운트: 2 (메모리 관리용)
// 클라이언트 연결 수: 0

{
    let mut count = connections_clone.lock().await;
    *count += 1;
    // Arc 참조 카운트: 여전히 2
    // 클라이언트 연결 수: 1 (비즈니스 로직용)
}

// 3. 두 번째 클라이언트 연결
let connections_clone2 = Arc::clone(&connections);
// Arc 참조 카운트: 3
// 클라이언트 연결 수: 1

{
    let mut count = connections_clone2.lock().await;
    *count += 1;
    // Arc 참조 카운트: 여전히 3
    // 클라이언트 연결 수: 2
}
```

더 구체적인 예시를 들어본다.

```rust
use std::sync::Arc;
use tokio::sync::Mutex;

async fn example() {
    // 서버 상태 초기화
    let server_state = Arc::new(Mutex::new(0));  // 클라이언트 연결 수: 0

    // 클라이언트 1 연결
    let state1 = Arc::clone(&server_state);      // Arc 참조 카운트: 2
    tokio::spawn(async move {
        let mut count = state1.lock().await;
        *count += 1;                             // 클라이언트 연결 수: 1
        println!("클라이언트 연결 수: {}", *count);  // 출력: 1
    });

    // 클라이언트 2 연결
    let state2 = Arc::clone(&server_state);      // Arc 참조 카운트: 3
    tokio::spawn(async move {
        let mut count = state2.lock().await;
        *count += 1;                             // 클라이언트 연결 수: 2
        println!("클라이언트 연결 수: {}", *count);  // 출력: 2
    });

    // 이 시점에서:
    // - Arc 참조 카운트: 3 (원본 1개 + 클라이언트 2개)
    // - 실제 연결된 클라이언트 수: 2
}
```

정리하면 다음과 같다.

- `Arc::clone`은 코드의 동시성을 관리하기 위한 메모리 레벨의 카운팅
- `*count += 1`은 실제 비즈니스 로직을 위한 애플리케이션 레벨의 카운팅

이 두 카운터는 서로 다른 목적을 가지고 있어서 둘 다 필요하다.

1. Arc 참조 카운트: 메모리 누수 방지
2. 클라이언트 연결 카운트: 서버 상태 모니터링

이 장에서는 Tokio를 사용한 네트워크 프로그래밍의 기초를 다루었다. TCP와 UDP 통신의 기본부터 에러 처리와 타임아웃 같은 실전적인 요소들까지 살펴보았다. 이러한 개념들을 잘 이해하고 활용하면 안정적이고 효율적인 네트워크 애플리케이션을 개발할 수 있다.
