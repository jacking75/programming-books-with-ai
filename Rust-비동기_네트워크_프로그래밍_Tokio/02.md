# 2장. Tokio 런타임

## 런타임 아키텍처 이해
Tokio 런타임은 비동기 작업을 실행하고 관리하는 핵심 엔진이다. 초보자가 이해하기 쉽게 런타임을 자동차에 비유해본다.

### 런타임의 주요 구성 요소

1. 리액터 (Reactor)
   - 운전자가 도로 상황을 관찰하는 것처럼 I/O 이벤트를 감지
   - 네트워크 연결, 파일 작업 등의 이벤트를 모니터링
   - epoll(Linux), kqueue(macOS) 등의 시스템 이벤트 통지 메커니즘 사용

2. 실행기 (Executor)
   - 자동차의 엔진처럼 실제 작업을 실행
   - Future들을 실행하고 완료까지 추적
   - 작업 우선순위 관리

```rust
// 기본적인 런타임 생성 예제
use tokio::runtime::Runtime;

fn basic_runtime_example() {
    // 기본 런타임 생성
    let rt = Runtime::new().unwrap();

    // 런타임에서 비동기 작업 실행
    rt.block_on(async {
        println!("Hello from Tokio runtime!");
    });
}
```
  

## 런타임 구성 및 설정
Tokio 런타임은 다양한 방식으로 구성할 수 있다. 마치 자동차를 용도에 맞게 커스터마이징하는 것과 같다.

### 런타임 종류

1. 현재 스레드 런타임 (Current Thread Runtime)

```rust
use tokio::runtime::Builder;

fn current_thread_runtime() {
    // 단일 스레드 런타임 생성
    let rt = Builder::new_current_thread()
        .enable_all()  // 모든 기능 활성화
        .build()
        .unwrap();

    rt.block_on(async {
        println!("단일 스레드에서 실행 중");
    });
}
```

2. 멀티 스레드 런타임 (Multi Thread Runtime)

```rust
use tokio::runtime::Builder;

fn multi_thread_runtime() {
    // 멀티 스레드 런타임 생성
    let rt = Builder::new_multi_thread()
        .worker_threads(4)            // 워커 스레드 수 설정
        .thread_name("my-custom-name")// 스레드 이름 설정
        .thread_stack_size(3 * 1024 * 1024) // 스레드 스택 크기 설정
        .enable_all()                // 모든 기능 활성화
        .build()
        .unwrap();

    rt.block_on(async {
        println!("멀티 스레드에서 실행 중");
    });
}
```

### 매크로를 사용한 간단한 설정

```rust
// 기본 멀티스레드 런타임 사용
#[tokio::main]
async fn main() {
    println!("메인 함수에서 실행 중");
}

// 단일 스레드 런타임 사용
#[tokio::main(flavor = "current_thread")]
async fn main() {
    println!("단일 스레드에서 실행 중");
}
```
  

## 작업 스케줄링
작업 스케줄링은 여러 작업을 효율적으로 관리하고 실행하는 방법이다.

### 기본적인 작업 생성과 실행

```rust
use tokio::time::{sleep, Duration};

#[tokio::main]
async fn main() {
    // spawn을 사용한 새로운 작업 생성
    let task1 = tokio::spawn(async {
        sleep(Duration::from_secs(1)).await;
        println!("Task 1 완료");
        "task1 결과"
    });

    let task2 = tokio::spawn(async {
        sleep(Duration::from_secs(2)).await;
        println!("Task 2 완료");
        "task2 결과"
    });

    // 모든 작업이 완료될 때까지 대기
    let (result1, result2) = tokio::join!(task1, task2);

    println!("결과: {:?}, {:?}", result1, result2);
}
```

### 작업 우선순위와 양보

```rust
use tokio::task;

async fn yielding_task() {
    for i in 0..5 {
        println!("작업 실행 중: {}", i);
        // 다른 작업에게 실행 기회를 양보
        task::yield_now().await;
    }
}
```
  

## 워커 스레드 관리
워커 스레드는 실제 작업을 수행하는 실행 단위이다.

### 워커 스레드 설정 예제

```rust
use tokio::runtime::Builder;
use std::thread;

fn worker_thread_example() {
    let runtime = Builder::new_multi_thread()
        .worker_threads(4)  // 워커 스레드 수 지정
        .on_thread_start(|| {
            println!("새로운 워커 스레드 시작: {:?}", thread::current().id());
        })
        .on_thread_stop(|| {
            println!("워커 스레드 종료: {:?}", thread::current().id());
        })
        .build()
        .unwrap();

    runtime.block_on(async {
        // 여러 작업 실행
        for i in 0..10 {
            tokio::spawn(async move {
                println!("작업 {} 실행 중", i);
            });
        }
    });
}
```

### Builder::new_multi_thread() 사용 예
Tokio의 `Builder::new_multi_thread()`를 사용하는 간단한 예제 코드이다.

```rust
use tokio::runtime::Builder;
use std::time::Duration;
use std::error::Error;

async fn async_task(id: u32) {
    println!("Task {} started", id);
    tokio::time::sleep(Duration::from_secs(1)).await;
    println!("Task {} completed", id);
}

fn main() -> Result<(), Box<dyn Error>> {
    // 멀티스레드 런타임 생성
    let runtime = Builder::new_multi_thread()
        .worker_threads(4)               // 워커 스레드 수 설정
        .thread_name("my-custom-thread") // 스레드 이름 설정
        .thread_stack_size(3 * 1024 * 1024) // 스택 크기 설정 (3MB)
        .enable_all()                    // 모든 기능 활성화
        .build()?;

    // 런타임에서 비동기 작업 실행
    runtime.block_on(async {
        let mut handles = vec![];

        // 여러 태스크 생성
        for i in 0..10 {
            let handle = tokio::spawn(async move {
                async_task(i).await;
            });
            handles.push(handle);
        }

        // 모든 태스크 완료 대기
        for handle in handles {
            handle.await?;
        }

        Ok::<_, Box<dyn Error>>(())
    })?;

    Ok(())
}
```

좀 더 실용적인 예제로, 네트워크 요청을 처리하는 서버를 만들어본다.

```rust
use tokio::runtime::Builder;
use tokio::net::{TcpListener, TcpStream};
use tokio::io::{AsyncReadExt, AsyncWriteExt};
use std::error::Error;

async fn handle_connection(mut socket: TcpStream) {
    let mut buffer = [0; 1024];

    while let Ok(n) = socket.read(&mut buffer).await {
        if n == 0 {
            break;
        }

        // 에코 서버: 받은 데이터를 다시 전송
        if let Err(e) = socket.write_all(&buffer[0..n]).await {
            eprintln!("Failed to write to socket: {}", e);
            break;
        }
    }
}

fn main() -> Result<(), Box<dyn Error>> {
    // 커스텀 런타임 생성
    let runtime = Builder::new_multi_thread()
        .worker_threads(4)
        .enable_all()
        .build()?;

    // 서버 실행
    runtime.block_on(async {
        let listener = TcpListener::bind("127.0.0.1:8080").await?;
        println!("Server listening on port 8080");

        loop {
            match listener.accept().await {
                Ok((socket, addr)) => {
                    println!("New connection from: {}", addr);

                    // 각 연결을 새로운 태스크로 처리
                    tokio::spawn(async move {
                        handle_connection(socket).await;
                    });
                }
                Err(e) => {
                    eprintln!("Failed to accept connection: {}", e);
                }
            }
        }
    })
}
```

CPU 집중 작업과 I/O 작업을 함께 처리하는 예제이다.

```rust
use tokio::runtime::Builder;
use std::time::Duration;
use std::error::Error;

// CPU 집중 작업 시뮬레이션
fn cpu_intensive_task(n: u64) -> u64 {
    let mut result = 0;
    for i in 0..n {
        result = result.wrapping_add(i);
    }
    result
}

// I/O 작업 시뮬레이션
async fn io_task(id: u32) {
    println!("I/O task {} started", id);
    tokio::time::sleep(Duration::from_secs(1)).await;
    println!("I/O task {} completed", id);
}

fn main() -> Result<(), Box<dyn Error>> {
    // 커스텀 런타임 생성
    let runtime = Builder::new_multi_thread()
        .worker_threads(4)
        .enable_all()
        .build()?;

    runtime.block_on(async {
        let mut handles = vec![];

        // CPU 집중 작업 실행
        for i in 0..3 {
            let handle = tokio::task::spawn_blocking(move || {
                println!("CPU task {} started", i);
                let result = cpu_intensive_task(1_000_000_000);
                println!("CPU task {} completed with result {}", i, result);
            });
            handles.push(handle);
        }

        // I/O 작업 실행
        for i in 0..5 {
            let handle = tokio::spawn(io_task(i));
            handles.push(handle);
        }

        // 모든 작업 완료 대기
        for handle in handles {
            handle.await?;
        }

        Ok::<_, Box<dyn Error>>(())
    })?;

    Ok(())
}
```

이러한 예제들에서 `Builder::new_multi_thread()`의 주요 장점은 다음과 같다.

1. 워커 스레드 수 커스터마이징
2. 스레드 이름 및 스택 크기 설정
3. 동시성 작업의 효율적인 처리
4. CPU 집중 작업과 I/O 작업의 적절한 분배

사용시 주의사항은 다음과 같다.

1. 워커 스레드 수는 시스템의 CPU 코어 수를 고려하여 설정
2. 메모리 사용량과 스택 크기의 균형을 고려
3. 에러 처리와 리소스 정리를 적절히 구현
  

## 리소스 드라이버의 이해
리소스 드라이버는 시스템 리소스(네트워크, 파일 시스템 등)와의 상호작용을 관리한다.

### 주요 드라이버 종류

1. I/O 드라이버

```rust
use tokio::fs::File;
use tokio::io::AsyncReadExt;

async fn read_file_example() -> std::io::Result<()> {
    // 파일 비동기 읽기
    let mut file = File::open("example.txt").await?;
    let mut contents = String::new();
    file.read_to_string(&mut contents).await?;

    println!("파일 내용: {}", contents);
    Ok(())
}
```

2. 시간 드라이버

```rust
use tokio::time::{sleep, Duration};

async fn timer_example() {
    println!("시작");
    sleep(Duration::from_secs(2)).await;
    println!("2초 후");
}
```

3. 네트워크 드라이버

```rust
use tokio::net::TcpListener;
use tokio::io::AsyncWriteExt;

async fn network_example() -> std::io::Result<()> {
    let listener = TcpListener::bind("127.0.0.1:8080").await?;

    loop {
        let (mut socket, _) = listener.accept().await?;

        tokio::spawn(async move {
            socket.write_all(b"Hello from Tokio!").await.unwrap();
        });
    }
}
```

### 실제 사용 예제: 통합 애플리케이션

```rust
use tokio::time::{sleep, Duration};
use tokio::fs::File;
use tokio::io::AsyncWriteExt;

#[tokio::main]
async fn main() -> std::io::Result<()> {
    // 파일 작업
    let mut file = File::create("log.txt").await?;

    // 여러 작업 동시 실행
    for i in 0..3 {
        let file_clone = file.try_clone().await?;

        tokio::spawn(async move {
            // 시간 지연
            sleep(Duration::from_secs(i as u64)).await;

            // 파일에 로그 작성
            let log = format!("작업 {} 완료\n", i);
            let mut file = file_clone;
            file.write_all(log.as_bytes()).await.unwrap();
        });
    }

    // 모든 작업이 완료될 때까지 대기
    sleep(Duration::from_secs(3)).await;

    Ok(())
}
```

이러한 예제들을 통해 Tokio 런타임의 기본 개념과 사용법을 이해할 수 있다. 런타임은 복잡해 보일 수 있지만, 각 구성 요소가 명확한 역할을 가지고 있으며, 이들이 조화롭게 작동하여 효율적인 비동기 프로그래밍을 가능하게 한다.
