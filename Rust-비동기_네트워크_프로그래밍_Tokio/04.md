# 4장. 비동기 스트림과 싱크

## Stream 트레이트 이해
Stream은 비동기적으로 일련의 값을 생성하는 트레이트이다. Iterator와 유사하지만 비동기 컨텍스트에서 동작한다.

### Stream 기본 구현

```rust
use futures::Stream;
use std::pin::Pin;
use std::task::{Context, Poll};
use tokio::time::{self, Duration};

// 기본적인 스트림 구현
struct CountStream {
    count: u32,
    max: u32,
    interval: Duration,
}

impl CountStream {
    fn new(max: u32, interval: Duration) -> Self {
        CountStream {
            count: 0,
            max,
            interval,
        }
    }
}

impl Stream for CountStream {
    type Item = u32;

    fn poll_next(mut self: Pin<&mut Self>, cx: &mut Context<'_>) -> Poll<Option<Self::Item>> {
        if self.count >= self.max {
            return Poll::Ready(None);
        }
        self.count += 1;
        Poll::Ready(Some(self.count))
    }
}

// 스트림 사용 예제
#[tokio::main]
async fn main() {
    use futures::StreamExt;
    let mut stream = CountStream::new(5, Duration::from_secs(1));

    while let Some(num) = stream.next().await {
        println!("값: {}", num);
        time::sleep(Duration::from_secs(1)).await;
    }
}
```

**1. 의존성 및 임포트**

```rust
use futures::Stream;
use std::pin::Pin;
use std::task::{Context, Poll};
use tokio::time::{self, Duration};
```

- `Stream`: 비동기 데이터 스트림을 위한 트레이트
- `Pin`: 메모리 위치가 고정된 타입을 위한 래퍼
- `Context`, `Poll`: 비동기 작업의 상태 관리
- `Duration`: 시간 간격을 표현하는 타입

**2. 스트림 구조체 정의**

```rust
struct CountStream {
    count: u32,    // 현재 카운트
    max: u32,      // 최대 카운트
    interval: Duration,  // 간격
}

impl CountStream {
    fn new(max: u32, interval: Duration) -> Self {
        CountStream {
            count: 0,
            max,
            interval,
        }
    }
}
```

- 간단한 카운터 스트림 구현
- `new` 생성자로 최대값과 간격 설정
- 내부 상태로 현재 카운트 유지

**3. Stream 트레이트 구현**

```rust
impl Stream for CountStream {
    type Item = u32;  // 스트림이 생성하는 아이템의 타입

    fn poll_next(mut self: Pin<&mut Self>, cx: &mut Context<'_>) -> Poll<Option<Self::Item>> {
        if self.count >= self.max {
            return Poll::Ready(None);  // 스트림 종료
        }
        self.count += 1;
        Poll::Ready(Some(self.count))  // 다음 값 반환
    }
}
```

**poll_next 메서드의 동작**

1. `Pin<&mut Self>`: 자기 참조 구조체를 안전하게 다루기 위한 타입
2. `Context`: 비동기 실행 컨텍스트 제공
3. 반환값:
   - `Poll::Ready(Some(value))`: 새 값이 준비됨
   - `Poll::Ready(None)`: 스트림 종료
   - `Poll::Pending`: 아직 값이 준비되지 않음

**4. 메인 함수**

```rust
#[tokio::main]
async fn main() {
    use futures::StreamExt;  // 스트림 확장 트레이트
    let mut stream = CountStream::new(5, Duration::from_secs(1));

    while let Some(num) = stream.next().await {
        println!("값: {}", num);
        time::sleep(Duration::from_secs(1)).await;
    }
}
```

**주요 특징**

- `#[tokio::main]`: 비동기 런타임 설정
- `StreamExt`: 스트림에 대한 추가 메서드 제공
- `stream.next().await`: 스트림의 다음 값을 비동기적으로 가져옴
- `time::sleep`: 각 값 사이에 1초 대기

**5. 실행 예시**

```
// 실행 결과
값: 1
값: 2
값: 3
값: 4
값: 5
// 프로그램 종료
```

### 스트림 처리 메서드

```rust
use futures::{Stream, StreamExt};
use tokio::time::{interval, Duration};

#[tokio::main]
async fn main() {
    // 인터벌 스트림 생성
    let mut interval_stream = interval(Duration::from_secs(1))
        .map(|_| Ok::<_, std::io::Error>(1))  // 값을 변환
        .take(5);  // 처음 5개 항목만 사용

    // filter와 map 사용
    let mut processed_stream = interval_stream
        .filter(|r| futures::future::ready(r.is_ok()))  // 성공한 결과만 필터링
        .map(|r| r.unwrap() * 2);  // 값을 2배로 증가

    while let Some(value) = processed_stream.next().await {
        println!("처리된 값: {}", value);
    }
}
```
  

## Sink 트레이트 활용
Sink는 비동기적으로 값을 소비하는 트레이트이다. 주로 데이터를 쓰거나 전송하는 데 사용된다.

### 기본 Sink 구현

```rust
use futures::Sink;
use std::pin::Pin;
use std::task::{Context, Poll};

struct NumberSink {
    values: Vec<i32>,
}

impl NumberSink {
    fn new() -> Self {
        NumberSink { values: Vec::new() }
    }
}

impl Sink<i32> for NumberSink {
    type Error = std::io::Error;

    fn poll_ready(self: Pin<&mut Self>, _cx: &mut Context<'_>) -> Poll<Result<(), Self::Error>> {
        Poll::Ready(Ok(()))
    }

    fn start_send(mut self: Pin<&mut Self>, item: i32) -> Result<(), Self::Error> {
        self.values.push(item);
        Ok(())
    }

    fn poll_flush(self: Pin<&mut Self>, _cx: &mut Context<'_>) -> Poll<Result<(), Self::Error>> {
        Poll::Ready(Ok(()))
    }

    fn poll_close(self: Pin<&mut Self>, _cx: &mut Context<'_>) -> Poll<Result<(), Self::Error>> {
        Poll::Ready(Ok(()))
    }
}
```

### Sink 사용 예제

```rust
use futures::SinkExt;

#[tokio::main]
async fn main() -> Result<(), std::io::Error> {
    let mut sink = NumberSink::new();

    // 값 전송
    sink.send(1).await?;
    sink.send(2).await?;
    sink.send(3).await?;

    // 싱크 닫기
    sink.close().await?;

    println!("저장된 값들: {:?}", sink.values);
    Ok(())
}
```
 

## 스트림 변환과 조작

### 스트림 변환 유틸리티

```rust
use futures::{Stream, StreamExt};
use std::time::Duration;
use tokio::time::interval;

#[tokio::main]
async fn main() {
    // 기본 스트림 생성
    let base_stream = interval(Duration::from_secs(1))
        .map(|_| 1)
        .take(10);

    // 청크로 나누기
    let chunked = base_stream.chunks(3);

    // 윈도우 적용
    let windowed = base_stream.windows(3);

    // 버퍼링
    let buffered = base_stream.buffer_unordered(3);

    // 스트림 연결
    let combined = base_stream.chain(base_stream);
}
```

### 스트림 에러 처리

```rust
use futures::{Stream, StreamExt};
use std::io;

async fn process_stream<S>(stream: S)
where
    S: Stream<Item = Result<i32, io::Error>>
{
    let processed = stream
        .map_err(|e| eprintln!("에러 발생: {}", e))  // 에러 처리
        .filter_map(|r| async move {  // 성공한 값만 처리
            match r {
                Ok(val) => Some(val * 2),
                Err(_) => None,
            }
        });

    tokio::pin!(processed);

    while let Some(value) = processed.next().await {
        println!("처리된 값: {}", value);
    }
}
```
  

## 백프레셔 처리
백프레셔는 데이터 생산자가 소비자의 처리 능력을 초과하지 않도록 제어하는 메커니즘이다.

### 백프레셔 구현 예제

```rust
use futures::{Stream, StreamExt};
use tokio::sync::mpsc;
use std::time::Duration;
use tokio::time::sleep;

#[tokio::main]
async fn main() {
    // 제한된 채널 크기로 백프레셔 구현
    let (tx, rx) = mpsc::channel::<i32>(5);  // 버퍼 크기 5로 제한

    // 생산자 태스크
    tokio::spawn(async move {
        for i in 0..20 {
            // 채널이 가득 차면 자동으로 백프레셔 적용
            if let Err(e) = tx.send(i).await {
                eprintln!("전송 실패: {}", e);
                break;
            }
            println!("전송됨: {}", i);
        }
    });

    // 소비자
    let mut rx_stream = tokio_stream::wrappers::ReceiverStream::new(rx);

    while let Some(value) = rx_stream.next().await {
        println!("수신됨: {}", value);
        // 처리 시간 시뮬레이션
        sleep(Duration::from_millis(500)).await;
    }
}
```
  

## 스트림 결합과 분할

### 스트림 결합

```rust
use futures::{Stream, StreamExt};
use tokio::time::{interval, Duration};

#[tokio::main]
async fn main() {
    // 두 개의 스트림 생성
    let stream1 = interval(Duration::from_secs(1))
        .map(|_| "스트림 1")
        .take(5);

    let stream2 = interval(Duration::from_secs(2))
        .map(|_| "스트림 2")
        .take(3);

    // zip으로 스트림 결합
    let mut zipped = stream1.zip(stream2);

    while let Some((s1, s2)) = zipped.next().await {
        println!("결합된 값: {} - {}", s1, s2);
    }

    // merge로 스트림 결합
    use futures::stream::select;
    let merged = select(stream1, stream2);
    tokio::pin!(merged);

    while let Some(value) = merged.next().await {
        println!("병합된 값: {}", value);
    }
}
```

### 스트림 분할

```rust
use futures::{Stream, StreamExt};
use tokio::sync::mpsc;

// 스트림을 두 개의 채널로 분할하는 함수
async fn split_stream<S, T>(mut stream: S) -> (mpsc::Receiver<T>, mpsc::Receiver<T>)
where
    S: Stream<Item = T> + Unpin,
    T: Clone + Send + 'static,
{
    let (tx1, rx1) = mpsc::channel(10);
    let (tx2, rx2) = mpsc::channel(10);

    tokio::spawn(async move {
        while let Some(item) = stream.next().await {
            // 두 채널로 데이터 복사
            let _ = tx1.send(item.clone()).await;
            let _ = tx2.send(item).await;
        }
    });

    (rx1, rx2)
}

#[tokio::main]
async fn main() {
    // 테스트 스트림 생성
    let stream = futures::stream::iter(1..=5);

    // 스트림 분할
    let (mut rx1, mut rx2) = split_stream(stream).await;

    // 분할된 스트림 처리
    tokio::spawn(async move {
        while let Some(value) = rx1.recv().await {
            println!("스트림 1 수신: {}", value);
        }
    });

    while let Some(value) = rx2.recv().await {
        println!("스트림 2 수신: {}", value);
    }
}
```

### 실전 예제: 복잡한 스트림 처리

```rust
use futures::{Stream, StreamExt};
use tokio::time::{interval, Duration};
use std::error::Error;

// 복잡한 데이터 처리 파이프라인 예제
#[tokio::main]
async fn main() -> Result<(), Box<dyn Error>> {
    // 데이터 소스 스트림
    let source = interval(Duration::from_millis(100))
        .map(|_| Ok::<_, std::io::Error>(rand::random::<u32>()))
        .take(20);

    // 처리 파이프라인 구성
    let processed = source
        // 짝수만 필터링
        .filter(|r| futures::future::ready(match r {
            Ok(n) => n % 2 == 0,
            Err(_) => false,
        }))
        // 값을 변환
        .map(|r| r.map(|n| n * 2))
        // 청크로 그룹화
        .chunks(3)
        // 각 청크의 평균 계산
        .map(|chunk| {
            let sum: u32 = chunk.into_iter()
                .filter_map(|r| r.ok())
                .sum();
            let count = chunk.len() as u32;
            sum / count
        });

    tokio::pin!(processed);

    // 결과 처리
    while let Some(avg) = processed.next().await {
        println!("청크 평균: {}", avg);
    }

    Ok(())
}
```

이 장에서는 Rust의 비동기 스트림과 싱크의 기본 개념부터 고급 사용법까지 다루었다. Stream과 Sink 트레이트의 구현 방법, 스트림 변환과 조작, 백프레셔 처리, 그리고 스트림의 결합과 분할에 대해 학습했다. 이러한 개념들은 비동기 데이터 처리 파이프라인을 구축하는 데 필수적인 도구가 된다.

이 내용들을 잘 이해하고 활용하면, 효율적이고 안정적인 비동기 데이터 처리 시스템을 구축할 수 있다. 특히 백프레셔 처리는 실제 프로덕션 환경에서 시스템의 안정성을 보장하는 중요한 요소가 된다.
