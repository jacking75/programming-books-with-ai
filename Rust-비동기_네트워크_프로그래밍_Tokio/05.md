# 5장. 프로토콜 구현

## 프로토콜 설계 원칙
프로토콜 설계는 네트워크 통신의 기초가 되는 중요한 부분이다. 좋은 프로토콜은 다음과 같은 원칙을 따른다.  

### 기본 설계 원칙

```rust
// 프로토콜 메시지 기본 구조
#[derive(Debug, Clone, Serialize, Deserialize)]
struct ProtocolMessage {
    version: u8,           // 프로토콜 버전
    message_type: u8,      // 메시지 타입
    payload_length: u32,   // 페이로드 길이
    payload: Vec<u8>,      // 실제 데이터
    checksum: u32,         // 체크섬
}

impl ProtocolMessage {
    fn new(message_type: u8, payload: Vec<u8>) -> Self {
        let payload_length = payload.len() as u32;
        let checksum = Self::calculate_checksum(&payload);

        ProtocolMessage {
            version: 1,
            message_type,
            payload_length,
            payload,
            checksum,
        }
    }

    fn calculate_checksum(data: &[u8]) -> u32 {
        // CRC32 체크섬 계산 예시
        let mut hasher = crc32fast::Hasher::new();
        hasher.update(data);
        hasher.finalize()
    }
}
```

### 에러 처리 구현

```rust
#[derive(Debug)]
enum ProtocolError {
    InvalidVersion,
    InvalidChecksum,
    InvalidLength,
    InvalidMessageType,
    SerializationError(String),
    IOError(std::io::Error),
}

impl From<std::io::Error> for ProtocolError {
    fn from(err: std::io::Error) -> Self {
        ProtocolError::IOError(err)
    }
}

type ProtocolResult<T> = Result<T, ProtocolError>;
```
  

## 커스텀 프로토콜 구현

### 기본 프로토콜 정의

```rust
use tokio::net::{TcpStream, TcpListener};
use tokio::io::{AsyncReadExt, AsyncWriteExt};
use serde::{Serialize, Deserialize};

// 프로토콜 메시지 타입 정의
#[derive(Debug, Serialize, Deserialize)]
enum MessageType {
    Hello = 1,
    Data = 2,
    Ping = 3,
    Pong = 4,
    Goodbye = 5,
}

// 실제 메시지 구조체
#[derive(Debug, Serialize, Deserialize)]
struct Message {
    msg_type: MessageType,
    content: String,
}

// 프로토콜 핸들러
struct ProtocolHandler {
    stream: TcpStream,
}

impl ProtocolHandler {
    async fn handle_message(&mut self, message: Message) -> ProtocolResult<()> {
        match message.msg_type {
            MessageType::Hello => {
                println!("Received Hello: {}", message.content);
                // 응답 처리
            },
            MessageType::Ping => {
                // Pong으로 응답
                let response = Message {
                    msg_type: MessageType::Pong,
                    content: "Pong".to_string(),
                };
                self.send_message(response).await?;
            },
            // 기타 메시지 타입 처리
            _ => println!("Unhandled message type"),
        }
        Ok(())
    }

    async fn send_message(&mut self, message: Message) -> ProtocolResult<()> {
        // 메시지 직렬화 및 전송
        let serialized = serde_json::to_string(&message)
            .map_err(|e| ProtocolError::SerializationError(e.to_string()))?;

        self.stream.write_all(serialized.as_bytes()).await?;
        Ok(())
    }
}
```
  

## 프레임 인코딩/디코딩

### 프레임 구조 정의

```rust
use bytes::{BytesMut, Buf, BufMut};

struct Frame {
    header: FrameHeader,
    payload: Vec<u8>,
}

#[derive(Debug)]
struct FrameHeader {
    version: u8,
    flags: u8,
    length: u32,
}

impl Frame {
    fn encode(&self) -> BytesMut {
        let mut buf = BytesMut::with_capacity(5 + self.payload.len());

        // 헤더 인코딩
        buf.put_u8(self.header.version);
        buf.put_u8(self.header.flags);
        buf.put_u32(self.header.length);

        // 페이로드 추가
        buf.extend_from_slice(&self.payload);

        buf
    }

    fn decode(mut buf: BytesMut) -> Option<Frame> {
        if buf.len() < 5 {  // 최소 헤더 크기
            return None;
        }

        let version = buf.get_u8();
        let flags = buf.get_u8();
        let length = buf.get_u32();

        if buf.len() < length as usize {
            return None;
        }

        let payload = buf.split_to(length as usize).to_vec();

        Some(Frame {
            header: FrameHeader {
                version,
                flags,
                length,
            },
            payload,
        })
    }
}
```

### 프레임 코덱 구현

```rust
use tokio_util::codec::{Decoder, Encoder};

struct FrameCodec;

impl Decoder for FrameCodec {
    type Item = Frame;
    type Error = ProtocolError;

    fn decode(&mut self, src: &mut BytesMut) -> Result<Option<Self::Item>, Self::Error> {
        if let Some(frame) = Frame::decode(src.split()) {
            Ok(Some(frame))
        } else {
            Ok(None)
        }
    }
}

impl Encoder<Frame> for FrameCodec {
    type Error = ProtocolError;

    fn encode(&mut self, item: Frame, dst: &mut BytesMut) -> Result<(), Self::Error> {
        dst.extend_from_slice(&item.encode());
        Ok(())
    }
}
```
  

## 메시지 직렬화/역직렬화

### JSON 기반 직렬화

```rust
use serde_json::{Value, json};

#[derive(Debug, Serialize, Deserialize)]
struct CustomMessage {
    id: u64,
    command: String,
    parameters: Value,
}

impl CustomMessage {
    fn serialize(&self) -> ProtocolResult<Vec<u8>> {
        serde_json::to_vec(self)
            .map_err(|e| ProtocolError::SerializationError(e.to_string()))
    }

    fn deserialize(data: &[u8]) -> ProtocolResult<Self> {
        serde_json::from_slice(data)
            .map_err(|e| ProtocolError::SerializationError(e.to_string()))
    }
}

// 사용 예제
async fn handle_message(data: &[u8]) -> ProtocolResult<()> {
    let message = CustomMessage::deserialize(data)?;

    match message.command.as_str() {
        "get_user" => {
            let response = CustomMessage {
                id: message.id,
                command: "user_data".to_string(),
                parameters: json!({
                    "name": "John Doe",
                    "age": 30
                }),
            };
            // 응답 처리
        },
        _ => println!("Unknown command"),
    }

    Ok(())
}
```

### 바이너리 직렬화

```rust
use bincode::{serialize, deserialize};

#[derive(Debug, Serialize, Deserialize)]
struct BinaryMessage {
    message_type: u8,
    data: Vec<u8>,
}

impl BinaryMessage {
    fn to_bytes(&self) -> ProtocolResult<Vec<u8>> {
        serialize(self)
            .map_err(|e| ProtocolError::SerializationError(e.to_string()))
    }

    fn from_bytes(bytes: &[u8]) -> ProtocolResult<Self> {
        deserialize(bytes)
            .map_err(|e| ProtocolError::SerializationError(e.to_string()))
    }
}
```

이 장에서는 프로토콜 구현의 핵심 개념과 실제 구현 방법에 대해 다루었다. 프로토콜 설계 원칙부터 시작하여, 커스텀 프로토콜 구현, 프레임 처리, 메시지 직렬화/역직렬화, 그리고 버전 관리까지 전반적인 내용을 다루었다.

프로토콜 구현 시 주의해야 할 핵심 사항은 다음과 같다.

1. 명확한 메시지 구조 정의
2. 적절한 에러 처리
3. 효율적인 직렬화/역직렬화
4. 버전 호환성 유지
5. 보안 고려사항 적용

이러한 개념들을 잘 이해하고 적용하면, 안정적이고 확장 가능한 네트워크 프로토콜을 구현할 수 있다.
