# 신입 게임 프로그래머를 위한 가챠 확률 구현 실전 가이드

저자: 최흥배, AI-Assisted 


## 이 책이 다루는 것
수집형 RPG와 MMORPG에서 가챠(Gacha) 확률을 어떻게 구현하는지, 신입 프로그래머도 바로 따라 할 수 있도록 코드 중심으로 설명하는 책이다.

## 기술 스택

- **언어**: C# (.NET 10)
- **RDB**: MySQL + SqlKata (Query Builder)
- **Cache**: Redis + CloudStructures
- **테스트**: xUnit, FluentAssertions
- **시뮬레이션**: 콘솔 / 유닛 테스트 기반

## 이 책의 특징

기존 가챠 책과는 달리 **사례 → 그림 → 실습** 순서로 구성한다. 모든 장에 [실습] 섹션이 있고, 사고 사례는 관련 장에 분산해서 넣었다. 이론은 필요한 만큼만 다루고, 실제 게임 서버에 붙일 수 있는 코드를 우선한다.

## 책을 읽는 순서
신입이라면 1부부터 순서대로 읽기를 권한다. 이미 가챠를 한 번이라도 구현해본 경력자라면 2부부터 시작해도 무방하다. 운영 사고를 겪어본 사람이라면 4부의 16장(사고 사례)부터 거꾸로 읽는 것도 좋은 방법이다.

## 사전 준비
C# 11 이상 문법(record, pattern matching, primary constructor)에 익숙하다고 가정한다. MySQL과 Redis가 로컬에 설치되어 있어야 실습이 가능하다. Docker Compose로 한 번에 띄우는 방법은 부록 A에 정리해두었다.
