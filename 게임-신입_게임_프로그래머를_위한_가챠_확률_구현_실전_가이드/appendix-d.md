# 부록 D. 용어집

가나다 순 정렬, 영문 병기, 본문 페이지(장) 참조 포함. 신입이 회의에서 막히지 않도록 50개 핵심 용어를 정리했다.

---

**가챠 (Gacha)** — 일본어 "가챠가챠"에서 유래. 무작위로 아이템을 뽑는 시스템. (3장)

**감사 로그 (Audit Log)** — 모든 추첨 결과를 영구 보관하는 로그. CS·법무 대응에 사용. (10장)

**격리 수준 (Isolation Level)** — DB 트랜잭션의 동시성 제어 수준. MySQL 기본은 REPEATABLE READ. (11장)

**기댓값 (Expected Value)** — 확률 변수의 평균값. p 확률 아이템은 평균 1/p회 시도해야 1번 나옴. (1장, 부록 B)

**낙관적 락 (Optimistic Lock)** — 충돌 거의 없다고 가정하고 진행하다가 commit 시 검증. 가챠에 부적합. (12장)

**누적 확률 (Cumulative Probability)** — 가중치를 누적합으로 변환한 표. 이진 탐색 추첨에 사용. (4장)

**도박사의 오류 (Gambler's Fallacy)** — "직전 결과 때문에 이번엔 다를 것"이라는 잘못된 믿음. (1장)

**드롭 테이블 (Drop Table)** — 몹·보스가 떨어뜨리는 아이템과 확률 표. 가챠와 유사 구조. (4장)

**랜덤 시드 (Random Seed)** — 난수 생성기의 초기값. 같은 시드는 같은 수열 생성. (2장)

**룰렛 휠 (Roulette Wheel)** — 가장 단순한 가중치 추첨 알고리즘. O(N). (4장)

**메모리 변조 (Memory Hack)** — 클라이언트 메모리를 조작해 게임 결과를 바꾸는 행위. (9장)

**멱등성 (Idempotency)** — 같은 요청을 여러 번 보내도 결과가 한 번만 적용되는 성질. (11장)

**모니터링 (Monitoring)** — 운영 중 시스템 상태를 실시간 관찰하는 활동. (15장)

**몬테카를로 시뮬레이션 (Monte Carlo Simulation)** — 무작위 시도를 반복하여 확률을 근사하는 방법. (14장)

**박스 가챠 (Box Gacha)** — 비복원 추첨. 박스 안 아이템이 정해져 있고 뽑을수록 줄어듬. (7장)

**별칭 기법 (Alias Method, Vose's Alias Method)** — O(1)로 가중치 추첨하는 알고리즘. 큰 N에 적합. (4장)

**보장 (Guaranteed)** — 일정 조건 충족 시 특정 결과를 보장하는 시스템. 천장의 일종. (3장, 6장)

**복원 추첨 (With Replacement)** — 매번 같은 풀에서 추첨. 일반 가챠. (7장)

**분산 (Variance)** — 결과가 평균에서 얼마나 흩어지는지의 척도. (부록 B)

**분산락 (Distributed Lock)** — 여러 서버에 걸쳐 동시 접근을 막는 락. Redis로 구현. (12장)

**비관적 락 (Pessimistic Lock)** — 충돌 가능성이 있다고 가정하고 미리 잠그는 락. FOR UPDATE. (12장)

**비복원 추첨 (Without Replacement)** — 뽑힌 아이템이 풀에서 빠지는 추첨. 박스 가챠. (7장)

**서버 권위 (Server Authoritative)** — 게임 결과를 서버가 결정하는 설계. 클라는 표시만. (9장)

**소프트 천장 (Soft Pity)** — 일정 회차부터 확률이 점진 상승하는 천장 시스템. (6장)

**스텝업 가챠 (Step-up Gacha)** — 단계마다 확률·보장이 달라지는 가챠. (8장)

**시뮬레이션 (Simulation)** — 실제 환경 없이 코드로 결과를 미리 보는 것. (1장, 14장)

**시그마 (Sigma, σ)** — 표준편차 기호. 3시그마 범위 밖이면 이상으로 판단. (15장)

**아이템 풀 (Item Pool)** — 추첨 대상이 되는 아이템 집합. 등급별/배너별로 구분. (3장)

**알고리즘 (Algorithm)** — 문제를 해결하는 절차. 가챠는 룰렛/이진/별칭 등의 알고리즘 사용. (4장)

**알람 피로 (Alert Fatigue)** — 너무 많은 알람으로 진짜 사고를 놓치는 현상. (15장)

**연챠 (Multi-pull, e.g. 10-pull)** — 여러 번 한꺼번에 추첨. 보통 보장 시스템과 함께. (3장)

**유의수준 (Significance Level, α)** — 통계 검정에서 귀무가설을 기각할 기준. 0.05 또는 0.01. (14장)

**이항분포 (Binomial Distribution)** — n번 독립 시행에서 k번 성공할 확률 분포. (1장, 부록 B)

**자유도 (Degrees of Freedom, df)** — 카이제곱 검정의 파라미터. 카테고리 수 - 1. (14장)

**천장 (Pity, Ceiling)** — N번 안에 보장되는 시스템. 하드/소프트 두 종류. (6장)

**카나리 배포 (Canary Deployment)** — 일부 유저에게 먼저 배포하여 사고를 조기 발견. (15장)

**카이제곱 (Chi-Squared, χ²)** — 관찰값과 기대값의 차이를 측정하는 통계량. (14장, 부록 B)

**컬렉션 가챠 (Collection / Complete Gacha)** — 정해진 아이템을 모두 모으면 추가 보상. 일본 규제 대상. (8장)

**큰 수의 법칙 (Law of Large Numbers)** — 시행 횟수가 늘수록 관찰값이 이론값에 수렴. (1장)

**클라이언트 추첨 (Client-side RNG)** — 클라이언트에서 추첨하는 방식. 보안상 금지. (9장)

**트랜잭션 (Transaction)** — 여러 DB 작업을 원자적으로 묶는 단위. ACID. (11장)

**파티셔닝 (Partitioning)** — 큰 테이블을 시간/범위 기준으로 나누는 기법. 추첨 이력 보관에 사용. (10장)

**픽업 (Pick-up)** — 특정 캐릭터의 등장 확률을 일시적으로 올리는 시스템. (3장)

**핫 리로드 (Hot Reload)** — 서버 재시작 없이 데이터 변경을 적용하는 것. (10장)

**핫핸드 편향 (Hot Hand Fallacy)** — "운이 좋은 상태"가 계속될 거라는 잘못된 믿음. (1장)

**해시 (Hash)** — 임의 입력을 고정 길이 출력으로 변환. SHA-256 등. 멱등성 키 검증에 사용. (11장)

**확률 변수 (Random Variable)** — 시행 결과로 결정되는 값. 확률 분포를 가짐. (1장)

**확률 공시 (Disclosure)** — 가챠 확률 정보를 유저에게 공개하는 행위. 한국 법규. (13장)

**확률형 아이템 (Random Item)** — 한국 게임산업법 용어. 가챠와 유사 개념. (13장)

**FOR UPDATE** — MySQL의 행 잠금 SQL 구문. 비관적 락. (11장, 12장)

**JOGA** — Japan Online Game Association. 일본 온라인 게임 자율규제 단체. (13장, 부록 C)

**Race Condition** — 동시 접근 시 결과가 예측 불가능해지는 상황. (12장)

**Redis** — 인메모리 키-값 저장소. 캐시·분산락·실시간 카운터에 사용. (10장, 12장)

**SqlKata** — C#용 SQL 쿼리 빌더. 본 책 표준 라이브러리. (10장 등)

**SSR / SR / R** — 가챠의 대표적 등급 약어. SS Rare, S Rare, Rare. (3장)
