# 14장. 확률이 올바른지 테스트하는 법

확률은 "느낌"으로 검증할 수 없다. 100번 돌려보고 "괜찮네"라고 판단하면 사고로 직행이다. 이번 장에서는 **자동화된 확률 검증**의 표준 도구인 몬테카를로 시뮬레이션과 카이제곱 검정을 다룬다.

---

## 14.1 "100만 번 돌려보면 안다" — 몬테카를로 시뮬레이션

### 아이디어

> "수학적으로 풀기 어려운 문제는 직접 100만 번 돌려보고 평균을 본다."

```
의도 확률          관찰된 확률 (시뮬레이션 N회)
SSR: 0.700%   →   N=1만:    0.71% (오차 ±0.16%)
                  N=10만:   0.703% (오차 ±0.05%)
                  N=100만:  0.7008% (오차 ±0.02%)
                  N=1천만:  0.6997% (오차 ±0.005%)
```

N이 커질수록 관찰값이 이론값에 수렴한다. 이게 **큰 수의 법칙**이다.

### 코드

```csharp
public sealed class MonteCarloSimulator
{
    private readonly IGachaDrawer _drawer;
    private readonly long _userId;
    private readonly int _bannerId;

    public MonteCarloSimulator(IGachaDrawer drawer, long userId = 0, int bannerId = 0)
    {
        _drawer = drawer;
        _userId = userId;
        _bannerId = bannerId;
    }

    public Dictionary<Tier, int> SimulateTierFrequencies(int trials)
    {
        var counts = new Dictionary<Tier, int>
        {
            [Tier.SSR] = 0, [Tier.SR] = 0, [Tier.R] = 0,
        };
        for (int i = 0; i < trials; i++)
        {
            var item = _drawer.Draw(_userId, _bannerId).MainItem;
            counts[item.Tier]++;
        }
        return counts;
    }

    public Dictionary<long, int> SimulateItemFrequencies(int trials)
    {
        var counts = new Dictionary<long, int>();
        for (int i = 0; i < trials; i++)
        {
            var item = _drawer.Draw(_userId, _bannerId).MainItem;
            counts.TryGetValue(item.ItemId, out var c);
            counts[item.ItemId] = c + 1;
        }
        return counts;
    }

    public void PrintReport(int trials, IDictionary<Tier, double> expectedRates)
    {
        var counts = SimulateTierFrequencies(trials);
        Console.WriteLine($"== 시뮬레이션 N={trials:N0} ==");
        Console.WriteLine($"{"Tier",-5} {"기대",10} {"관찰",10} {"오차",10}");
        foreach (var tier in counts.Keys.OrderBy(x => x))
        {
            var observed = (double)counts[tier] / trials;
            var expected = expectedRates[tier];
            var diff = Math.Abs(observed - expected);
            Console.WriteLine($"{tier,-5} {expected,10:P3} {observed,10:P3} {diff,10:P3}");
        }
    }
}
```

### 사용 예시

```csharp
var sim = new MonteCarloSimulator(drawer);
sim.PrintReport(1_000_000, new Dictionary<Tier, double>
{
    [Tier.SSR] = 0.007,
    [Tier.SR]  = 0.18,
    [Tier.R]   = 0.813,
});

// 출력:
// == 시뮬레이션 N=1,000,000 ==
// Tier   기대         관찰         오차
// SSR    0.700%      0.701%      0.001%
// SR     18.000%     17.992%     0.008%
// R      81.300%     81.307%     0.007%
```

### 100만 회면 충분한가

대략 **각 등급의 기대 발생 횟수가 30회 이상**이면 통계적으로 유의미하다.

```
SSR 0.7% × 100만 = 7000회 → 충분
SSR 0.01% × 100만 = 100회 → 좀 적음, 1000만 권장
```

희귀 아이템일수록 더 많이 돌려야 한다.

## 14.2 카이제곱 검정 — 코드로 "확률이 맞나?" 자동 검증하기

### 아이디어

> "관찰된 빈도가 기대 빈도와 **얼마나 차이나는지** 통계적으로 측정한다."

수식:

```
χ² = Σ (관찰빈도 - 기대빈도)² / 기대빈도

자유도 = 카테고리 수 - 1
```

이 χ²(카이제곱) 값을 표(자유도, 유의수준)와 비교해서 "정상 범위인가"를 판단한다.

### 가챠에 적용

```
관찰: SSR 698, SR 18020, R 81282 (총 100000)
기대: SSR 700, SR 18000, R 81300

χ² = (698-700)²/700 + (18020-18000)²/18000 + (81282-81300)²/81300
   = 4/700 + 400/18000 + 324/81300
   = 0.0057 + 0.0222 + 0.0040
   = 0.0319

자유도 = 3 - 1 = 2
유의수준 0.05일 때 임계값 = 5.991

0.0319 < 5.991 → 차이 없음 (확률 정상)
```

### C# 구현

```csharp
public sealed class ChiSquaredTest
{
    public sealed record Result(double ChiSquared, int DegreesOfFreedom, double PValue, bool IsRejected);

    /// <summary>
    /// 카이제곱 적합도 검정
    /// </summary>
    public static Result Test(
        IReadOnlyList<int> observed,
        IReadOnlyList<double> expectedProbabilities,
        int totalTrials,
        double significanceLevel = 0.05)
    {
        if (observed.Count != expectedProbabilities.Count)
            throw new ArgumentException("관찰/기대 카테고리 수가 다르다");

        var probSum = expectedProbabilities.Sum();
        if (Math.Abs(probSum - 1.0) > 1e-6)
            throw new ArgumentException($"기대 확률 합 ({probSum})이 1이 아니다");

        double chi2 = 0;
        for (int i = 0; i < observed.Count; i++)
        {
            var expected = expectedProbabilities[i] * totalTrials;
            if (expected < 5)
                throw new InvalidOperationException(
                    $"카테고리 {i}의 기대값({expected})이 5 미만이라 카이제곱이 신뢰할 수 없다. " +
                    $"시뮬레이션 횟수를 늘려야 한다.");
            chi2 += Math.Pow(observed[i] - expected, 2) / expected;
        }

        int df = observed.Count - 1;
        double pValue = ChiSquaredPValue(chi2, df);
        bool rejected = pValue < significanceLevel;
        return new Result(chi2, df, pValue, rejected);
    }

    /// <summary>
    /// 카이제곱 p-value 근사 (간단한 구현)
    /// 정확도가 더 필요하면 MathNet.Numerics 사용 권장
    /// </summary>
    private static double ChiSquaredPValue(double chi2, int df)
    {
        // MathNet.Numerics를 쓰는 경우:
        // return 1.0 - MathNet.Numerics.Distributions.ChiSquared.CDF(df, chi2);

        // 자체 구현 (간이)
        return 1.0 - LowerIncompleteGamma(df / 2.0, chi2 / 2.0) / Gamma(df / 2.0);
    }

    private static double Gamma(double x) => MathNet.Numerics.SpecialFunctions.Gamma(x);
    private static double LowerIncompleteGamma(double s, double x)
        => MathNet.Numerics.SpecialFunctions.GammaLowerIncomplete(s, x);
}
```

### 사용

```csharp
// 100만 회 시뮬레이션 결과
var observed = new[] { 6987, 180210, 812803 };  // SSR, SR, R
var expected = new[] { 0.007, 0.18, 0.813 };

var result = ChiSquaredTest.Test(observed, expected, totalTrials: 1_000_000);

Console.WriteLine($"χ² = {result.ChiSquared:F4}");
Console.WriteLine($"df = {result.DegreesOfFreedom}");
Console.WriteLine($"p-value = {result.PValue:F4}");
Console.WriteLine(result.IsRejected
    ? "❌ 확률이 의도와 다르다 (귀무가설 기각)"
    : "✅ 확률이 정상 범위다");
```

### p-value가 무엇인가

- **p-value < 0.05**: 5% 미만의 확률로 우연히 발생할 만한 차이 → "차이가 있다고 판단" (의심)
- **p-value ≥ 0.05**: 우연 범위 → "차이 없다고 판단" (정상)

가챠 검증에서는 **0.05 또는 0.01**이 표준이다.

### 흔한 실수

- 시뮬레이션 횟수를 너무 적게 (예: 1000회) 잡고 카이제곱이 깨졌다고 코드를 의심한다 → **수가 적어서 변동이 큰 것**일 뿐이다.
- 0.001%처럼 매우 희귀한 카테고리가 있는데 시뮬레이션이 부족 → **기대값이 5 미만이면 카이제곱은 못 쓴다**.

## 14.3 [실습] 가챠 유닛 테스트 작성 — PR마다 자동으로 돌리기

### xUnit + FluentAssertions

```csharp
public sealed class GachaProbabilityTests
{
    private readonly IGachaDrawer _drawer;
    private readonly Dictionary<Tier, double> _expected;

    public GachaProbabilityTests()
    {
        var rng = new ThreadSafeRandomProvider();
        var bannerData = LoadTestBanner();
        _drawer = new TieredGachaDrawer(bannerData, rng);
        _expected = bannerData.TierRates.ToDictionary(t => t.Tier, t => t.Probability);
    }

    [Fact(DisplayName = "100만 회 시뮬레이션 시 등급 확률은 의도와 통계적으로 일치해야 한다")]
    public void TierRates_AreCorrect_With_OneMillionDraws()
    {
        const int trials = 1_000_000;
        var counts = new Dictionary<Tier, int>
        {
            [Tier.SSR] = 0, [Tier.SR] = 0, [Tier.R] = 0,
        };
        for (int i = 0; i < trials; i++)
            counts[_drawer.Draw(0, 0).MainItem.Tier]++;

        var observed = new[] { counts[Tier.SSR], counts[Tier.SR], counts[Tier.R] };
        var probs = new[] { _expected[Tier.SSR], _expected[Tier.SR], _expected[Tier.R] };

        var result = ChiSquaredTest.Test(observed, probs, trials, significanceLevel: 0.01);
        result.IsRejected.Should().BeFalse(
            $"확률 차이가 통계적으로 유의미하다 (χ²={result.ChiSquared:F2}, p={result.PValue:F4})");
    }

    [Fact]
    public void Pity_TriggersAt_HardLimit()
    {
        var rng = new QueuedRandomProvider(doubles: Enumerable.Repeat(0.999, 200));
        var pityState = new GachaPityState();
        var service = new HardPityGachaService(_drawer, hardPityAt: 90);

        for (int i = 0; i < 89; i++)
            service.Draw(pityState).Tier.Should().NotBe(Tier.SSR);

        // 90회째에 무조건 SSR
        service.Draw(pityState).Tier.Should().Be(Tier.SSR);
        pityState.Counter.Should().Be(0);
    }

    [Fact]
    public void Pity_ResetsOn_NaturalSsr()
    {
        // 첫 추첨에 SSR이 나오는 시나리오
        var rng = new QueuedRandomProvider(doubles: new[] { 0.001 });  // 0.001 < 0.007
        var state = new GachaPityState();
        var service = new HardPityGachaService(...);

        var item = service.Draw(state);
        item.Tier.Should().Be(Tier.SSR);
        state.Counter.Should().Be(0);  // ← 자연 SSR 시 리셋
    }
}
```

## 14.4 [체크리스트] 배포 전 확률 검증 항목 총정리

```
[ ] 1. 모든 배너에 대해 100만 회 시뮬레이션 통과
[ ] 2. 카이제곱 p-value ≥ 0.01 (유의수준 0.01)
[ ] 3. 천장 시스템 단위 테스트 통과
    [ ] 하드 천장 90회 작동
    [ ] 소프트 천장 곡선 검증
    [ ] 자연 SSR 시 카운터 리셋
    [ ] 50/50 보장 미스 → 다음 픽업 확정
[ ] 4. 박스 가챠 비복원 검증
    [ ] N번 뽑으면 박스 비워짐
    [ ] 등급별 정확한 개수
[ ] 5. 멱등성 키 중복 요청 시 같은 결과 반환
[ ] 6. 분산락 + FOR UPDATE 동시성 부하 테스트 통과
[ ] 7. 공시 페이지가 DB와 자동 생성된 결과와 일치
[ ] 8. 모든 아이템이 풀에 정확히 1번씩 등장
[ ] 9. 가중치 0 또는 음수가 없음
[ ] 10. 등급 확률 합 = 1.0 (오차 1e-6 이내)
```

배포 직전에 이 체크리스트를 PR Description에 붙이고, 모두 체크되어야 머지하는 것을 사내 룰로 권장한다.

## 14장 요약

- 몬테카를로 시뮬레이션은 100만 회 이상이 안정적이다.
- 카이제곱 검정으로 관찰값과 기대값의 차이를 통계적으로 판정한다.
- p-value < 0.01이면 확률이 의심, p-value ≥ 0.01이면 정상 범위다.
- xUnit으로 PR마다 빠른 결정론적 테스트를, 야간에는 100만 회 시뮬레이션을 돌린다.
- 배포 전 체크리스트로 회귀를 막는다.
