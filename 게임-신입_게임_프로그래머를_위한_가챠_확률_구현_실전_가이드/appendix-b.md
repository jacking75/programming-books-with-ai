## B-1. 카이제곱 검정 — 공식·p-value 해석·판단 기준

### 공식

```
χ² = Σ (관찰빈도 - 기대빈도)² / 기대빈도

자유도 df = 카테고리 수 - 1
```

### 사용 조건

- 각 카테고리의 **기대 빈도가 5 이상**일 것
- 표본이 충분히 클 것
- 카테고리는 서로 배타적

### p-value 해석

| p-value | 의미 | 가챠 판단 |
|---------|------|---------|
| < 0.001 | 매우 유의미한 차이 | **즉시 사고 의심** |
| 0.001 ~ 0.01 | 유의미한 차이 | 모니터링 강화 |
| 0.01 ~ 0.05 | 약한 의심 | 표본 더 모음 |
| ≥ 0.05 | 우연 범위 | 정상 |

### 임계값(자유도 1~5, 유의수준 0.05/0.01)

| 자유도 | α=0.05 | α=0.01 |
|--------|--------|--------|
| 1 | 3.841 | 6.635 |
| 2 | 5.991 | 9.210 |
| 3 | 7.815 | 11.345 |
| 4 | 9.488 | 13.277 |
| 5 | 11.070 | 15.086 |

χ² 값이 임계값보다 크면 "확률이 의도와 다르다"고 판단한다.

### 빠른 판단

```
3카테고리(SSR/SR/R), 100만회 시뮬레이션 시
χ² < 6 → 정상
χ² > 10 → 의심
χ² > 20 → 거의 확실히 사고
```

## B-2. 기댓값·분산·표준편차

### 기댓값(평균) E[X]

```
이항분포 (n번 시도, 성공률 p):
  E[X] = n × p

기하분포 (성공할 때까지 시도 횟수):
  E[X] = 1 / p
```

### 분산 Var[X]

```
이항분포: Var[X] = n × p × (1-p)
기하분포: Var[X] = (1-p) / p²
```

### 표준편차 σ

```
σ = √Var[X]
```

### 게임 문맥 예시

| 상황 | 공식 | 값 |
|------|------|---|
| SSR 0.7%로 100만회 시도 시 평균 SSR 수 | n×p | 7000개 |
| 위 표준편차 | √(n×p×(1-p)) | √6951 ≈ 83.4 |
| 평균 ± 3σ 정상 범위 | E ± 3σ | [6750, 7250] |
| SSR을 한 번이라도 뽑는 평균 시도 횟수 | 1/p | 약 143회 |

### "일평균 사용자 N명, SSR 비율 X" 예측

```
n = N × draws_per_user
expected_ssr = n × ssr_rate
sigma = √(n × ssr_rate × (1 - ssr_rate))

# 3시그마 정상 범위
[expected_ssr - 3*sigma, expected_ssr + 3*sigma]
```

운영 페이지에 이 범위를 띄워두면, 한눈에 정상 여부가 보인다.

## B-3. 자주 쓰는 확률 계산 — "N번 뽑아서 1번이라도 나올 확률"

### 한 번 이상 나올 확률

```
P(at least one) = 1 - (1 - p)^n
```

### 정확히 k번 나올 확률 (이항분포)

```
P(X = k) = C(n,k) × p^k × (1-p)^(n-k)
        = n! / (k!(n-k)!) × p^k × (1-p)^(n-k)
```

### 표본 표 — SSR 0.7% 기준

### CS 응대용 계산 함수

```csharp
public static double AtLeastOnce(double p, int n) => 1 - Math.Pow(1 - p, n);
public static int RequiredPulls(double p, double targetProb)
    => (int)Math.Ceiling(Math.Log(1 - targetProb) / Math.Log(1 - p));
public static double Expected(double p) => 1.0 / p;
```

### 천장 시스템 합쳐 계산

천장 90회까지 받을 평균:

```
유효 확률(소프트+하드 평균):
  1~73: 0.7%
  74~89: 점진 상승
  90: 100%

평균 시도 ≈ 60~70회 정도가 일반적
```

정확한 계산은 시뮬레이션이 더 빠르다.

