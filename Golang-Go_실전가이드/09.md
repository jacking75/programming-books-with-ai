**9.1 Go 테스트 철학과 구조**

Go는 테스트를 언어 수준에서 일급 시민(first-class citizen)으로 대우합니다. 별도의 테스트 프레임워크를 설치하지 않아도 `go test` 명령 하나로 테스트를 실행할 수 있으며, 표준 라이브러리의 `testing` 패키지만으로 강력한 테스트를 작성할 수 있습니다. 이 철학의 핵심은 "테스트는 코드다"라는 것입니다. 테스트 역시 Go 코드로 작성되고, Go의 타입 시스템과 인터페이스를 완벽하게 활용합니다.

```
┌──────────────────────────────────────────────────────────────────┐
│                    Go 테스트 피라미드                             │
│                                                                  │
│                         ╱▔▔▔▔▔╲                                 │
│                        ╱  E2E   ╲    ← 느리고 비용이 크다        │
│                       ╱─────────╲                                │
│                      ╱Integration╲   ← httptest, testcontainers │
│                     ╱─────────────╲                              │
│                    ╱  Unit Tests   ╲  ← 빠르고 격리됨            │
│                   ╱─────────────────╲                            │
│                  ▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔                            │
│                                                                  │
│   파일명 규칙:  xxx_test.go                                       │
│   함수명 규칙:  func TestXxx(t *testing.T)                       │

│   예제:         func ExampleXxx()                                │
```

**프로젝트 구조와 테스트 파일 배치**

Go 테스트 파일에는 두 가지 패키지 전략이 있습니다. `package mypackage`로 선언하면 패키지 내부의 비공개(unexported) 심볼까지 테스트할 수 있는 **화이트박스 테스트**가 되고, `package mypackage_test`로 선언하면 공개 API만 테스트하는 **블랙박스 테스트**가 됩니다. 실무에서는 두 방식을 함께 사용합니다.

```
myapp/
├── go.mod
├── go.sum
├── internal/
│   └── user/
│       ├── user.go
│       ├── user_test.go          ← 화이트박스 테스트 (package user)
│       └── user_integration_test.go ← 블랙박스 (package user_test)
├── handler/
│   ├── handler.go
│   └── handler_test.go
└── testdata/                     ← 골든 파일, 픽스처 데이터
    └── expected_response.json
```

**기본 테스트 구조**

```go
// math/calc.go
package math

import "errors"

func Divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, errors.New("0으로 나눌 수 없습니다")
    }
    return a / b, nil
}
```

```go
// math/calc_test.go
package math

import (
    "testing"
)

func TestDivide(t *testing.T) {
    result, err := Divide(10, 2)
    if err != nil {
        t.Fatalf("예상치 못한 에러: %v", err)
    }
    if result != 5.0 {
        t.Errorf("Divide(10, 2) = %v, want 5.0", result)
    }
}
```

`t.Fatal`과 `t.Error`의 차이를 이해하는 것이 중요합니다. `t.Fatalf`는 해당 테스트를 즉시 중단하지만, `t.Errorf`는 테스트를 실패로 표시하고 계속 실행합니다. 일반적으로 전제 조건이 실패하면 `Fatalf`를, 개별 assertion에는 `Errorf`를 사용합니다.

**9.2 테이블 구동 테스트 (Table-Driven Tests)**

테이블 구동 테스트는 Go 커뮤니티에서 가장 관용적인(idiomatic) 테스트 패턴입니다. 동일한 함수에 대해 여러 입력/출력 시나리오를 슬라이스로 정의하고, 루프로 반복 실행합니다. 이 패턴은 코드 중복을 극적으로 줄이고 새로운 테스트 케이스 추가를 용이하게 합니다.

```
┌──────────────────────────────────────────────────────────────────┐
│               테이블 구동 테스트의 구조                           │
│                                                                  │
│  tests := []struct{                                              │
│      name     string  ← 테스트 케이스 이름                       │
│      input    ???     ← 입력값                                   │
│      want     ???     ← 기대값                                   │
│      wantErr  bool    ← 에러 기대 여부                           │
│  }{                                                              │
│      { "정상 케이스", ... },                                     │
│      { "경계값 케이스", ... },                                   │
│      { "에러 케이스", ... },                                     │
│  }                                                               │
│                                                                  │
│  for _, tt := range tests {                                      │
│      t.Run(tt.name, func(t *testing.T) {         ← 서브테스트   │
│          // assertion                                            │
│      })                                                          │
│  }                                                               │
└──────────────────────────────────────────────────────────────────┘
```

**실전 예시: 문자열 처리 함수 테스트**

```go
// stringutil/stringutil.go
package stringutil

import (
    "errors"
    "strings"
    "unicode"
)

// Slugify 문자열을 URL 슬러그 형태로 변환합니다.
func Slugify(s string) (string, error) {
    if s == "" {
        return "", errors.New("빈 문자열은 슬러그로 변환할 수 없습니다")
    }
    s = strings.ToLower(s)
    var result strings.Builder
    prevDash := false
    for _, r := range s {
        if unicode.IsLetter(r) || unicode.IsDigit(r) {
            result.WriteRune(r)
            prevDash = false
        } else if !prevDash {
            result.WriteRune('-')
            prevDash = true
        }
    }
    return strings.Trim(result.String(), "-"), nil
}
```

```go
// stringutil/stringutil_test.go
package stringutil_test

import (
    "testing"

    "myapp/stringutil"
)

func TestSlugify(t *testing.T) {
    // 테스트 케이스 테이블 정의
    tests := []struct {
        name    string
        input   string
        want    string
        wantErr bool
    }{
        {
            name:  "일반 영어 문자열",
            input: "Hello World",
            want:  "hello-world",
        },
        {
            name:  "특수문자 포함",
            input: "Go Lang! 2024",
            want:  "go-lang--2024",   // 느낌표와 공백 모두 대시로
        },
        {
            name:  "앞뒤 공백 제거",
            input: "  leading and trailing  ",
            want:  "leading-and-trailing",
        },
        {
            name:  "연속 특수문자는 단일 대시",
            input: "Hello---World",
            want:  "hello-world",
        },
        {
            name:    "빈 문자열은 에러",
            input:   "",
            wantErr: true,
        },
    }

    for _, tt := range tests {
        // t.Run으로 서브테스트 실행 — 각 케이스가 독립 테스트로 동작
        t.Run(tt.name, func(t *testing.T) {
            // t.Parallel()을 추가하면 서브테스트를 병렬 실행할 수 있습니다
            got, err := stringutil.Slugify(tt.input)

            // 에러 기대 여부 확인
            if (err != nil) != tt.wantErr {
                t.Errorf("Slugify(%q) 에러 = %v, wantErr %v", tt.input, err, tt.wantErr)
                return
            }
            // 에러가 발생한 케이스는 결과값 비교 불필요
            if tt.wantErr {
                return
            }
            if got != tt.want {
                t.Errorf("Slugify(%q) = %q, want %q", tt.input, got, tt.want)
            }
        })
    }
}
```

**병렬 서브테스트에서의 루프 변수 캡처 문제**

Go 1.22 이전에는 루프 변수 캡처(loop variable capture)가 가장 흔한 버그였습니다. Go 1.22부터는 루프 변수가 반복마다 새로운 변수를 생성하도록 변경되었으나, 관용적인 코드 작성 습관을 들이는 것이 중요합니다.

```go
func TestParallelSafe(t *testing.T) {
    tests := []struct {
        name  string
        value int
    }{
        {"case A", 1},
        {"case B", 2},
        {"case C", 3},
    }

    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            t.Parallel() // 서브테스트를 병렬 실행

            // Go 1.22+: 루프 변수가 각 이터레이션마다 새로 생성됨
            // Go 1.21 이하에서는 아래와 같이 로컬 변수에 복사해야 했음:
            // tt := tt  ← 과거의 관용구
            
            if tt.value <= 0 {
                t.Errorf("value는 양수여야 합니다: %d", tt.value)
            }
        })
    }
}
```

**9.3 서브테스트와 t.Run — 계층적 테스트 구조**

`t.Run`은 단순히 루프를 위한 것이 아닙니다. 테스트를 논리적으로 그룹화하고 계층 구조를 만드는 데 사용할 수 있으며, `go test -run TestFoo/SubCase` 형태로 특정 케이스만 선택 실행할 수 있습니다.

```go
// go test -run "TestUserService/생성/이메일_중복"  형태로 선택 실행 가능
func TestUserService(t *testing.T) {
    // 공통 설정 (Setup)
    db := setupTestDB(t)

    t.Run("생성", func(t *testing.T) {
        t.Run("정상 생성", func(t *testing.T) {
            // ...
        })
        t.Run("이메일 중복", func(t *testing.T) {
            // ...
        })
        t.Run("잘못된 이메일 형식", func(t *testing.T) {
            // ...
        })
    })

    t.Run("조회", func(t *testing.T) {
        t.Run("존재하는 사용자", func(t *testing.T) {
            // ...
        })
        t.Run("존재하지 않는 사용자", func(t *testing.T) {
            // ...
        })
    })

    t.Run("삭제", func(t *testing.T) {
        // ...
    })

    _ = db
}
```

**테스트 정리: t.Cleanup**

`defer` 대신 `t.Cleanup`을 사용하면 서브테스트 구조에서 정리 함수의 실행 순서를 더 정밀하게 제어할 수 있습니다. `t.Cleanup`에 등록된 함수는 해당 `t`의 수명이 끝날 때 역순으로 실행됩니다.

```go
func setupTestDB(t *testing.T) *sql.DB {
    t.Helper() // 이 함수가 헬퍼임을 선언 (에러 발생 시 이 함수가 아닌 호출자의 위치를 표시)
    
    db, err := sql.Open("sqlite3", ":memory:")
    if err != nil {
        t.Fatalf("DB 연결 실패: %v", err)
    }

    // 테스트 종료 시 자동으로 DB를 닫는다
    t.Cleanup(func() {
        if err := db.Close(); err != nil {
            t.Errorf("DB Close 실패: %v", err)
        }
    })

    return db
}
```

**9.4 httptest — HTTP 핸들러 테스트**

`net/http/httptest` 패키지는 HTTP 핸들러를 실제 서버를 띄우지 않고 메모리 내에서 테스트할 수 있게 해주는 강력한 도구입니다. 두 가지 핵심 타입인 `httptest.ResponseRecorder`와 `httptest.Server`를 이해하면 대부분의 HTTP 테스트를 커버할 수 있습니다.

```
┌──────────────────────────────────────────────────────────────────────┐
│                    httptest 두 가지 접근법                            │
│                                                                      │
│  방법 1: ResponseRecorder (핸들러 단위 테스트)                        │
│  ┌──────────┐   직접 호출   ┌─────────────────────┐                  │
│  │ 테스트코드│ ──────────── │ http.Handler         │                  │
│  │          │ ◄──────────── │  (함수/메서드)        │                  │
│  └──────────┘  응답 검증    └─────────────────────┘                  │
│                                                                      │
│  방법 2: httptest.Server (통합 테스트, 외부 클라이언트 시뮬레이션)      │
│  ┌──────────┐  HTTP 요청   ┌─────────────────────┐                   │
│  │ http     │ ──────────── │ httptest.NewServer() │                   │
│  │ .Client  │ ◄──────────── │  (실제 TCP 리스닝)   │                   │
│  └──────────┘  응답 수신    └─────────────────────┘                   │
└──────────────────────────────────────────────────────────────────────┘
```

**핸들러 단위 테스트: ResponseRecorder**

`httptest.NewRecorder()`는 `http.ResponseWriter`를 구현하여 핸들러가 작성하는 헤더, 상태 코드, 바디를 메모리에 기록합니다.

```go
// handler/user_handler.go
package handler

import (
    "encoding/json"
    "net/http"
    "strconv"
)

type User struct {
    ID    int    `json:"id"`
    Name  string `json:"name"`
    Email string `json:"email"`
}

type UserService interface {
    GetUser(id int) (*User, error)
    CreateUser(name, email string) (*User, error)
}

type UserHandler struct {
    service UserService
}

func NewUserHandler(service UserService) *UserHandler {
    return &UserHandler{service: service}
}

func (h *UserHandler) GetUser(w http.ResponseWriter, r *http.Request) {
    // 쿼리 파라미터에서 id 추출
    idStr := r.URL.Query().Get("id")
    id, err := strconv.Atoi(idStr)
    if err != nil {
        http.Error(w, "잘못된 ID입니다", http.StatusBadRequest)
        return
    }

    user, err := h.service.GetUser(id)
    if err != nil {
        http.Error(w, "사용자를 찾을 수 없습니다", http.StatusNotFound)
        return
    }

    w.Header().Set("Content-Type", "application/json")
    w.WriteHeader(http.StatusOK)
    json.NewEncoder(w).Encode(user)
}

func (h *UserHandler) CreateUser(w http.ResponseWriter, r *http.Request) {
    var req struct {
        Name  string `json:"name"`
        Email string `json:"email"`
    }
    if err := json.NewDecoder(r.Body).Decode(&req); err != nil {
        http.Error(w, "잘못된 요청 바디입니다", http.StatusBadRequest)
        return
    }

    user, err := h.service.CreateUser(req.Name, req.Email)
    if err != nil {
        http.Error(w, err.Error(), http.StatusInternalServerError)
        return
    }

    w.Header().Set("Content-Type", "application/json")
    w.WriteHeader(http.StatusCreated)
    json.NewEncoder(w).Encode(user)
}
```

```go
            queryID: "1",
            mockGetUser: func(id int) (*handler.User, error) {
                return &handler.User{ID: 1, Name: "홍길동", Email: "hong@example.com"}, nil
            },
            wantStatusCode: http.StatusOK,
            wantBody:       &handler.User{ID: 1, Name: "홍길동", Email: "hong@example.com"},
        },
        {
            name:    "존재하지 않는 사용자",
            queryID: "999",
            mockGetUser: func(id int) (*handler.User, error) {
                return nil, errors.New("not found")
            },
            wantStatusCode: http.StatusNotFound,
            wantBody:       nil,
        },
        {
            name:           "잘못된 ID 형식",
            queryID:        "abc",
            mockGetUser:    nil, // 호출되지 않아야 함
            wantStatusCode: http.StatusBadRequest,
            wantBody:       nil,
        },
    }

    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            // Mock 서비스 구성
            svc := &mockUserService{
                getUserFn: tt.mockGetUser,
            }
            h := handler.NewUserHandler(svc)

            // HTTP 요청 생성
            req := httptest.NewRequest(http.MethodGet, "/user?id="+tt.queryID, nil)
            
            // ResponseRecorder: 핸들러가 쓰는 응답을 캡처
            rr := httptest.NewRecorder()

            // 핸들러를 직접 호출 (서버 불필요)
            h.GetUser(rr, req)

            // 상태 코드 검증
            if rr.Code != tt.wantStatusCode {
                t.Errorf("상태 코드 = %d, want %d", rr.Code, tt.wantStatusCode)
            }

            // 바디 검증 (정상 케이스만)
            if tt.wantBody != nil {
                var got handler.User
                if err := json.NewDecoder(rr.Body).Decode(&got); err != nil {
                    t.Fatalf("응답 바디 디코딩 실패: %v", err)
                }
                if got.ID != tt.wantBody.ID || got.Name != tt.wantBody.Name {
                    t.Errorf("응답 바디 = %+v, want %+v", got, tt.wantBody)
                }
            }

            // Content-Type 헤더 검증
            if tt.wantBody != nil {
                contentType := rr.Header().Get("Content-Type")
                if contentType != "application/json" {
                    t.Errorf("Content-Type = %q, want %q", contentType, "application/json")
                }
            }
        })
    }
}
```

**외부 HTTP API 테스트: httptest.NewServer**

외부 API를 호출하는 클라이언트를 테스트할 때는 `httptest.NewServer`로 가짜 서버를 생성합니다. 이를 통해 실제 네트워크 의존성 없이 외부 API 동작을 시뮬레이션할 수 있습니다.

```go
// client/weather_client.go
package client

import (
    "encoding/json"
    "fmt"
    "net/http"
    "time"
)

type WeatherResponse struct {
    City        string  `json:"city"`
    Temperature float64 `json:"temperature"`
    Description string  `json:"description"`
}

type WeatherClient struct {
    baseURL    string
    httpClient *http.Client
}

func NewWeatherClient(baseURL string) *WeatherClient {
    return &WeatherClient{
        baseURL: baseURL,
        httpClient: &http.Client{
            Timeout: 5 * time.Second,
        },
    }
}

func (c *WeatherClient) GetWeather(city string) (*WeatherResponse, error) {
    url := fmt.Sprintf("%s/weather?city=%s", c.baseURL, city)
    resp, err := c.httpClient.Get(url)
    if err != nil {
        return nil, fmt.Errorf("API 호출 실패: %w", err)
    }
    defer resp.Body.Close()

    if resp.StatusCode != http.StatusOK {
        return nil, fmt.Errorf("API 에러: 상태 코드 %d", resp.StatusCode)
    }

    var weather WeatherResponse
    if err := json.NewDecoder(resp.Body).Decode(&weather); err != nil {
        return nil, fmt.Errorf("응답 디코딩 실패: %w", err)
    }
    return &weather, nil
}
```

**9.5 모의(Mock) 전략**

Mock은 실제 의존성(데이터베이스, 외부 API, 파일 시스템 등)을 테스트 환경에서 격리하기 위한 가짜 구현입니다. Go에서 Mock은 **인터페이스를 기반**으로 동작하므로, 인터페이스를 잘 설계하는 것이 Mock 전략의 시작점입니다.

```
┌──────────────────────────────────────────────────────────────────────┐
│                    Go Mock 전략 비교                                 │
│                                                                      │
│  ┌─────────────────┬───────────┬──────────┬───────────────────────┐ │
│  │ 방식             │ 설정 복잡도│ 유연성   │ 추천 상황             │ │
│  ├─────────────────┼───────────┼──────────┼───────────────────────┤ │
│  │ 수동 Mock        │ 낮음      │ 높음     │ 간단한 인터페이스     │ │
│  │ testify/mock    │ 중간      │ 중간     │ 복잡한 동작 검증      │ │
│  │ uber-go/mock    │ 중간      │ 높음     │ 대규모 프로젝트       │ │
│  │ (mockgen)       │           │          │ 자동 생성 선호 시     │ │
│  └─────────────────┴───────────┴──────────┴───────────────────────┘ │
└──────────────────────────────────────────────────────────────────────┘
```

**전략 1: 수동 Mock (인터페이스 기반)**

작은 인터페이스에 적합한 가장 단순한 Mock 방식입니다. 함수 필드를 사용하면 테스트마다 동작을 쉽게 교체할 수 있습니다.

```go
// repository/user_repository.go
package repository

import "context"

type User struct {
    ID    int
    Name  string
    Email string
}

// 인터페이스를 정의 — Mock의 계약
type UserRepository interface {
    FindByID(ctx context.Context, id int) (*User, error)
    Save(ctx context.Context, user *User) error
    Delete(ctx context.Context, id int) error
}
```

```go
// repository/mock_user_repository.go (테스트용 수동 Mock)
package repository

import "context"

// FuncUserRepository — 함수 필드로 구성된 유연한 Mock
type FuncUserRepository struct {
    FindByIDFn func(ctx context.Context, id int) (*User, error)
    SaveFn     func(ctx context.Context, user *User) error
    DeleteFn   func(ctx context.Context, id int) error
    
    // 호출 기록 (검증용)
    FindByIDCalls int
    SaveCalls     int
}

func (m *FuncUserRepository) FindByID(ctx context.Context, id int) (*User, error) {
    m.FindByIDCalls++
    return m.FindByIDFn(ctx, id)
}

func (m *FuncUserRepository) Save(ctx context.Context, user *User) error {
    m.SaveCalls++
    return m.SaveFn(ctx, user)
}

func (m *FuncUserRepository) Delete(ctx context.Context, id int) error {
    return m.DeleteFn(ctx, id)
}
```

**전략 2: testify/mock — 동작 검증까지 포함한 Mock**

`github.com/stretchr/testify/mock`은 기대 호출 횟수, 인자 매칭, 반환값 설정을 선언적으로 정의할 수 있습니다.

```go
// go get github.com/stretchr/testify

// service/user_service_test.go
package service_test

import (
    "context"
    "errors"
    "testing"

    "github.com/stretchr/testify/assert"
    "github.com/stretchr/testify/mock"

    "myapp/repository"
    "myapp/service"
)

// testify/mock을 임베딩한 Mock 구현체
type MockUserRepository struct {
    mock.Mock
}

func (m *MockUserRepository) FindByID(ctx context.Context, id int) (*repository.User, error) {
    // mock.Called: testify에게 이 호출을 알린다
    args := m.Called(ctx, id)
    // 첫 번째 반환값 (nil 처리 필요)
    if args.Get(0) == nil {
        return nil, args.Error(1)
    }
    return args.Get(0).(*repository.User), args.Error(1)
}

func (m *MockUserRepository) Save(ctx context.Context, user *repository.User) error {
    args := m.Called(ctx, user)
    return args.Error(0)
}

func (m *MockUserRepository) Delete(ctx context.Context, id int) error {
    args := m.Called(ctx, id)
    return args.Error(0)
}

// --- 서비스 레이어 테스트 ---
func TestUserService_GetUser(t *testing.T) {
    ctx := context.Background()

    tests := []struct {
        name      string
        userID    int
        setupMock func(*MockUserRepository)
        wantUser  *repository.User
        wantErr   bool
    }{
        {
            name:   "정상 조회",
            userID: 1,
            setupMock: func(m *MockUserRepository) {
                // id=1로 호출 시 User를 반환하도록 설정
                m.On("FindByID", ctx, 1).
                    Return(&repository.User{ID: 1, Name: "홍길동"}, nil).
                    Once() // 정확히 한 번만 호출되어야 함
            },
            wantUser: &repository.User{ID: 1, Name: "홍길동"},
            wantErr:  false,
        },
        {
            name:   "사용자 없음",
            userID: 999,
            setupMock: func(m *MockUserRepository) {
                m.On("FindByID", ctx, 999).
                    Return(nil, errors.New("not found")).
                    Once()
            },
            wantErr: true,
        },
        {
            name:   "임의의 ID에 대해 에러 반환",
            userID: 42,
            setupMock: func(m *MockUserRepository) {
                // mock.Anything: 임의의 인자 매칭
                m.On("FindByID", mock.Anything, mock.AnythingOfType("int")).
                    Return(nil, errors.New("DB 에러"))
            },
            wantErr: true,
        },
    }

    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            // Mock 인스턴스 생성 및 설정
            mockRepo := new(MockUserRepository)
            tt.setupMock(mockRepo)

            // 서비스에 Mock 주입
            svc := service.NewUserService(mockRepo)
            
            got, err := svc.GetUser(ctx, tt.userID)

            // testify/assert로 검증
            if tt.wantErr {
                assert.Error(t, err)
                assert.Nil(t, got)
            } else {
                assert.NoError(t, err)
                assert.Equal(t, tt.wantUser.ID, got.ID)
                assert.Equal(t, tt.wantUser.Name, got.Name)
            }

            // Mock에 설정한 기대값이 모두 충족되었는지 검증
            mockRepo.AssertExpectations(t)
        })
    }
}
```

**전략 3: uber-go/mock (mockgen) — 자동 코드 생성**

대규모 프로젝트에서는 인터페이스마다 Mock을 수동으로 작성하는 것이 번거롭습니다. `mockgen` 도구는 인터페이스 정의를 파싱하여 Mock 구현체를 자동으로 생성합니다.

```bash
# 설치
go install go.uber.org/mock/mockgen@latest

# 인터페이스 파일로부터 Mock 자동 생성
# -source: 입력 인터페이스 파일
# -destination: 생성될 Mock 파일 경로
# -package: 생성 파일의 패키지명
mockgen \
  -source=repository/user_repository.go \
  -destination=repository/mock/mock_user_repository.go \
  -package=mockrepo
```

생성된 Mock 파일을 사용하는 예시는 다음과 같습니다.

**9.6 테스트 헬퍼 (Test Helpers)**

테스트 코드에서도 코드 중복은 피해야 합니다. 공통 assertion이나 복잡한 셋업 로직은 헬퍼 함수로 추출하되, 반드시 `t.Helper()`를 호출해야 합니다. 이 호출이 없으면 실패 로그에 헬퍼 내부의 행 번호가 표시되어 디버깅이 어려워집니다.

```go
// testutil/assert.go
package testutil

import (
    "encoding/json"
    "net/http"
    "testing"
)

// AssertStatusCode HTTP 응답의 상태 코드를 검증하는 헬퍼
func AssertStatusCode(t *testing.T, got, want int) {
    t.Helper() // 이 함수가 헬퍼임을 선언 — 에러 위치가 호출자를 가리킴
    if got != want {
        t.Errorf("상태 코드: got %d, want %d", got, want)
    }
}

// AssertJSONBody HTTP 응답 바디를 파싱해서 구조체와 비교하는 헬퍼
func AssertJSONBody(t *testing.T, body interface{}, resp *http.Response) {
    t.Helper()
    if err := json.NewDecoder(resp.Body).Decode(body); err != nil {
        t.Fatalf("JSON 디코딩 실패: %v", err)
    }
}

// AssertContains 문자열 포함 여부를 검증하는 헬퍼
func AssertContains(t *testing.T, s, substr string) {
    t.Helper()
    if !strings.Contains(s, substr) {
        t.Errorf("%q가 %q를 포함하지 않습니다", s, substr)
    }
}
```

**골든 파일 테스트 (Golden File Testing)**

API 응답, 코드 생성 결과, 복잡한 JSON 구조와 같이 기대값이 크고 복잡한 경우, 기대 결과를 파일로 저장해두고 비교하는 **골든 파일 테스트** 패턴을 사용합니다. `-update` 플래그를 통해 골든 파일을 한 번에 갱신할 수 있어 유지보수가 편리합니다.

```
testdata/
├── golden/
│   ├── TestGetAllUsers.json       ← 기대 응답 저장
│   ├── TestCreateUser.json
│   └── TestGetUserProfile.json
```

```go
// testutil/golden.go
package testutil

import (
    "flag"
    "os"
    "path/filepath"
    "testing"
)

// -update 플래그: go test -update 로 실행하면 골든 파일을 갱신
var update = flag.Bool("update", false, "골든 파일을 현재 출력으로 갱신합니다")

// AssertGolden 출력을 골든 파일과 비교하거나, -update 시 갱신합니다
func AssertGolden(t *testing.T, got []byte) {
    t.Helper()

    // 골든 파일 경로: testdata/golden/<TestName>.golden
    goldenPath := filepath.Join("testdata", "golden", t.Name()+".golden")

    if *update {
        // -update 플래그 사용 시 현재 출력으로 파일 생성/덮어쓰기
        if err := os.MkdirAll(filepath.Dir(goldenPath), 0750); err != nil {
            t.Fatalf("디렉토리 생성 실패: %v", err)
        }
        if err := os.WriteFile(goldenPath, got, 0600); err != nil {
            t.Fatalf("골든 파일 쓰기 실패: %v", err)
        }
        return
    }

    // 기존 골든 파일과 비교
    want, err := os.ReadFile(goldenPath)
    if err != nil {
        t.Fatalf(
            "골든 파일 읽기 실패 (%s): %v\n"+
                "힌트: 'go test -update'를 실행하여 골든 파일을 생성하세요",
            goldenPath, err,
        )
    }

    if string(got) != string(want) {
        t.Errorf(
            "골든 파일과 출력이 다릅니다:\n--- want ---\n%s\n--- got ---\n%s",
            want, got,
        )
    }
}
```

**9.7 퍼징 (Fuzzing) — 예측하지 못한 입력 발견**

Go 1.18부터 표준 라이브러리에 퍼징이 내장되었습니다. 퍼징은 랜덤하게 생성된 입력값으로 함수를 반복 실행하여 크래시나 패닉을 유발하는 엣지 케이스를 자동으로 발견합니다.

```
┌──────────────────────────────────────────────────────────────────┐
│                    퍼징 동작 원리                                 │
│                                                                  │
│   시드 코퍼스                    퍼즈 엔진                        │
│  ┌──────────────┐              ┌─────────────────┐              │
│  │ "hello"      │──────────────│ 입력 변형 & 확장 │              │
│  │ "world"      │              │  "hell\x00o"    │              │
│  │ ""           │              │  "hello\xff"    │──► 함수 실행  │
│  └──────────────┘              │  "\x00\x01..."  │              │
│                                └─────────────────┘              │
│                                         │                       │
│                                         ▼                       │
│                                  크래시 발견 시                  │
│                              testdata/fuzz/<FuncName>/          │
│                              에 재현 케이스 저장                  │
└──────────────────────────────────────────────────────────────────┘
```

```go
// stringutil/stringutil_fuzz_test.go
package stringutil_test

import (
    "testing"
    "unicode/utf8"

    "myapp/stringutil"
)

// FuzzSlugify — Slugify 함수를 퍼즈 테스트합니다
// 실행: go test -fuzz=FuzzSlugify -fuzztime=30s
func FuzzSlugify(f *testing.F) {
    // 시드 코퍼스: 퍼즈 엔진이 변형할 초기 입력값들
    f.Add("Hello World")
    f.Add("한국어 문자열")
    f.Add("!@#$%^&*()")
    f.Add("") // 경계값

    f.Fuzz(func(t *testing.T, input string) {
        // Fuzz 함수 내에서 패닉이 발생하거나 t.Fatal을 호출하면 실패로 기록됨
        result, err := stringutil.Slugify(input)

        // 불변식(invariant) 검증: 어떤 입력이 들어와도 성립해야 하는 조건
        if err == nil {
            // 1. 결과는 유효한 UTF-8이어야 함
            if !utf8.ValidString(result) {
                t.Errorf("Slugify(%q) 결과가 유효한 UTF-8이 아닙니다: %q", input, result)
            }
            // 2. 결과의 길이는 입력보다 길 수 없음
            if len(result) > len(input) {
                t.Errorf("Slugify(%q) 결과 길이(%d)가 입력 길이(%d)보다 큽니다",
                    input, len(result), len(input))
            }
            // 3. 결과에 대소문자 영문자만 포함되어야 함 (아라비아 숫자 포함)
            for _, r := range result {
                if !isSlugChar(r) {
                    t.Errorf("Slugify(%q) 결과에 허용되지 않는 문자 포함: %q", input, r)
                }
            }
        }
    })
}

func isSlugChar(r rune) bool {
    return (r >= 'a' && r <= 'z') || (r >= '0' && r <= '9') || r == '-'
}
```

```bash

# 퍼즈 테스트로 발견된 케이스를 재현 (회귀 테스트)
go test -run=FuzzSlugify/testdata/fuzz/FuzzSlugify/
```

**9.8 testing/synctest — 병행 코드 테스트 (Go 1.25+)**

Go 1.24에서 실험적으로 도입되고 Go 1.25에서 정식 패키지로 승격된 `testing/synctest`는 병행(concurrent) 코드를 테스트할 때의 고질적인 문제인 **느리고 불안정한 테스트**를 해결합니다. 내부적으로 가상 시계(virtual clock)를 사용하여 `time.Sleep` 같은 시간 관련 동작을 즉시 시뮬레이션합니다.

```
┌──────────────────────────────────────────────────────────────────────┐
│               testing/synctest 동작 원리                             │
│                                                                      │
│   synctest.Run(func() {                                              │
│       │                                                              │
│       │  ┌─ 격리된 "버블(bubble)" 환경 ─────────────────────────┐   │
│       │  │                                                       │   │
│       └──│── goroutine A ─── 채널 대기 ── (차단)               │   │
│          │                                                       │   │
│          │── goroutine B ─── time.Sleep ── (차단)               │   │
│          │                                                       │   │
│          │   모든 goroutine이 차단됨 → "durable block" 감지      │   │
│          │                                                       │   │
│          │   → synctest.Wait() 반환                              │   │
│          │   → 가상 시계가 다음 타이머로 점프                    │   │
│          │                                                       │   │
│          └───────────────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────────────────────┘
```

```go
// cache/ttl_cache.go
package cache

import (
    "sync"
    "time"
)

// TTLCache — 항목이 지정된 시간 후 자동 만료되는 캐시
type TTLCache struct {
    mu      sync.Mutex
    items   map[string]cacheItem
    ttl     time.Duration
}

type cacheItem struct {
    value     interface{}
    expiresAt time.Time
}

func NewTTLCache(ttl time.Duration) *TTLCache {
    c := &TTLCache{
        items: make(map[string]cacheItem),
        ttl:   ttl,
    }
    // 백그라운드 정리 goroutine 시작
    go c.cleanup()
    return c
}

func (c *TTLCache) Set(key string, value interface{}) {
    c.mu.Lock()
    defer c.mu.Unlock()
    c.items[key] = cacheItem{
        value:     value,
        expiresAt: time.Now().Add(c.ttl),
    }
}

func (c *TTLCache) Get(key string) (interface{}, bool) {
    c.mu.Lock()
    defer c.mu.Unlock()
    item, ok := c.items[key]
    if !ok || time.Now().After(item.expiresAt) {
        delete(c.items, key)
        return nil, false
    }
    return item.value, true
}

func (c *TTLCache) cleanup() {
    ticker := time.NewTicker(c.ttl)
    defer ticker.Stop()
    for range ticker.C {
        c.mu.Lock()
        now := time.Now()
        for k, v := range c.items {
            if now.After(v.expiresAt) {
                delete(c.items, k)
            }
        }
        c.mu.Unlock()
    }
}
```

```go
// cache/ttl_cache_test.go
package cache_test

import (
    "testing"
    "testing/synctest" // Go 1.25+ 정식 패키지
    "time"

    "myapp/cache"
)

func TestTTLCache_Expiry(t *testing.T) {
    // synctest.Run: 가상 시계가 적용된 격리 환경에서 실행
    synctest.Run(func() {
        ttl := 5 * time.Second
        c := cache.NewTTLCache(ttl)

        // 값 설정
        c.Set("user:1", "홍길동")

        // TTL 만료 전 — 값이 존재해야 함
        synctest.Wait() // 모든 goroutine이 블록될 때까지 대기
        
        val, ok := c.Get("user:1")
        if !ok {
            t.Fatal("TTL 만료 전에 항목이 사라졌습니다")
        }
        if val != "홍길동" {
            t.Errorf("Get() = %v, want 홍길동", val)
        }

        // TTL보다 조금 짧게 잠든다 — 가상 시계로 즉시 점프
        time.Sleep(ttl - time.Nanosecond)
        synctest.Wait()

        // 아직 만료되지 않아야 함
        if _, ok := c.Get("user:1"); !ok {
            t.Error("TTL 직전인데 항목이 만료됐습니다")
        }

        // TTL 정확히 경과 — 가상 시계로 즉시 점프
        time.Sleep(time.Nanosecond)
        synctest.Wait()

        // 이제 만료되어야 함
        if _, ok := c.Get("user:1"); ok {
            t.Error("TTL 경과 후에도 항목이 남아 있습니다")
        }
    })
    // 실제 실행 시간: 거의 0ms (가상 시계 사용)
}

        for i := 0; i < 100; i++ {

                key := "key"
                c.Set(key, i)
                c.Get(key)
            }()
        }
        
        // 모든 goroutine 완료 대기

    })
```

```go
// todo/domain.go
package todo

import (
    "context"
    "errors"
    "time"

// 도메인 에러 정의
var (
    ErrNotFound      = errors.New("todo: 항목을 찾을 수 없습니다")
    ErrInvalidInput  = errors.New("todo: 잘못된 입력값입니다")
    ErrAlreadyExists = errors.New("todo: 이미 존재하는 항목입니다")

// Todo 도메인 모델
type Todo struct {
    ID          int       `json:"id"`
    Title       string    `json:"title"`
    Description string    `json:"description"`
    Done        bool      `json:"done"`
    Priority    int       `json:"priority"` // 1(낮음) ~ 5(높음)
    CreatedAt   time.Time `json:"created_at"`
    UpdatedAt   time.Time `json:"updated_at"`
}

// CreateTodoInput 생성 요청 DTO
type CreateTodoInput struct {
    Title       string `json:"title"`
    Description string `json:"description"`
    Priority    int    `json:"priority"`
}

// UpdateTodoInput 수정 요청 DTO
type UpdateTodoInput struct {
    Title       *string `json:"title,omitempty"`
    Description *string `json:"description,omitempty"`
    Done        *bool   `json:"done,omitempty"`
    Priority    *int    `json:"priority,omitempty"`
}

// Repository 인터페이스 — 데이터 접근 계층의 계약
type Repository interface {
    FindAll(ctx context.Context) ([]*Todo, error)
    FindByID(ctx context.Context, id int) (*Todo, error)
    Create(ctx context.Context, todo *Todo) error
    Update(ctx context.Context, todo *Todo) error
    Delete(ctx context.Context, id int) error
}

// Service 인터페이스 — 비즈니스 로직 계층의 계약
type Service interface {
    GetAll(ctx context.Context) ([]*Todo, error)
    GetByID(ctx context.Context, id int) (*Todo, error)
    Create(ctx context.Context, input CreateTodoInput) (*Todo, error)
    Update(ctx context.Context, id int, input UpdateTodoInput) (*Todo, error)
    Delete(ctx context.Context, id int) error
}
```

**서비스 구현**

```go
// todo/service.go
package todo

import (
    "context"
    "fmt"
    "strings"
    "time"
)

type todoService struct {
    repo Repository
    now  func() time.Time // 테스트에서 교체 가능한 시간 함수
}

// NewService 서비스 생성자 — Repository를 주입받는다
func NewService(repo Repository) Service {
    return &todoService{
        repo: repo,
        now:  time.Now,
    }
}

func (s *todoService) GetAll(ctx context.Context) ([]*Todo, error) {
    return s.repo.FindAll(ctx)
}

func (s *todoService) GetByID(ctx context.Context, id int) (*Todo, error) {
    if id <= 0 {
        return nil, fmt.Errorf("%w: id는 양수여야 합니다", ErrInvalidInput)
    }
    todo, err := s.repo.FindByID(ctx, id)
    if err != nil {
        return nil, err
    }
    return todo, nil
}

func (s *todoService) Create(ctx context.Context, input CreateTodoInput) (*Todo, error) {
    // 입력값 검증
    input.Title = strings.TrimSpace(input.Title)
    if input.Title == "" {
        return nil, fmt.Errorf("%w: 제목은 필수입니다", ErrInvalidInput)
    }
    if input.Priority < 1 || input.Priority > 5 {
        return nil, fmt.Errorf("%w: 우선순위는 1~5 사이여야 합니다", ErrInvalidInput)
    }

    now := s.now()
    todo := &Todo{
        Title:       input.Title,
        Description: input.Description,
        Priority:    input.Priority,
        Done:        false,
        CreatedAt:   now,
        UpdatedAt:   now,
    }

    if err := s.repo.Create(ctx, todo); err != nil {
        return nil, fmt.Errorf("Todo 생성 실패: %w", err)
    }
    return todo, nil
}

func (s *todoService) Update(ctx context.Context, id int, input UpdateTodoInput) (*Todo, error) {
    todo, err := s.repo.FindByID(ctx, id)
    if err != nil {
        return nil, err
    }

    if input.Title != nil {
        title := strings.TrimSpace(*input.Title)
        if title == "" {
            return nil, fmt.Errorf("%w: 제목은 비어있을 수 없습니다", ErrInvalidInput)
        }
        todo.Title = title
    }
    if input.Description != nil {
        todo.Description = *input.Description
    }
    if input.Done != nil {
        todo.Done = *input.Done
    }
    if input.Priority != nil {
        if *input.Priority < 1 || *input.Priority > 5 {
            return nil, fmt.Errorf("%w: 우선순위는 1~5 사이여야 합니다", ErrInvalidInput)
        }
        todo.Priority = *input.Priority
    }
    todo.UpdatedAt = s.now()

    if err := s.repo.Update(ctx, todo); err != nil {
        return nil, fmt.Errorf("Todo 수정 실패: %w", err)
    }
    return todo, nil
}

func (s *todoService) Delete(ctx context.Context, id int) error {
    if _, err := s.repo.FindByID(ctx, id); err != nil {
        return err
    }
    return s.repo.Delete(ctx, id)
}
```

```go
package todo

import (
    "encoding/json"
    "errors"
    "log/slog"
    "net/http"
    "strconv"
    "strings"
)

type Handler struct {
    svc Service
    log *slog.Logger
}

func NewHandler(svc Service, log *slog.Logger) *Handler {
    return &Handler{svc: svc, log: log}
}

// RegisterRoutes 라우터에 핸들러를 등록합니다
func (h *Handler) RegisterRoutes(mux *http.ServeMux) {
    mux.HandleFunc("GET /todos", h.handleGetAll)
    mux.HandleFunc("POST /todos", h.handleCreate)
    mux.HandleFunc("GET /todos/{id}", h.handleGetByID)
    mux.HandleFunc("PUT /todos/{id}", h.handleUpdate)
    mux.HandleFunc("DELETE /todos/{id}", h.handleDelete)
}

// APIError 에러 응답 구조체
type APIError struct {
    Code    string `json:"code"`
    Message string `json:"message"`
}

func (h *Handler) writeJSON(w http.ResponseWriter, status int, data interface{}) {
    w.Header().Set("Content-Type", "application/json; charset=utf-8")
    w.WriteHeader(status)
    if err := json.NewEncoder(w).Encode(data); err != nil {
        h.log.Error("JSON 인코딩 실패", "error", err)
    }
}

func (h *Handler) writeError(w http.ResponseWriter, status int, code, message string) {
    h.writeJSON(w, status, APIError{Code: code, Message: message})
}

func (h *Handler) handleGetAll(w http.ResponseWriter, r *http.Request) {
    todos, err := h.svc.GetAll(r.Context())
    if err != nil {
        h.writeError(w, http.StatusInternalServerError, "INTERNAL_ERROR", "서버 오류가 발생했습니다")
        return
    }
    // null 대신 빈 배열 반환
    if todos == nil {
        todos = []*Todo{}
    }
    h.writeJSON(w, http.StatusOK, todos)
}

func (h *Handler) handleCreate(w http.ResponseWriter, r *http.Request) {
    var input CreateTodoInput
    if err := json.NewDecoder(r.Body).Decode(&input); err != nil {
        h.writeError(w, http.StatusBadRequest, "BAD_REQUEST", "잘못된 요청 형식입니다")
        return
    }

    created, err := h.svc.Create(r.Context(), input)
    if err != nil {
        if errors.Is(err, ErrInvalidInput) {
            h.writeError(w, http.StatusBadRequest, "VALIDATION_ERROR", err.Error())
            return
        }
        h.writeError(w, http.StatusInternalServerError, "INTERNAL_ERROR", "서버 오류가 발생했습니다")
        return
    }

    h.writeJSON(w, http.StatusCreated, created)
}

func (h *Handler) extractID(r *http.Request) (int, error) {
    idStr := r.PathValue("id") // Go 1.22+ 내장 경로 파라미터
    return strconv.Atoi(idStr)
}

func (h *Handler) handleGetByID(w http.ResponseWriter, r *http.Request) {
    id, err := h.extractID(r)
    if err != nil {
        h.writeError(w, http.StatusBadRequest, "BAD_REQUEST", "잘못된 ID 형식입니다")
        return
    }

    t, err := h.svc.GetByID(r.Context(), id)
    if err != nil {
        if errors.Is(err, ErrNotFound) {
            h.writeError(w, http.StatusNotFound, "NOT_FOUND", "항목을 찾을 수 없습니다")
            return
        }
        h.writeError(w, http.StatusInternalServerError, "INTERNAL_ERROR", "서버 오류가 발생했습니다")
        return
    }

    h.writeJSON(w, http.StatusOK, t)
}

func (h *Handler) handleUpdate(w http.ResponseWriter, r *http.Request) {
    id, err := h.extractID(r)
    if err != nil {
        h.writeError(w, http.StatusBadRequest, "BAD_REQUEST", "잘못된 ID 형식입니다")
        return
    }

    var input UpdateTodoInput
    if err := json.NewDecoder(r.Body).Decode(&input); err != nil {
        h.writeError(w, http.StatusBadRequest, "BAD_REQUEST", "잘못된 요청 형식입니다")
        return
    }

    updated, err := h.svc.Update(r.Context(), id, input)
    if err != nil {
        switch {
        case errors.Is(err, ErrNotFound):
            h.writeError(w, http.StatusNotFound, "NOT_FOUND", "항목을 찾을 수 없습니다")
        case errors.Is(err, ErrInvalidInput):
            h.writeError(w, http.StatusBadRequest, "VALIDATION_ERROR", err.Error())
        default:
            h.writeError(w, http.StatusInternalServerError, "INTERNAL_ERROR", "서버 오류가 발생했습니다")
        }
        return
    }

    h.writeJSON(w, http.StatusOK, updated)
}

func (h *Handler) handleDelete(w http.ResponseWriter, r *http.Request) {
    id, err := h.extractID(r)
    if err != nil {
        h.writeError(w, http.StatusBadRequest, "BAD_REQUEST", "잘못된 ID 형식입니다")
        return
    }

    if err := h.svc.Delete(r.Context(), id); err != nil {
        if errors.Is(err, ErrNotFound) {
            h.writeError(w, http.StatusNotFound, "NOT_FOUND", "항목을 찾을 수 없습니다")
            return
        }
        h.writeError(w, http.StatusInternalServerError, "INTERNAL_ERROR", "서버 오류가 발생했습니다")
        return
    }

    w.WriteHeader(http.StatusNoContent)
}
```

```go
// doRequest HTTP 요청을 보내고 응답을 반환하는 헬퍼
func doRequest(t *testing.T, client *http.Client, method, url string, body interface{}) *http.Response {
    t.Helper()

    var reqBody io.Reader
    if body != nil {
        b, err := json.Marshal(body)
        if err != nil {
            t.Fatalf("요청 바디 직렬화 실패: %v", err)
        }
        reqBody = bytes.NewBuffer(b)
    }

    req, err := http.NewRequestWithContext(context.Background(), method, url, reqBody)
    if err != nil {
        t.Fatalf("요청 생성 실패: %v", err)
    }
    if body != nil {
        req.Header.Set("Content-Type", "application/json")
    }

    resp, err := client.Do(req)
    if err != nil {
        t.Fatalf("요청 전송 실패: %v", err)
    }
    return resp
}

        t.Fatalf("응답 디코딩 실패: %v", err)
    }
    return result
```

```go
// todo/memory_repository.go
package todo

import (
    "context"
    "fmt"
    "sync"
    "time"
)

// MemoryRepository 테스트 및 개발용 인메모리 Repository
type MemoryRepository struct {
    mu      sync.RWMutex
    todos   map[int]*Todo
    counter int
}

func NewMemoryRepository() *MemoryRepository {
    return &MemoryRepository{
        todos: make(map[int]*Todo),
    }
}

func (r *MemoryRepository) FindAll(ctx context.Context) ([]*Todo, error) {
    r.mu.RLock()
    defer r.mu.RUnlock()

    result := make([]*Todo, 0, len(r.todos))
    for _, t := range r.todos {
        copied := *t // 복사본 반환 (불변성 보장)
        result = append(result, &copied)
    }
    return result, nil
}

func (r *MemoryRepository) FindByID(ctx context.Context, id int) (*Todo, error) {
    r.mu.RLock()
    defer r.mu.RUnlock()

    t, ok := r.todos[id]
    if !ok {
        return nil, fmt.Errorf("%w: id=%d", ErrNotFound, id)
    }
    copied := *t
    return &copied, nil
}

func (r *MemoryRepository) Create(ctx context.Context, t *Todo) error {
    r.mu.Lock()
    defer r.mu.Unlock()

    r.counter++
    t.ID = r.counter
    t.CreatedAt = time.Now()
    t.UpdatedAt = t.CreatedAt
    copied := *t
    r.todos[r.counter] = &copied
    return nil
}

func (r *MemoryRepository) Update(ctx context.Context, t *Todo) error {
    r.mu.Lock()
    defer r.mu.Unlock()

    if _, ok := r.todos[t.ID]; !ok {
        return fmt.Errorf("%w: id=%d", ErrNotFound, t.ID)
    }
    t.UpdatedAt = time.Now()
    copied := *t
    r.todos[t.ID] = &copied
    return nil
}

func (r *MemoryRepository) Delete(ctx context.Context, id int) error {
    r.mu.Lock()
    defer r.mu.Unlock()

    if _, ok := r.todos[id]; !ok {
        return fmt.Errorf("%w: id=%d", ErrNotFound, id)
    }
    delete(r.todos, id)
    return nil
}
```

```go
        _, err := repo.FindByID(ctx, item.ID)
        if !errors.Is(err, todo.ErrNotFound) {
            t.Errorf("삭제 후 FindByID: 에러 타입 = %v, want %v", err, todo.ErrNotFound)
        }
    })

    t.Run("동시 접근 안전성", func(t *testing.T) {
        repo := todo.NewMemoryRepository()
        var wg sync.WaitGroup
        
        // 100개의 고루틴이 동시에 Create
        for i := 0; i < 100; i++ {
            wg.Add(1)
            go func(n int) {
                defer wg.Done()
                item := &todo.Todo{
                    Title:    fmt.Sprintf("Todo #%d", n),
                    Priority: (n % 5) + 1,
                }
                if err := repo.Create(ctx, item); err != nil {
                    t.Errorf("동시 Create 실패: %v", err)
                }
            }(i)
        }
        wg.Wait()

        all, err := repo.FindAll(ctx)
        if err != nil {
            t.Fatalf("FindAll 실패: %v", err)
        }
        if len(all) != 100 {
            t.Errorf("항목 수: got %d, want 100", len(all))
        }
    })
}
```

Go의 테스트 생태계는 간결하지만 매우 강력합니다. 표준 라이브러리의 `testing` 패키지만으로도 테이블 구동 테스트, 서브테스트, 퍼징, 벤치마크를 모두 구현할 수 있으며, `httptest`는 HTTP 계층의 테스트를 실제 서버 없이 가능하게 합니다. `testify/mock`이나 `uber-go/mock`은 복잡한 의존성을 선언적으로 제어하는 훌륭한 도구입니다. 그리고 Go 1.25에서 정식 승격된 `testing/synctest`는 병행 코드 테스트에서 오랫동안 해결되지 않았던 느리고 불안정한 테스트 문제를 우아하게 해결합니다. 이 장에서 배운 기법들을 조합하면, 빠르고 신뢰할 수 있으며 유지보수가 쉬운 테스트 스위트를 구축할 수 있습니다.
