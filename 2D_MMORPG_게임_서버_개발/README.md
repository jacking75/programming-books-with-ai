# 2D MMORPG 게임 서버 개발

## **1주차: 개발 환경 구축 & 기본 통신**
  
### **학습 목표**
- 게임 서버의 기본 개념 이해
- 개발 도구 설치 및 기본 통신 구현

### **구현 내용**
- **환경 설정**: Visual Studio, MySQL, Redis 설치
- **프로젝트 생성**: 게임 서버, API 서버, MonoGame 엔진 클라이언트 솔루션
- **기본 통신**: 
  - TCP 소켓 기반 게임 서버
  - 클라이언트-서버 연결/해제
  - 오픈소스 MemoryPack 패킷 송수신
- **DB/Redis 연결**: 기본 연결 테스트

### **핵심 개념**
- 클라이언트-서버 구조
- TCP 통신 기초
- 패킷 직렬화/역직렬화

### **실습 목표**
- Visual Studio, MySQL, Redis를 사용한다.
- MySQL 클라이언트 라이브러리로 SqlKata 라이브러리를 사용한다.
- Redis 클라이언트 라이브러리로 Cloud Structures 라이브러리를 사용한다.
- ASP.NET Core Web API 서버 만들기
- [SuperSocketLite](https://github.com/jacking75/SuperSocketLite)를 이용한 에코 서버 만들기

## **2주차: API 서버 & 계정/캐릭터 시스템 완성**
### **학습 목표**
- 웹 API 서버 구축
- 로그인부터 캐릭터 선택까지 전체 플로우 완성

### **구현 내용**
- **API 서버 구축**: 
  - ASP.NET Core Web API 프로젝트
  - 회원가입 `/api/register`
  - 로그인 `/api/login` (Redis 사용)
  - 월드 목록 조회 `/api/worlds`
  - 캐릭터 생성 `/api/character/create`
  - 캐릭터 목록 `/api/character/list`

- **클라이언트 UI**:
  - 로그인 화면
  - 월드 선택 화면
  - 캐릭터 생성/선택 화면

- **DB 스키마**: users, worlds, characters 테이블 완성

### **핵심 개념**
- RESTful API 설계
- Redis를 이용한 인증
- 데이터베이터 관계 설계
- 패스워드 해싱

### **실습 목표**
- 회원가입 → 로그인 → 월드 선택 → 캐릭터 생성/선택 전체 플로우 완성

## **3주차: 게임 월드 입장 & 실시간 이동**
### **학습 목표**

### **핵심 개념**

- 좌표계 및 충돌 처리
- 실시간 데이터 동기화

### **실습 목표**

- 다중 사용자 실시간 동기화
- 브로드캐스트 시스템 구현

### **구현 내용**
- **게임 서버**:
  - 다른 플레이어 위치 브로드캐스트
  - 플레이어 입장/퇴장 처리
  - 시야 범위 내 플레이어만 동기화
  - 플레이어 상태 관리 (온라인/오프라인)

- **클라이언트**:
  - 다른 플레이어 표시
  - 플레이어 이름 표시
  - 접속자 수 표시
  - 플레이어 입장/퇴장 메시지

### **핵심 개념**
- 브로드캐스트 vs 유니캐스트
- 동기화 최적화
- 네트워크 트래픽 관리
- 플레이어 상태 동기화

### **실습 목표**
- 2명 이상 동시 접속하여 서로의 이동 실시간 확인
- 플레이어 입장/퇴장 시 즉시 반영
