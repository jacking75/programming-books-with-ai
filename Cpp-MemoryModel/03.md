## 3.1 스핀락(Spinlock) 구현

### 기본 스핀락

스핀락은 락을 획득할 때까지 반복문(spinning)을 돌며 대기하는 동기화 메커니즘이다. 컨텍스트 스위칭 비용이 없어 짧은 임계 영역에서 효과적이다.

**기본 구조 다이어그램:**
```
스레드 A                    스레드 B
   |                           |
   | try_lock                  |
   |---> [Lock=0]              |
   | SUCCESS                   |
   |                           | try_lock
   | [Critical Section]        |---> [Lock=1]
   |                           | SPINNING...
   |                           | SPINNING...
   | unlock                    |
   |---> [Lock=0]              |
   |                           |---> SUCCESS
   |                           | [Critical Section]
```

**기본 스핀락 구현:**

```cpp
#include <atomic>
#include <thread>
#include <iostream>
#include <vector>

class BasicSpinlock {
private:
    std::atomic<bool> locked{false};

public:
    void lock() {
        // 락이 해제될 때까지 계속 시도
        while (locked.exchange(true, std::memory_order_acquire)) {
            // busy-wait (spinning)
        }
    }

    void unlock() {
        locked.store(false, std::memory_order_release);
    }
};

// 사용 예제
BasicSpinlock spinlock;
int shared_counter = 0;

void increment_counter(int iterations) {
    for (int i = 0; i < iterations; ++i) {
        spinlock.lock();
        ++shared_counter;
        spinlock.unlock();
    }
}

int main() {
    const int num_threads = 4;
    const int iterations = 100000;
    
    std::vector<std::thread> threads;
    
    for (int i = 0; i < num_threads; ++i) {
        threads.emplace_back(increment_counter, iterations);
    }
    
    for (auto& t : threads) {
        t.join();
    }
    
    std::cout << "최종 카운터 값: " << shared_counter << "\n";
    std::cout << "예상 값: " << num_threads * iterations << "\n";
    
    return 0;
}
```

### 메모리 순서 최적화

스핀락의 성능을 개선하기 위해 메모리 순서를 최적화할 수 있다. 특히 획득 시도 중에는 relaxed 순서를 사용하여 오버헤드를 줄인다.

**최적화된 스핀락:**

```cpp
#include <atomic>
#include <thread>
#include <chrono>

class OptimizedSpinlock {
private:
    std::atomic<bool> locked{false};

public:
    void lock() {
        // 1단계: relaxed로 먼저 확인 (읽기만 수행)
        while (locked.load(std::memory_order_relaxed)) {
            // CPU에게 힌트: 다른 하이퍼스레드에 우선권 양보
            #ifdef _MSC_VER
                _mm_pause();  // x86/x64
            #else
                __builtin_ia32_pause();
            #endif
        }
        
        // 2단계: exchange로 실제 획득 시도 (acquire 순서)
        while (locked.exchange(true, std::memory_order_acquire)) {
            // 락 획득 실패 시 다시 1단계로
            while (locked.load(std::memory_order_relaxed)) {
                #ifdef _MSC_VER
                    _mm_pause();
                #else
                    __builtin_ia32_pause();
                #endif
            }
        }
    }

    bool try_lock() {
        // 단순히 한 번만 시도
        return !locked.exchange(true, std::memory_order_acquire);
    }

    void unlock() {
        locked.store(false, std::memory_order_release);
    }
};

// 백오프(backoff) 전략을 적용한 스핀락
class BackoffSpinlock {
private:
    std::atomic<bool> locked{false};
    static constexpr int MAX_BACKOFF = 64;

public:
    void lock() {
        int backoff = 1;
        
        while (true) {
            // 먼저 relaxed로 확인
            if (!locked.load(std::memory_order_relaxed)) {
                // 락이 해제된 것으로 보이면 획득 시도
                if (!locked.exchange(true, std::memory_order_acquire)) {
                    return;  // 성공
                }
            }
            
            // 백오프: 점진적으로 대기 시간 증가
            for (int i = 0; i < backoff; ++i) {
                #ifdef _MSC_VER
                    _mm_pause();
                #endif
            }
            
            backoff = std::min(backoff * 2, MAX_BACKOFF);
        }
    }

    void unlock() {
        locked.store(false, std::memory_order_release);
    }
};
```

**메모리 순서 최적화 이유:**

```
최적화 전략 플로우:
┌─────────────────────────────────────────┐
│ 1. relaxed load로 빠른 확인             │
│    - 캐시 일관성 트래픽 최소화          │
│    - locked == false 될 때까지 대기     │
└──────────────┬──────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────┐
│ 2. acquire exchange로 실제 획득         │
│    - 동기화 보장 필요                   │
│    - 이전 unlock의 release와 동기화     │
└──────────────┬──────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────┐
│ 3. Critical Section 실행                │
└──────────────┬──────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────┐
│ 4. release store로 해제                 │
│    - 임계 영역의 모든 변경사항 가시화   │
└─────────────────────────────────────────┘
```

```cpp
// 디버깅 정보를 포함한 스핀락
class DebugSpinlock {
private:
    std::atomic<bool> locked{false};
    std::atomic<int> contention_count{0};  // 경합 횟수 추적
    std::atomic<std::thread::id> owner_id;  // 소유자 추적

public:
    void lock() {
        auto this_id = std::this_thread::get_id();
        int local_contention = 0;
        
        while (locked.load(std::memory_order_relaxed)) {
            ++local_contention;
            std::this_thread::yield();
        }
        
        while (locked.exchange(true, std::memory_order_acquire)) {
            ++local_contention;
            std::this_thread::yield();
        }
        
        if (local_contention > 0) {
            contention_count.fetch_add(local_contention, std::memory_order_relaxed);
        }
        
        owner_id.store(this_id, std::memory_order_relaxed);
    }

    void unlock() {
        owner_id.store(std::thread::id{}, std::memory_order_relaxed);
        locked.store(false, std::memory_order_release);
    }

    // 디버깅 정보 출력
    void print_stats() const {
        std::cout << "총 경합 횟수: " << contention_count.load() << "\n";
    }
    
    // Visual Studio 디버거에서 확인하기 좋은 형태
    bool is_locked() const {
        return locked.load(std::memory_order_relaxed);
    }
    
    std::thread::id get_owner() const {
        return owner_id.load(std::memory_order_relaxed);
    }
};
```

## 3.2 Lock-Free 자료구조

### Lock-Free 스택

락 없이 동작하는 스택은 CAS(Compare-And-Swap) 연산을 기반으로 구현된다. ABA 문제를 고려해야 한다.

**Lock-Free 스택 구조:**

```
스택 구조 (단일 연결 리스트):

  head (atomic<Node*>)
    |
    v
  [Node 3] -> [Node 2] -> [Node 1] -> nullptr
    |           |           |
   data        data        data

Push 연산:
  1. 새 노드 생성
  2. new_node->next = head.load()
  3. head.compare_exchange_weak(new_node->next, new_node)
  4. 실패 시 2단계부터 재시도
```

**구현 코드:**

```cpp
#include <atomic>
#include <memory>
#include <iostream>
#include <thread>
#include <vector>

template<typename T>
class LockFreeStack {
private:
    struct Node {
        T data;
        Node* next;
        
        Node(const T& value) : data(value), next(nullptr) {}
    };
    
    std::atomic<Node*> head{nullptr};

public:
    ~LockFreeStack() {
        while (Node* old_head = head.load()) {
            head.store(old_head->next);
            delete old_head;
        }
    }
    
    void push(const T& value) {
        Node* new_node = new Node(value);
        
        // head를 새 노드의 next로 설정하고
        // head를 새 노드로 업데이트 (원자적으로)
        new_node->next = head.load(std::memory_order_relaxed);
        
        // CAS 루프: 다른 스레드가 head를 변경했다면 재시도
        while (!head.compare_exchange_weak(
            new_node->next,                    // expected
            new_node,                          // desired
            std::memory_order_release,         // success
            std::memory_order_relaxed          // failure
        )) {
            // compare_exchange_weak가 실패하면
            // new_node->next는 자동으로 현재 head 값으로 업데이트됨
        }
    }
    
    bool pop(T& result) {
        Node* old_head = head.load(std::memory_order_relaxed);
        
        // CAS 루프로 head 제거 시도
        while (old_head != nullptr &&
               !head.compare_exchange_weak(
                   old_head,                      // expected
                   old_head->next,                // desired
                   std::memory_order_acquire,     // success
                   std::memory_order_relaxed      // failure
               )) {
            // 실패 시 old_head는 자동으로 현재 head로 업데이트됨
        }
        
        if (old_head == nullptr) {
            return false;  // 스택이 비어있음
        }
        
        result = old_head->data;
        delete old_head;  // 메모리 재사용 문제 발생 가능! (나중에 해결)
        return true;
    }
    
    bool empty() const {
        return head.load(std::memory_order_relaxed) == nullptr;
    }
};

// 사용 예제
void test_lock_free_stack() {
    LockFreeStack<int> stack;
    const int num_threads = 4;
    const int operations = 10000;
    
    std::vector<std::thread> producers;
    std::vector<std::thread> consumers;
    
    // Producer 스레드들
    for (int i = 0; i < num_threads; ++i) {
        producers.emplace_back([&stack, i, operations]() {
            for (int j = 0; j < operations; ++j) {
                stack.push(i * operations + j);
            }
        });
    }
    
    // Consumer 스레드들
    std::atomic<int> pop_count{0};
    for (int i = 0; i < num_threads; ++i) {
        consumers.emplace_back([&stack, &pop_count, operations]() {
            int value;
            int local_count = 0;
            while (local_count < operations) {
                if (stack.pop(value)) {
                    ++local_count;
                }
            }
            pop_count.fetch_add(local_count, std::memory_order_relaxed);
        });
    }
    
    for (auto& t : producers) t.join();
    for (auto& t : consumers) t.join();
    
    std::cout << "Pop 횟수: " << pop_count.load() << "\n";
    std::cout << "예상 값: " << num_threads * operations << "\n";
}
```

### Lock-Free 큐 (SPSC - Single Producer Single Consumer)

SPSC 큐는 한 개의 생산자와 한 개의 소비자가 있을 때 효율적인 lock-free 구조다.

**SPSC 큐 구조:**

```
링 버퍼 기반 SPSC 큐:

Buffer: [0][1][2][3][4][5][6][7]
         ^              ^
       read            write
       (consumer)      (producer)

상태:
- write_pos (atomic): 다음 쓸 위치
- read_pos (atomic): 다음 읽을 위치
- capacity: 버퍼 크기

Full: (write_pos + 1) % capacity == read_pos
Empty: write_pos == read_pos
```

**구현 코드:**

```cpp
#include <atomic>
#include <vector>
#include <optional>

template<typename T>
class SPSCQueue {
private:
    struct alignas(64) AlignedAtomic {  // 캐시 라인 크기로 정렬
        std::atomic<size_t> value{0};
    };
    
    std::vector<T> buffer;
    size_t capacity;
    
    AlignedAtomic write_pos;  // Producer만 수정
    AlignedAtomic read_pos;   // Consumer만 수정

public:
    explicit SPSCQueue(size_t size) 
        : buffer(size + 1)  // +1: full/empty 구분을 위해
        , capacity(size + 1) 
    {}
    
    // Producer가 호출
    bool push(const T& item) {
        size_t current_write = write_pos.value.load(std::memory_order_relaxed);
        size_t next_write = (current_write + 1) % capacity;
        
        // Full 체크
        if (next_write == read_pos.value.load(std::memory_order_acquire)) {
            return false;  // 큐가 가득 참
        }
        
        buffer[current_write] = item;
        
        // write_pos 업데이트 (release로 데이터 가시화)
        write_pos.value.store(next_write, std::memory_order_release);
        return true;
    }
    
    // Consumer가 호출
    std::optional<T> pop() {
        size_t current_read = read_pos.value.load(std::memory_order_relaxed);
        
        // Empty 체크
        if (current_read == write_pos.value.load(std::memory_order_acquire)) {
            return std::nullopt;  // 큐가 비어있음
        }
        
        T item = buffer[current_read];
        size_t next_read = (current_read + 1) % capacity;
        
        // read_pos 업데이트
        read_pos.value.store(next_read, std::memory_order_release);
        return item;
    }
    
    bool empty() const {
        return read_pos.value.load(std::memory_order_relaxed) == 
               write_pos.value.load(std::memory_order_relaxed);
    }
    
    size_t size() const {
        size_t write = write_pos.value.load(std::memory_order_relaxed);
        size_t read = read_pos.value.load(std::memory_order_relaxed);
        
        if (write >= read) {
            return write - read;
        } else {
            return capacity - read + write;
        }
    }
};

// 사용 예제
void test_spsc_queue() {
    SPSCQueue<int> queue(1000);
    std::atomic<bool> done{false};
    std::atomic<int> sum{0};
    
    // Producer 스레드
    std::thread producer([&]() {
        for (int i = 1; i <= 10000; ++i) {
            while (!queue.push(i)) {
                std::this_thread::yield();
            }
        }
        done.store(true, std::memory_order_release);
    });
    
    // Consumer 스레드
    std::thread consumer([&]() {
        int count = 0;
        while (count < 10000 || !done.load(std::memory_order_acquire)) {
            if (auto value = queue.pop()) {
                sum.fetch_add(*value, std::memory_order_relaxed);
                ++count;
            } else {
                std::this_thread::yield();
            }
        }
    });
    
    producer.join();
    consumer.join();
    
    std::cout << "합계: " << sum.load() << "\n";
    std::cout << "예상 값: " << (10000 * 10001 / 2) << "\n";
}
```

### 메모리 재사용 문제 (ABA 문제)

ABA 문제는 lock-free 자료구조에서 포인터를 재사용할 때 발생하는 심각한 버그다.

**ABA 문제 시나리오:**

```
초기 상태:
  head -> A -> B -> C

스레드 1:
  1. old_head = A를 읽음
  2. next = B를 읽음
  3. (컨텍스트 스위칭)

스레드 2:
  1. A를 pop (head = B)
  2. B를 pop (head = C)
  3. A를 다시 push (head = A)  <- 같은 주소!
  
스레드 1 (재개):
  4. CAS(head, A, B) 성공!  <- 문제!
  5. B는 이미 해제됨 -> 댕글링 포인터!
```

**해결 방법 1: 참조 카운팅 (Hazard Pointer 간소화 버전)**

```cpp
#include <atomic>
#include <memory>
#include <array>

template<typename T>
class SafeLockFreeStack {
private:
    struct Node {
        std::shared_ptr<T> data;
        Node* next;
        
        Node(const T& value) 
            : data(std::make_shared<T>(value))
            , next(nullptr) 
        {}
    };
    
    std::atomic<Node*> head{nullptr};
    std::atomic<int> threads_in_pop{0};  // pop 중인 스레드 수
    std::atomic<Node*> to_be_deleted{nullptr};  // 삭제 대기 노드들

    void try_reclaim(Node* old_head) {
        // pop 중인 다른 스레드가 있다면 삭제 지연
        if (threads_in_pop.load() == 1) {
            // 나만 pop 중이면 안전하게 삭제
            Node* nodes_to_delete = to_be_deleted.exchange(nullptr);
            
            if (--threads_in_pop == 0) {
                // 아직도 나만 있으면 실제 삭제
                delete_nodes(nodes_to_delete);
            } else {
                // 다른 스레드가 들어왔으면 다시 연기
                chain_pending_nodes(nodes_to_delete);
            }
            
            delete old_head;
        } else {
            // 삭제 대기 리스트에 추가
            chain_pending_node(old_head);
            --threads_in_pop;
        }
    }
    
    void chain_pending_node(Node* node) {
        Node* last = to_be_deleted.load();
        node->next = last;
        while (!to_be_deleted.compare_exchange_weak(
            last, node,
            std::memory_order_release,
            std::memory_order_relaxed
        )) {
            node->next = last;
        }
    }
    
    void chain_pending_nodes(Node* nodes) {
        if (!nodes) return;
        
        Node* last = nodes;
        while (last->next) {
            last = last->next;
        }
        
        Node* current_to_delete = to_be_deleted.load();
        last->next = current_to_delete;
        
        while (!to_be_deleted.compare_exchange_weak(
            current_to_delete, nodes,
            std::memory_order_release,
            std::memory_order_relaxed
        )) {
            last->next = current_to_delete;
        }
    }
    
    void delete_nodes(Node* nodes) {
        while (nodes) {
            Node* next = nodes->next;
            delete nodes;
            nodes = next;
        }
    }

public:
    ~SafeLockFreeStack() {
        while (Node* old_head = head.load()) {
            head.store(old_head->next);
            delete old_head;
        }
        
        delete_nodes(to_be_deleted.load());
    }
    
    void push(const T& value) {
        Node* new_node = new Node(value);
        new_node->next = head.load(std::memory_order_relaxed);
        
        while (!head.compare_exchange_weak(
            new_node->next, new_node,
            std::memory_order_release,
            std::memory_order_relaxed
        ));
    }
    
    std::shared_ptr<T> pop() {
        ++threads_in_pop;  // pop 시작 알림
        
        Node* old_head = head.load(std::memory_order_relaxed);
        
        while (old_head != nullptr &&
               !head.compare_exchange_weak(
                   old_head, old_head->next,
                   std::memory_order_acquire,
                   std::memory_order_relaxed
               ));
        
        std::shared_ptr<T> result;
        if (old_head) {
            result = old_head->data;
            try_reclaim(old_head);
        } else {
            --threads_in_pop;
        }
        
        return result;
    }
};
```

**해결 방법 2: Tagged Pointer (64비트 시스템)**

```cpp
#include <atomic>
#include <cstdint>

template<typename T>
class TaggedLockFreeStack {
private:
    struct Node {
        T data;
        Node* next;
        
        Node(const T& value) : data(value), next(nullptr) {}
    };
    
    // Tagged pointer: 상위 16비트는 태그, 하위 48비트는 포인터
    struct TaggedPointer {
        uintptr_t ptr : 48;
        uintptr_t tag : 16;
    };
    
    static_assert(sizeof(TaggedPointer) == sizeof(uintptr_t), 
                  "TaggedPointer size mismatch");
    
    std::atomic<TaggedPointer> head;

public:
    TaggedLockFreeStack() {
        TaggedPointer init{0, 0};
        head.store(init, std::memory_order_relaxed);
    }
    
    void push(const T& value) {
        Node* new_node = new Node(value);
        TaggedPointer new_head, old_head;
        
        old_head = head.load(std::memory_order_relaxed);
        
        do {
            new_node->next = reinterpret_cast<Node*>(old_head.ptr);
            new_head.ptr = reinterpret_cast<uintptr_t>(new_node);
            new_head.tag = old_head.tag + 1;  // 태그 증가로 ABA 방지
        } while (!head.compare_exchange_weak(
            old_head, new_head,
            std::memory_order_release,
            std::memory_order_relaxed
        ));
    }
    
    bool pop(T& result) {
        TaggedPointer old_head, new_head;
        
        old_head = head.load(std::memory_order_relaxed);
        
        do {
            if (old_head.ptr == 0) {
                return false;  // 비어있음
            }
            
            Node* node = reinterpret_cast<Node*>(old_head.ptr);
            new_head.ptr = reinterpret_cast<uintptr_t>(node->next);
            new_head.tag = old_head.tag + 1;  // 태그 증가
        } while (!head.compare_exchange_weak(
            old_head, new_head,
            std::memory_order_acquire,
            std::memory_order_relaxed
        ));
        
        Node* node = reinterpret_cast<Node*>(old_head.ptr);
        result = node->data;
        delete node;  // 여전히 메모리 재사용 문제 존재 (완벽하지 않음)
        
        return true;
    }
};
```

## 3.3 Double-Checked Locking 패턴

### 올바른 구현 방법

Double-Checked Locking은 초기화를 지연시키면서도 성능을 최적화하는 패턴이다. 잘못 구현하면 미묘한 버그가 발생한다.

**잘못된 구현 (C++11 이전):**

```cpp
// 위험! 사용하지 말 것
class Singleton {
private:
    static Singleton* instance;
    static std::mutex mtx;
    
public:
    static Singleton* getInstance() {
        if (instance == nullptr) {  // 첫 번째 체크 (lock 없이)
            std::lock_guard<std::mutex> lock(mtx);
            if (instance == nullptr) {  // 두 번째 체크 (lock 안에서)
                instance = new Singleton();  // 문제 발생 지점!
            }
        }
        return instance;
    }
};

// 문제: 컴파일러와 CPU가 재정렬 가능
// 1. 메모리 할당
// 2. instance 포인터 설정
// 3. 생성자 호출
// -> 다른 스레드가 2번 시점에 접근하면 초기화되지 않은 객체 사용!
```

**올바른 구현 (C++11 이후):**

```cpp
#include <atomic>
#include <mutex>
#include <iostream>

class Singleton {
private:
    Singleton() {
        std::cout << "Singleton 생성자 호출\n";
        // 초기화 작업...
    }
    
    static std::atomic<Singleton*> instance;
    static std::mutex mtx;

public:
    Singleton(const Singleton&) = delete;
    Singleton& operator=(const Singleton&) = delete;
    
    static Singleton* getInstance() {
        // 첫 번째 체크: acquire로 읽기
        Singleton* tmp = instance.load(std::memory_order_acquire);
        
        if (tmp == nullptr) {
            std::lock_guard<std::mutex> lock(mtx);
            
            // 두 번째 체크: relaxed로 읽기 (이미 lock 안)
            tmp = instance.load(std::memory_order_relaxed);
            
            if (tmp == nullptr) {
                tmp = new Singleton();
                
                // release로 쓰기: 생성자 완료를 보장
                instance.store(tmp, std::memory_order_release);
            }
        }
        
        return tmp;
    }
};

std::atomic<Singleton*> Singleton::instance{nullptr};
std::mutex Singleton::mtx;
```

**메모리 순서 설명:**

```
타임라인:

스레드 A                           스레드 B
   |                                  |
   | load(acquire)                    |
   | -> nullptr                       |
   |                                  |
   | lock()                           |
   | load(relaxed)                    |
   | -> nullptr                       |
   |                                  |
   | new Singleton()                  |
   | [생성자 실행]                    |
   |                                  |
   | store(release) ─────────┐        |
   | unlock()                │        |
   |                         │        |
   |                         │        | load(acquire)
   |                         └───────>| -> 완전히 초기화된 객체
   |                                  |
```

```cpp
#include <mutex>
#include <memory>

class ResourceSingleton {
private:
    struct Resource {
        // 무거운 리소스...
        Resource() {
            std::cout << "리소스 초기화 중...\n";

public:
    static Resource* getInstance() {
        Resource* tmp = instance.load(std::memory_order_acquire);
        
        if (tmp == nullptr) {
            std::lock_guard<std::mutex> lock(mtx);
            tmp = instance.load(std::memory_order_relaxed);
            
            if (tmp == nullptr) {
                tmp = new Resource();
                instance.store(tmp, std::memory_order_release);
            }
        }
        
        return tmp;
    }
    
    static void cleanup() {
        Resource* tmp = instance.exchange(nullptr, std::memory_order_acquire);
        delete tmp;
    }
```

## 3.4 펜스(Fence) 사용하기

### `atomic_thread_fence`

펜스는 명시적인 메모리 배리어로, atomic 연산 없이도 메모리 순서를 제어할 수 있다.

**펜스의 동작 원리:**

```
펜스 없이:
  Store A          Load A
  Store B          Load B
  (재정렬 가능)    (재정렬 가능)

펜스와 함께:
  Store A
  Store B
  fence(release)
  ─────────────── 이 선을 넘어 재정렬 불가
  
  fence(acquire)
  ─────────────── 이 선을 넘어 재정렬 불가
  Load A
  Load B
```

**기본 사용법:**

```cpp
#include <atomic>
#include <thread>
#include <iostream>

// 일반 변수 (atomic 아님!)
int data = 0;
std::atomic<bool> ready{false};

void producer() {
    data = 42;  // 일반 변수에 쓰기
    
    // Release fence: 위의 모든 쓰기가 아래 store 전에 완료되도록 보장
    std::atomic_thread_fence(std::memory_order_release);
    
    ready.store(true, std::memory_order_relaxed);
}

void consumer() {
    // Relaxed로 polling
    while (!ready.load(std::memory_order_relaxed)) {
        std::this_thread::yield();
    }
    
    // Acquire fence: 위의 load 이후 아래 읽기가 일어나도록 보장
    std::atomic_thread_fence(std::memory_order_acquire);
    
    std::cout << "데이터: " << data << "\n";  // 항상 42
}

int main() {
    std::thread t1(producer);
    std::thread t2(consumer);
    
    t1.join();
    t2.join();
    
    return 0;
}
```

**펜스 vs Atomic 연산의 메모리 순서:**


**예제 1: 배치 처리 시스템**

```cpp
#include <atomic>
#include <vector>
#include <thread>
#include <iostream>

class BatchProcessor {
private:
    static constexpr size_t BATCH_SIZE = 1000;
    
    std::vector<int> buffer;
    size_t write_index = 0;
    std::atomic<size_t> published_index{0};
    
public:
    BatchProcessor() : buffer(BATCH_SIZE) {}
    
    // Producer: 데이터 추가
    void add(int value) {
        buffer[write_index] = value;
        ++write_index;
        
        if (write_index >= BATCH_SIZE) {
            // 모든 데이터 쓰기가 완료되었음을 보장
            std::atomic_thread_fence(std::memory_order_release);
            
            // 배치가 준비되었음을 알림
            published_index.store(write_index, std::memory_order_relaxed);
            write_index = 0;
        }
    }
    
    // Consumer: 배치 처리
    void process_batch() {
        size_t ready_count = published_index.load(std::memory_order_relaxed);
        
        if (ready_count > 0) {
            // 모든 데이터 읽기 전에 fence
            std::atomic_thread_fence(std::memory_order_acquire);
            
            // 배치 처리
            for (size_t i = 0; i < ready_count; ++i) {
                std::cout << buffer[i] << " ";
            }
            std::cout << "\n";
            
            // 처리 완료 표시
            published_index.store(0, std::memory_order_relaxed);
        }
    }
};
```

**예제 2: 순환 버퍼 with Fence**

```cpp
#include <atomic>
#include <vector>
#include <optional>

template<typename T>
class FencedRingBuffer {
private:
    std::vector<T> buffer;
    size_t capacity;
    
    alignas(64) std::atomic<size_t> write_index{0};
    alignas(64) std::atomic<size_t> read_index{0};

public:
    explicit FencedRingBuffer(size_t size) 
        : buffer(size + 1)
        , capacity(size + 1)
    {}
    
    bool push(const T& item) {
        size_t current_write = write_index.load(std::memory_order_relaxed);
        size_t next_write = (current_write + 1) % capacity;
        
        if (next_write == read_index.load(std::memory_order_acquire)) {
            return false;  // Full
        }
        
        buffer[current_write] = item;
        
        // 데이터 쓰기 완료를 보장
        std::atomic_thread_fence(std::memory_order_release);
        
        write_index.store(next_write, std::memory_order_relaxed);
        return true;
    }
    
    std::optional<T> pop() {
        size_t current_read = read_index.load(std::memory_order_relaxed);
        
        if (current_read == write_index.load(std::memory_order_acquire)) {
            return std::nullopt;  // Empty
        }
        
        // 데이터 읽기 전 fence
        std::atomic_thread_fence(std::memory_order_acquire);
        
        T item = buffer[current_read];
        size_t next_read = (current_read + 1) % capacity;
        
        read_index.store(next_read, std::memory_order_relaxed);
        return item;
    }
};
```

```cpp
    void update(long total, long success, long failed, double latency) {
        // 버전 번호 증가 (홀수 = 쓰기 중)
        int current_version = version.load(std::memory_order_relaxed);
        version.store(current_version + 1, std::memory_order_relaxed);
        
        // Fence: 버전 증가가 데이터 쓰기 전에 완료되도록
        std::atomic_thread_fence(std::memory_order_release);
        
        // 데이터 업데이트
        total_requests = total;
        successful_requests = success;
        failed_requests = failed;
        average_latency = latency;
        
        // Fence: 모든 데이터 쓰기 완료 후
        std::atomic_thread_fence(std::memory_order_release);
        
        // 버전 번호 증가 (짝수 = 쓰기 완료)
        version.store(current_version + 2, std::memory_order_release);
    }
    
    // Reader: 일관된 스냅샷 읽기
    struct Snapshot {
        long total;
        long success;
        long failed;
        double latency;
    };
    
    Snapshot read() const {
        Snapshot snap;
        int version_before, version_after;
        
        do {
            // 버전이 짝수일 때까지 대기 (쓰기 중이 아님)
            do {
                version_before = version.load(std::memory_order_acquire);
            } while (version_before & 1);  // 홀수면 쓰기 중
            
            // Fence: 버전 읽기 후 데이터 읽기
            std::atomic_thread_fence(std::memory_order_acquire);
            
            // 데이터 읽기
            snap.total = total_requests;
            snap.success = successful_requests;
            snap.failed = failed_requests;
            snap.latency = average_latency;
            
            // Fence: 데이터 읽기 완료 후
            std::atomic_thread_fence(std::memory_order_acquire);
            
            // 버전 재확인
            version_after = version.load(std::memory_order_acquire);
            
            // 버전이 바뀌었거나 홀수면 다시 읽기
        } while (version_before != version_after || (version_after & 1));
        
        return snap;
    }
};

// 사용 예제
void test_statistics() {
    Statistics stats;
    
    // Writer 스레드
    std::thread writer([&]() {
        for (int i = 0; i < 1000; ++i) {
            stats.update(i * 100, i * 80, i * 20, 0.5 + i * 0.001);
            std::this_thread::sleep_for(std::chrono::milliseconds(1));
        }
    });
    
    // Reader 스레드
    std::thread reader([&]() {
        for (int i = 0; i < 100; ++i) {
            auto snap = stats.read();
            std::cout << "총 요청: " << snap.total 
                      << ", 성공: " << snap.success 
                      << ", 실패: " << snap.failed 
                      << ", 평균 지연: " << snap.latency << "\n";
            std::this_thread::sleep_for(std::chrono::milliseconds(10));
        }
    });
    
    writer.join();
    reader.join();
}
```

**Fence 사용 가이드라인:**

```
언제 Fence를 사용하는가?

✅ 사용해야 할 때:
  - 여러 일반 변수를 원자적으로 동기화
  - Relaxed atomic과 함께 사용하여 성능 최적화
  - 기존 코드에 메모리 순서 추가
  - 플랫폼 특화 최적화

❌ 사용하지 말아야 할 때:
  - 단일 atomic 변수만 사용하는 경우
    (atomic의 메모리 순서만으로 충분)
  - 코드 가독성이 중요한 경우
    (acquire/release가 더 명확함)
  - 성능 차이가 미미한 경우
```

이것으로 3부 "실전 패턴과 활용" 섹션을 마친다. 스핀락, lock-free 자료구조, double-checked locking, 그리고 펜스의 실용적인 사용법을 다루었다. 각 패턴은 실제 멀티스레드 프로그래밍에서 자주 사용되는 기법들이다.
