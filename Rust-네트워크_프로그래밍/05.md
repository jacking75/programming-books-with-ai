# 5장. Tokio로 네트워크 프로그래밍

## 5.1 Tokio의 TcpListener와 TcpStream

Tokio는 표준 라이브러리의 네트워크 API와 유사한 인터페이스를 제공한다. 하지만 모든 작업이 비동기로 처리되며, await 키워드를 사용하여 I/O 작업이 완료될 때까지 기다린다.

### TcpListener

`tokio::net::TcpListener`는 TCP 서버를 만들 때 사용한다. 클라이언트의 연결 요청을 수락하고 `TcpStream`을 생성한다.

기본적인 사용 방법은 다음과 같다.

```rust
use tokio::net::TcpListener;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    // 포트 8080에서 리스닝
    let listener = TcpListener::bind("127.0.0.1:8080").await?;
    println!("서버가 127.0.0.1:8080에서 대기 중");
    
    Ok(())
}
```

`bind` 메서드는 비동기 함수이므로 await를 붙여야 한다. 바인딩이 실패하면 에러를 반환한다.

연결을 수락하려면 `accept` 메서드를 사용한다.

```rust
use tokio::net::TcpListener;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let listener = TcpListener::bind("127.0.0.1:8080").await?;
    
    loop {
        // 새로운 연결 수락
        let (socket, addr) = listener.accept().await?;
        println!("새 연결: {}", addr);
        
        // socket은 TcpStream 타입
        // addr은 연결된 클라이언트의 주소
    }
}
```

`accept`는 블로킹 함수처럼 보이지만 실제로는 비동기로 동작한다. 연결 요청이 없으면 다른 태스크가 실행될 수 있도록 제어권을 양보한다.

### TcpStream

`tokio::net::TcpStream`은 연결된 TCP 소켓을 나타낸다. 데이터를 읽고 쓰는 데 사용한다.

TcpStream은 `AsyncRead`와 `AsyncWrite` 트레이트를 구현한다. 이를 통해 비동기 I/O 작업을 수행할 수 있다.

```rust
use tokio::net::TcpStream;
use tokio::io::{AsyncReadExt, AsyncWriteExt};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let mut stream = TcpStream::connect("127.0.0.1:8080").await?;
    
    // 데이터 쓰기
    stream.write_all(b"Hello, Server!").await?;
    
    // 데이터 읽기
    let mut buffer = [0u8; 1024];
    let n = stream.read(&mut buffer).await?;
    
    println!("받은 데이터: {:?}", &buffer[..n]);
    
    Ok(())
}
```

### AsyncReadExt와 AsyncWriteExt

이 두 트레이트는 편리한 헬퍼 메서드들을 제공한다. 사용하려면 먼저 import해야 한다.

```rust
use tokio::io::{AsyncReadExt, AsyncWriteExt};
```

주요 메서드는 다음과 같다.

`read` - 버퍼에 데이터를 읽어온다. 읽은 바이트 수를 반환한다.

```rust
let mut buffer = [0u8; 1024];
let n = stream.read(&mut buffer).await?;
```

`read_exact` - 정확히 버퍼 크기만큼 읽는다. 데이터가 부족하면 에러를 반환한다.

```rust
let mut buffer = [0u8; 10];
stream.read_exact(&mut buffer).await?;
```

`read_to_end` - EOF까지 모든 데이터를 Vec에 읽어온다.

```rust
let mut data = Vec::new();
stream.read_to_end(&mut data).await?;
```

`write` - 버퍼의 데이터를 쓴다. 실제로 쓴 바이트 수를 반환한다.

```rust
let n = stream.write(b"Hello").await?;
```

`write_all` - 버퍼의 모든 데이터를 쓴다.

```rust
stream.write_all(b"Hello, World!").await?;
```

### 스트림 분할하기

TcpStream을 읽기 전용과 쓰기 전용으로 분할할 수 있다. 이는 읽기와 쓰기를 동시에 처리할 때 유용하다.

```rust
use tokio::net::TcpStream;
use tokio::io::{AsyncReadExt, AsyncWriteExt};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let stream = TcpStream::connect("127.0.0.1:8080").await?;
    let (mut read_half, mut write_half) = stream.into_split();
    
    // 읽기와 쓰기를 각각 다른 태스크에서 처리 가능
    tokio::spawn(async move {
        let mut buffer = [0u8; 1024];
        loop {
            let n = read_half.read(&mut buffer).await.unwrap();
            if n == 0 {
                break;
            }
            println!("받음: {:?}", &buffer[..n]);
        }
    });
    
    write_half.write_all(b"Message").await?;
    
    Ok(())
}
```

## 5.2 비동기 Echo 서버 구현

이제 실제로 동작하는 Echo 서버를 만들어보자. Echo 서버는 클라이언트가 보낸 데이터를 그대로 돌려보낸다.

### 기본 Echo 서버

먼저 단일 클라이언트를 처리하는 간단한 버전을 만든다.

```rust
use tokio::net::TcpListener;
use tokio::io::{AsyncReadExt, AsyncWriteExt};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let listener = TcpListener::bind("127.0.0.1:8080").await?;
    println!("Echo 서버가 127.0.0.1:8080에서 대기 중");
    
    loop {
        let (mut socket, addr) = listener.accept().await?;
        println!("새 연결: {}", addr);
        
        let mut buffer = [0u8; 1024];
        
        loop {
            // 데이터 읽기
            let n = socket.read(&mut buffer).await?;
            
            // 연결이 닫혔는지 확인
            if n == 0 {
                println!("연결 종료: {}", addr);
                break;
            }
            
            // 받은 데이터 그대로 돌려보내기
            socket.write_all(&buffer[..n]).await?;
            println!("Echo: {} bytes to {}", n, addr);
        }
    }
}
```

이 코드는 한 번에 하나의 클라이언트만 처리할 수 있다. 첫 번째 클라이언트가 연결을 종료해야 다음 클라이언트를 받을 수 있다.

### 멀티 클라이언트 Echo 서버

여러 클라이언트를 동시에 처리하려면 각 연결을 별도의 태스크에서 처리해야 한다.

```rust
use tokio::net::TcpListener;
use tokio::io::{AsyncReadExt, AsyncWriteExt};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let listener = TcpListener::bind("127.0.0.1:8080").await?;
    println!("Echo 서버가 127.0.0.1:8080에서 대기 중");
    
    loop {
        let (socket, addr) = listener.accept().await?;
        println!("새 연결: {}", addr);
        
        // 각 연결을 별도 태스크에서 처리
        tokio::spawn(async move {
            handle_client(socket, addr).await;
        });
    }
}

async fn handle_client(mut socket: tokio::net::TcpStream, addr: std::net::SocketAddr) {
    let mut buffer = [0u8; 1024];
    
    loop {
        match socket.read(&mut buffer).await {
            Ok(0) => {
                println!("연결 종료: {}", addr);
                break;
            }
            Ok(n) => {
                println!("받음: {} bytes from {}", n, addr);
                
                if let Err(e) = socket.write_all(&buffer[..n]).await {
                    eprintln!("쓰기 실패: {}", e);
                    break;
                }
            }
            Err(e) => {
                eprintln!("읽기 실패: {}", e);
                break;
            }
        }
    }
}
```

`tokio::spawn`을 사용하여 각 클라이언트 연결을 독립적인 태스크로 만들었다. 이제 여러 클라이언트가 동시에 연결할 수 있다.

### 에러 처리 개선

실제 서버에서는 더 견고한 에러 처리가 필요하다. Result 타입을 적극 활용하자.

```rust
use tokio::net::{TcpListener, TcpStream};
use tokio::io::{AsyncReadExt, AsyncWriteExt};
use std::error::Error;

#[tokio::main]
async fn main() -> Result<(), Box<dyn Error>> {
    let listener = TcpListener::bind("127.0.0.1:8080").await?;
    println!("Echo 서버가 127.0.0.1:8080에서 대기 중");
    
    loop {
        match listener.accept().await {
            Ok((socket, addr)) => {
                println!("새 연결: {}", addr);
                tokio::spawn(async move {
                    if let Err(e) = handle_client(socket, addr).await {
                        eprintln!("클라이언트 처리 중 에러: {}", e);
                    }
                });
            }
            Err(e) => {
                eprintln!("연결 수락 실패: {}", e);
            }
        }
    }
}

async fn handle_client(
    mut socket: TcpStream, 
    addr: std::net::SocketAddr
) -> Result<(), Box<dyn Error>> {
    let mut buffer = [0u8; 1024];
    
    loop {
        let n = socket.read(&mut buffer).await?;
        
        if n == 0 {
            println!("연결 종료: {}", addr);
            return Ok(());
        }
        
        println!("받음: {} bytes from {}", n, addr);
        socket.write_all(&buffer[..n]).await?;
    }
}
```

### 읽기/쓰기 분리 버전

성능을 더 개선하려면 읽기와 쓰기를 분리할 수 있다.

```rust
use tokio::net::TcpListener;
use tokio::io::{AsyncReadExt, AsyncWriteExt};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let listener = TcpListener::bind("127.0.0.1:8080").await?;
    println!("Echo 서버가 127.0.0.1:8080에서 대기 중");
    
    loop {
        let (socket, addr) = listener.accept().await?;
        println!("새 연결: {}", addr);
        
        tokio::spawn(async move {
            let (mut read_half, mut write_half) = socket.into_split();
            let mut buffer = [0u8; 1024];
            
            loop {
                match read_half.read(&mut buffer).await {
                    Ok(0) => {
                        println!("연결 종료: {}", addr);
                        break;
                    }
                    Ok(n) => {
                        if let Err(e) = write_half.write_all(&buffer[..n]).await {
                            eprintln!("쓰기 에러: {}", e);
                            break;
                        }
                    }
                    Err(e) => {
                        eprintln!("읽기 에러: {}", e);
                        break;
                    }
                }
            }
        });
    }
}
```

### 버퍼 크기 조정

고정 크기 버퍼 대신 동적 버퍼를 사용할 수도 있다.

```rust
use tokio::net::TcpListener;
use tokio::io::{AsyncReadExt, AsyncWriteExt};

async fn handle_client_with_vec(
    mut socket: tokio::net::TcpStream, 
    addr: std::net::SocketAddr
) -> Result<(), Box<dyn std::error::Error>> {
    let mut buffer = vec![0u8; 4096]; // 더 큰 버퍼
    
    loop {
        let n = socket.read(&mut buffer).await?;
        
        if n == 0 {
            println!("연결 종료: {}", addr);
            return Ok(());
        }
        
        socket.write_all(&buffer[..n]).await?;
    }
}
```

## 5.3 비동기 Echo 클라이언트 구현

서버를 테스트하기 위한 클라이언트를 만들어보자.

### 기본 클라이언트

가장 간단한 형태의 클라이언트다.

```rust
use tokio::net::TcpStream;
use tokio::io::{AsyncReadExt, AsyncWriteExt};
use std::error::Error;

#[tokio::main]
async fn main() -> Result<(), Box<dyn Error>> {
    // 서버에 연결
    let mut stream = TcpStream::connect("127.0.0.1:8080").await?;
    println!("서버에 연결됨");
    
    // 메시지 전송
    let message = b"Hello, Echo Server!";
    stream.write_all(message).await?;
    println!("전송: {:?}", std::str::from_utf8(message).unwrap());
    
    // 응답 받기
    let mut buffer = [0u8; 1024];
    let n = stream.read(&mut buffer).await?;
    println!("받음: {:?}", std::str::from_utf8(&buffer[..n]).unwrap());
    
    Ok(())
}
```

### 대화형 클라이언트

사용자 입력을 받아서 서버로 보내는 클라이언트를 만들어보자.

```rust
use tokio::net::TcpStream;
use tokio::io::{AsyncReadExt, AsyncWriteExt, BufReader, AsyncBufReadExt};
use std::error::Error;

#[tokio::main]
async fn main() -> Result<(), Box<dyn Error>> {
    let mut stream = TcpStream::connect("127.0.0.1:8080").await?;
    println!("서버에 연결됨. 메시지를 입력하세요 (quit 입력 시 종료):");
    
    let stdin = tokio::io::stdin();
    let mut reader = BufReader::new(stdin);
    let mut line = String::new();
    
    loop {
        print!("> ");
        use std::io::Write;
        std::io::stdout().flush()?;
        
        line.clear();
        reader.read_line(&mut line).await?;
        
        let input = line.trim();
        if input == "quit" {
            println!("종료합니다.");
            break;
        }
        
        // 서버로 전송
        stream.write_all(input.as_bytes()).await?;
        
        // 서버로부터 응답 받기
        let mut buffer = [0u8; 1024];
        let n = stream.read(&mut buffer).await?;
        
        if n == 0 {
            println!("서버가 연결을 종료했습니다.");
            break;
        }
        
        println!("Echo: {}", std::str::from_utf8(&buffer[..n])?);
    }
    
    Ok(())
}
```

하지만 위 코드는 Windows에서 `tokio::io::stdin()`이 제대로 동작하지 않을 수 있다. Windows에서는 표준 입력이 비동기로 동작하지 않기 때문이다.

### Windows 호환 대화형 클라이언트

Windows에서 안정적으로 동작하는 버전을 만들어보자.

```rust
use tokio::net::TcpStream;
use tokio::io::{AsyncReadExt, AsyncWriteExt};
use std::io::{self, BufRead};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let mut stream = TcpStream::connect("127.0.0.1:8080").await?;
    println!("서버에 연결됨. 메시지를 입력하세요 (quit 입력 시 종료):");
    
    let stdin = io::stdin();
    
    loop {
        print!("> ");
        io::Write::flush(&mut io::stdout())?;
        
        let mut input = String::new();
        stdin.lock().read_line(&mut input)?;
        
        let input = input.trim();
        if input == "quit" {
            println!("종료합니다.");
            break;
        }
        
        // 서버로 전송
        stream.write_all(input.as_bytes()).await?;
        
        // 서버로부터 응답 받기
        let mut buffer = [0u8; 1024];
        let n = stream.read(&mut buffer).await?;
        
        if n == 0 {
            println!("서버가 연결을 종료했습니다.");
            break;
        }
        
        println!("Echo: {}", std::str::from_utf8(&buffer[..n])?);
    }
    
    Ok(())
}
```

이 버전은 표준 라이브러리의 동기 stdin을 사용한다. 입력을 기다리는 동안 블로킹되지만, 단순한 테스트 클라이언트로는 충분하다.

### 읽기/쓰기 동시 처리 클라이언트

더 발전된 버전으로, 입력과 출력을 동시에 처리하는 클라이언트를 만들 수 있다.

```rust
use tokio::net::TcpStream;
use tokio::io::{AsyncReadExt, AsyncWriteExt};
use std::sync::Arc;
use tokio::sync::Mutex;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let stream = TcpStream::connect("127.0.0.1:8080").await?;
    println!("서버에 연결됨");
    
    let (mut read_half, mut write_half) = stream.into_split();
    
    // 읽기 태스크
    let read_task = tokio::spawn(async move {
        let mut buffer = [0u8; 1024];
        loop {
            match read_half.read(&mut buffer).await {
                Ok(0) => {
                    println!("\n서버 연결 종료");
                    break;
                }
                Ok(n) => {
                    print!("\r받음: {}\n> ", 
                        std::str::from_utf8(&buffer[..n]).unwrap_or("(invalid utf8)"));
                    use std::io::Write;
                    std::io::stdout().flush().unwrap();
                }
                Err(e) => {
                    eprintln!("\n읽기 에러: {}", e);
                    break;
                }
            }
        }
    });
    
    // 쓰기 태스크
    let write_task = tokio::task::spawn_blocking(move || {
        let stdin = std::io::stdin();
        use std::io::BufRead;
        
        println!("메시지를 입력하세요 (quit 입력 시 종료):");
        
        loop {
            print!("> ");
            use std::io::Write;
            std::io::stdout().flush().unwrap();
            
            let mut input = String::new();
            stdin.lock().read_line(&mut input).unwrap();
            
            let input = input.trim();
            if input == "quit" {
                println!("종료합니다.");
                break;
            }
            
            // 비동기 컨텍스트에서 쓰기 수행
            let rt = tokio::runtime::Handle::current();
            rt.block_on(async {
                if let Err(e) = write_half.write_all(input.as_bytes()).await {
                    eprintln!("쓰기 에러: {}", e);
                }
            });
        }
    });
    
    // 둘 중 하나라도 종료되면 프로그램 종료
    tokio::select! {
        _ = read_task => {}
        _ = write_task => {}
    }
    
    Ok(())
}
```

이 버전은 입력과 출력을 완전히 독립적으로 처리한다. 서버로부터 메시지를 받는 동안에도 계속 입력할 수 있다.

### 여러 메시지 연속 전송 테스트

클라이언트로 서버의 성능을 간단히 테스트해볼 수 있다.

```rust
use tokio::net::TcpStream;
use tokio::io::{AsyncReadExt, AsyncWriteExt};
use std::time::Instant;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let mut stream = TcpStream::connect("127.0.0.1:8080").await?;
    println!("서버에 연결됨");
    
    let message = b"Test message for echo server";
    let count = 1000;
    
    let start = Instant::now();
    
    for i in 0..count {
        // 메시지 전송
        stream.write_all(message).await?;
        
        // 응답 받기
        let mut buffer = [0u8; 1024];
        let n = stream.read(&mut buffer).await?;
        
        if n == 0 {
            println!("서버 연결 종료");
            break;
        }
        
        if (i + 1) % 100 == 0 {
            println!("진행: {}/{}", i + 1, count);
        }
    }
    
    let elapsed = start.elapsed();
    println!("완료: {} 메시지, 소요 시간: {:?}", count, elapsed);
    println!("평균: {:?} per message", elapsed / count);
    
    Ok(())
}
```

### 서버 코드 (src/bin/server.rs)

```rust
use tokio::net::TcpListener;
use tokio::io::{AsyncReadExt, AsyncWriteExt};
use std::error::Error;

#[tokio::main]
async fn main() -> Result<(), Box<dyn Error>> {
    let listener = TcpListener::bind("127.0.0.1:8080").await?;
    println!("Echo 서버가 127.0.0.1:8080에서 대기 중");
    
    loop {
        match listener.accept().await {
            Ok((socket, addr)) => {
                println!("새 연결: {}", addr);
                tokio::spawn(async move {
                    if let Err(e) = handle_client(socket, addr).await {
                        eprintln!("클라이언트 처리 중 에러: {}", e);
                    }
                });
            }
            Err(e) => {
                eprintln!("연결 수락 실패: {}", e);
            }
        }
    }
}

async fn handle_client(
    mut socket: tokio::net::TcpStream,
    addr: std::net::SocketAddr
) -> Result<(), Box<dyn Error>> {
    let mut buffer = [0u8; 1024];
    
    loop {
        let n = socket.read(&mut buffer).await?;
        
        if n == 0 {
            println!("연결 종료: {}", addr);
            return Ok(());
        }
        
        println!("받음 from {}: {} bytes", addr, n);
        socket.write_all(&buffer[..n]).await?;
    }
}
```

### 클라이언트 코드 (src/bin/client.rs)

```rust
use tokio::net::TcpStream;
use tokio::io::{AsyncReadExt, AsyncWriteExt};
use std::io::{self, BufRead};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let mut stream = TcpStream::connect("127.0.0.1:8080").await?;
    println!("서버에 연결됨. 메시지를 입력하세요 (quit 입력 시 종료):");
    
    let stdin = io::stdin();
    
    loop {
        print!("> ");
        io::Write::flush(&mut io::stdout())?;
        
        let mut input = String::new();
        stdin.lock().read_line(&mut input)?;
        
        let input = input.trim();
        if input == "quit" {
            println!("종료합니다.");
            break;
        }
        
        if input.is_empty() {
            continue;
        }
        
        stream.write_all(input.as_bytes()).await?;
        
        let mut buffer = [0u8; 1024];
        let n = stream.read(&mut buffer).await?;
        
        if n == 0 {
            println!("서버가 연결을 종료했습니다.");
            break;
        }
        
        println!("Echo: {}", std::str::from_utf8(&buffer[..n])?);
    }
    
    Ok(())
}
```

## 5.5 표준 라이브러리 vs Tokio 비교

1장에서 만든 동기 버전과 이번 장의 비동기 버전을 비교해보자.

### 코드 구조 비교

동기 버전(표준 라이브러리):

```rust
use std::net::TcpListener;
use std::io::{Read, Write};
use std::thread;

fn main() {
    let listener = TcpListener::bind("127.0.0.1:8080").unwrap();
    
    for stream in listener.incoming() {
        let stream = stream.unwrap();
        thread::spawn(|| {
            handle_client(stream);
        });
    }
}

fn handle_client(mut stream: std::net::TcpStream) {
    let mut buffer = [0u8; 1024];
    loop {
        let n = stream.read(&mut buffer).unwrap();
        if n == 0 { break; }
        stream.write_all(&buffer[..n]).unwrap();
    }
}
```

비동기 버전(Tokio):

```rust
use tokio::net::TcpListener;
use tokio::io::{AsyncReadExt, AsyncWriteExt};

#[tokio::main]
async fn main() {
    let listener = TcpListener::bind("127.0.0.1:8080").await.unwrap();
    
    loop {
        let (socket, _) = listener.accept().await.unwrap();
        tokio::spawn(async move {
            handle_client(socket).await;
        });
    }
}

async fn handle_client(mut socket: tokio::net::TcpStream) {
    let mut buffer = [0u8; 1024];
    loop {
        let n = socket.read(&mut buffer).await.unwrap();
        if n == 0 { break; }
        socket.write_all(&buffer[..n]).await.unwrap();
    }
}
```

주요 차이점은 다음과 같다.

첫째, 함수에 `async` 키워드가 붙는다.

둘째, I/O 작업에 `.await`를 붙인다.

셋째, `std::thread::spawn` 대신 `tokio::spawn`을 사용한다.

넷째, 동기 트레이트(`Read`, `Write`) 대신 비동기 트레이트(`AsyncReadExt`, `AsyncWriteExt`)를 사용한다.

### 성능 비교

1000개의 동시 연결을 처리하는 경우를 가정해보자.

동기 버전은 1000개의 OS 스레드를 생성한다. 각 스레드는 약 2MB의 스택 메모리를 사용하므로 총 약 2GB의 메모리가 필요하다.

Tokio 버전은 1000개의 태스크를 생성하지만 실제 OS 스레드는 CPU 코어 수만큼만 사용한다. 각 태스크의 메모리 오버헤드는 수십 바이트에 불과하다.

간단한 벤치마크를 만들어보자.

```rust
use std::time::Instant;
use tokio::net::TcpStream;
use tokio::io::{AsyncWriteExt, AsyncReadExt};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let num_clients = 100;
    let messages_per_client = 100;
    
    let start = Instant::now();
    
    let mut handles = vec![];
    
    for _ in 0..num_clients {
        let handle = tokio::spawn(async move {
            let mut stream = TcpStream::connect("127.0.0.1:8080").await.unwrap();
            let message = b"Benchmark message";
            let mut buffer = [0u8; 1024];
            
            for _ in 0..messages_per_client {
                stream.write_all(message).await.unwrap();
                stream.read(&mut buffer).await.unwrap();
            }
        });
        handles.push(handle);
    }
    
    for handle in handles {
        handle.await?;
    }
    
    let elapsed = start.elapsed();
    let total_messages = num_clients * messages_per_client;
    
    println!("총 메시지: {}", total_messages);
    println!("소요 시간: {:?}", elapsed);
    println!("처리량: {:.2} msg/sec", 
        total_messages as f64 / elapsed.as_secs_f64());
    
    Ok(())
}
```

## 5.6 정리

이 장에서는 Tokio를 사용한 네트워크 프로그래밍의 기초를 배웠다. `TcpListener`와 `TcpStream`을 사용하여 비동기 Echo 서버와 클라이언트를 구현했다.

주요 내용을 정리하면 다음과 같다.

Tokio의 네트워크 API는 표준 라이브러리와 유사하지만 모든 작업이 비동기로 동작한다. `async`/`await` 키워드를 사용하여 비동기 작업을 명시적으로 표현한다.

`AsyncReadExt`와 `AsyncWriteExt` 트레이트는 편리한 헬퍼 메서드들을 제공한다. `read`, `write_all`, `read_exact` 등의 메서드를 통해 데이터를 주고받을 수 있다.

`tokio::spawn`을 사용하여 각 클라이언트 연결을 독립적인 태스크로 처리한다. 이를 통해 수천 개의 동시 연결을 효율적으로 관리할 수 있다.

에러 처리는 Result 타입과 `?` 연산자를 적극 활용한다. 비동기 환경에서도 동기 코드와 동일한 에러 처리 패턴을 사용할 수 있다.

다음 장에서는 Tokio의 고급 기능을 살펴본다. 동기화 프리미티브, 채널, `select!` 매크로 등을 배우고, 이를 활용하여 실시간 채팅 서버를 구현할 것이다.
