# 8장. 방 기반 게임 서버 아키텍처

이 장에서는 오목 게임 서버의 핵심 구조인 방(Room) 기반 아키텍처를 설계하고 구현한다. 멀티플레이어 게임 서버는 일반적으로 로비와 방으로 구성되며, 각 방은 독립적인 게임 세션을 관리한다. Rust의 소유권 시스템과 Tokio의 동시성 기능을 활용하여 안전하고 효율적인 아키�ект처를 만든다.

## 8.1 아키텍처 개요

방 기반 게임 서버의 구조는 다음과 같이 구성된다.

**서버**: 전체 서버의 진입점이며, 클라이언트 연결을 수락하고 로비로 전달한다.

**로비**: 방 목록을 관리하고, 방 생성/입장/퇴장 요청을 처리한다. 모든 방의 상태를 추적한다.

**방**: 게임 세션을 관리하며, 2명의 플레이어가 게임을 진행한다. 각 방은 독립적인 게임 상태를 유지한다.

**플레이어 세션**: 각 클라이언트 연결을 표현하며, 플레이어 정보와 통신 채널을 관리한다.

이러한 구조를 통해 동시에 여러 게임이 진행될 수 있고, 플레이어는 자유롭게 방을 생성하거나 입장할 수 있다.

## 8.2 공유 상태 관리

멀티스레드 환경에서 안전하게 상태를 공유하기 위해 Rust의 `Arc`(Atomic Reference Counting)와 `RwLock`을 사용한다. `Arc`는 여러 소유자 간에 데이터를 공유할 수 있게 하고, `RwLock`은 읽기/쓰기 잠금을 제공하여 동시성을 제어한다.

먼저 프로젝트 구조를 설정한다.

```rust
// src/lib.rs

pub mod player;
pub mod room;
pub mod lobby;
pub mod server;
```

## 8.3 플레이어 세션 구현

각 클라이언트 연결을 나타내는 플레이어 세션을 정의한다.

```rust
// src/player.rs
use tokio::sync::mpsc;
use std::sync::Arc;
use crate::protocol::ServerMessage;

/// 플레이어 고유 ID
pub type PlayerId = u64;

/// 플레이어 정보
#[derive(Debug, Clone)]
pub struct PlayerInfo {
    pub id: PlayerId,
    pub name: String,
}

/// 플레이어 세션
pub struct PlayerSession {
    pub info: PlayerInfo,
    /// 서버에서 클라이언트로 메시지를 보내는 채널
    pub tx: mpsc::UnboundedSender<ServerMessage>,
}

impl PlayerSession {
    pub fn new(id: PlayerId, name: String) -> (Self, mpsc::UnboundedReceiver<ServerMessage>) {
        let (tx, rx) = mpsc::unbounded_channel();
        
        let session = PlayerSession {
            info: PlayerInfo { id, name },
            tx,
        };
        
        (session, rx)
    }
    
    /// 플레이어에게 메시지 전송
    pub fn send(&self, message: ServerMessage) -> Result<(), String> {
        self.tx.send(message)
            .map_err(|_| "플레이어 연결이 끊어짐".to_string())
    }
}

impl std::fmt::Debug for PlayerSession {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        f.debug_struct("PlayerSession")
            .field("info", &self.info)
            .finish()
    }
}
```

`mpsc::unbounded_channel`을 사용하여 각 플레이어에게 메시지를 전송할 수 있는 채널을 만든다. 이를 통해 게임 로직이 있는 스레드에서 네트워크 스레드로 메시지를 보낼 수 있다.

## 8.4 방 구조 설계

방은 게임 세션의 핵심 단위다. 방의 상태와 플레이어 정보를 관리한다.

```rust
// src/room.rs
use std::sync::Arc;
use tokio::sync::RwLock;
use crate::player::{PlayerId, PlayerSession};
use crate::protocol::{ServerMessage, RoomInfo};

/// 방 고유 ID
pub type RoomId = u32;

/// 방 상태
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum RoomState {
    /// 대기 중 (플레이어 모집 중)
    Waiting,
    /// 게임 진행 중
    Playing,
    /// 게임 종료됨
    Finished,
}

/// 방 데이터
pub struct RoomData {
    pub id: RoomId,
    pub name: String,
    pub state: RoomState,
    /// 방에 있는 플레이어들 (최대 2명)
    pub players: Vec<Arc<PlayerSession>>,
    pub max_players: usize,
}

/// 방 (스레드 안전)
pub struct Room {
    data: Arc<RwLock<RoomData>>,
}

impl Room {
    pub fn new(id: RoomId, name: String) -> Self {
        let data = RoomData {
            id,
            name,
            state: RoomState::Waiting,
            players: Vec::new(),
            max_players: 2,
        };
        
        Room {
            data: Arc::new(RwLock::new(data)),
        }
    }
    
    /// 방 정보 조회
    pub async fn get_info(&self) -> RoomInfo {
        let data = self.data.read().await;
        RoomInfo {
            room_id: data.id,
            room_name: data.name.clone(),
            player_count: data.players.len() as u8,
            max_players: data.max_players as u8,
            in_game: data.state == RoomState::Playing,
        }
    }
    
    /// 플레이어 입장 시도
    pub async fn join_player(&self, player: Arc<PlayerSession>) -> Result<(), String> {
        let mut data = self.data.write().await;
        
        // 방이 가득 찬 경우
        if data.players.len() >= data.max_players {
            return Err("방이 가득 참".to_string());
        }
        
        // 이미 게임 중인 경우
        if data.state == RoomState::Playing {
            return Err("게임이 이미 진행 중".to_string());
        }
        
        // 중복 입장 방지
        if data.players.iter().any(|p| p.info.id == player.info.id) {
            return Err("이미 방에 있음".to_string());
        }
        
        // 플레이어 추가
        data.players.push(player.clone());
        
        // 다른 플레이어들에게 알림
        let join_msg = ServerMessage::PlayerJoined {
            player_name: player.info.name.clone(),
        };
        
        for p in &data.players {
            if p.info.id != player.info.id {
                let _ = p.send(join_msg.clone());
            }
        }
        
        // 입장한 플레이어에게 방 정보 전송
        let joined_msg = ServerMessage::JoinedRoom {
            room_id: data.id,
            room_name: data.name.clone(),
        };
        player.send(joined_msg).ok();
        
        println!("[방 {}] {} 입장 ({}/{} 명)", 
            data.id, player.info.name, data.players.len(), data.max_players);
        
        Ok(())
    }
    
    /// 플레이어 퇴장
    pub async fn leave_player(&self, player_id: PlayerId) -> Result<(), String> {
        let mut data = self.data.write().await;
        
        let player_name = data.players.iter()
            .find(|p| p.info.id == player_id)
            .map(|p| p.info.name.clone())
            .ok_or("플레이어를 찾을 수 없음")?;
        
        // 플레이어 제거
        data.players.retain(|p| p.info.id != player_id);
        
        // 나머지 플레이어들에게 알림
        let leave_msg = ServerMessage::PlayerLeft {
            player_name: player_name.clone(),
        };
        
        for p in &data.players {
            let _ = p.send(leave_msg.clone());
        }
        
        println!("[방 {}] {} 퇴장 ({}/{} 명)", 
            data.id, player_name, data.players.len(), data.max_players);
        
        // 방이 비었으면 상태를 Finished로 변경
        if data.players.is_empty() {
            data.state = RoomState::Finished;
        }
        
        Ok(())
    }
    
    /// 게임 시작 가능 여부 확인
    pub async fn can_start_game(&self) -> bool {
        let data = self.data.read().await;
        data.players.len() == data.max_players && data.state == RoomState::Waiting
    }
    
    /// 게임 시작
    pub async fn start_game(&self) -> Result<(), String> {
        let mut data = self.data.write().await;
        
        if data.players.len() != data.max_players {
            return Err("플레이어가 부족함".to_string());
        }
        
        if data.state != RoomState::Waiting {
            return Err("이미 게임이 시작됨".to_string());
        }
        
        data.state = RoomState::Playing;
        
        // 모든 플레이어에게 게임 시작 알림
        if data.players.len() >= 2 {
            let start_msg = ServerMessage::GameStart {
                black_player: data.players[0].info.name.clone(),
                white_player: data.players[1].info.name.clone(),
            };
            
            for player in &data.players {
                let _ = player.send(start_msg.clone());
            }
        }
        
        println!("[방 {}] 게임 시작", data.id);
        
        Ok(())
    }
    
    /// 방 상태 확인
    pub async fn get_state(&self) -> RoomState {
        self.data.read().await.state.clone()
    }
    
    /// 방에 있는 플레이어 수
    pub async fn player_count(&self) -> usize {
        self.data.read().await.players.len()
    }
}

impl Clone for Room {
    fn clone(&self) -> Self {
        Room {
            data: Arc::clone(&self.data),
        }
    }
}
```

`RwLock`을 사용하여 여러 스레드에서 안전하게 방 데이터에 접근할 수 있다. 읽기 작업은 동시에 여러 개가 가능하지만, 쓰기 작업은 배타적으로 실행된다.

## 8.5 로비 구조 설계

로비는 모든 방을 관리하고, 방 생성과 입장 요청을 처리한다.

```rust
// src/lobby.rs
use std::collections::HashMap;
use std::sync::Arc;
use tokio::sync::RwLock;
use crate::room::{Room, RoomId, RoomState};
use crate::player::{PlayerId, PlayerSession};
use crate::protocol::{ServerMessage, RoomInfo};

/// 로비 데이터
struct LobbyData {
    rooms: HashMap<RoomId, Room>,
    next_room_id: RoomId,
    /// 플레이어가 어느 방에 있는지 추적
    player_rooms: HashMap<PlayerId, RoomId>,
}

/// 로비 (스레드 안전)
pub struct Lobby {
    data: Arc<RwLock<LobbyData>>,
}

impl Lobby {
    pub fn new() -> Self {
        let data = LobbyData {
            rooms: HashMap::new(),
            next_room_id: 1,
            player_rooms: HashMap::new(),
        };
        
        Lobby {
            data: Arc::new(RwLock::new(data)),
        }
    }
    
    /// 새 방 생성
    pub async fn create_room(&self, room_name: String) -> RoomId {
        let mut data = self.data.write().await;
        
        let room_id = data.next_room_id;
        data.next_room_id += 1;
        
        let room = Room::new(room_id, room_name.clone());
        data.rooms.insert(room_id, room);
        
        println!("[로비] 방 생성: {} (ID: {})", room_name, room_id);
        
        room_id
    }
    
    /// 방 목록 조회
    pub async fn list_rooms(&self) -> Vec<RoomInfo> {
        let data = self.data.read().await;
        
        let mut rooms = Vec::new();
        for room in data.rooms.values() {
            rooms.push(room.get_info().await);
        }
        
        rooms
    }
    
    /// 플레이어를 방에 입장시킴
    pub async fn join_room(
        &self, 
        room_id: RoomId, 
        player: Arc<PlayerSession>
    ) -> Result<(), String> {
        let mut data = self.data.write().await;
        
        // 이미 다른 방에 있는지 확인
        if data.player_rooms.contains_key(&player.info.id) {
            return Err("이미 다른 방에 있음".to_string());
        }
        
        // 방 찾기
        let room = data.rooms.get(&room_id)
            .ok_or("방을 찾을 수 없음")?
            .clone();
        
        // 방에 입장
        drop(data); // 락 해제 (데드락 방지)
        room.join_player(player.clone()).await?;
        
        // 플레이어-방 매핑 저장
        let mut data = self.data.write().await;
        data.player_rooms.insert(player.info.id, room_id);
        
        // 방이 가득 찼으면 자동으로 게임 시작
        if room.can_start_game().await {
            drop(data); // 락 해제
            room.start_game().await?;
        }
        
        Ok(())
    }
    
    /// 플레이어가 방에서 퇴장
    pub async fn leave_room(&self, player_id: PlayerId) -> Result<(), String> {
        let mut data = self.data.write().await;
        
        // 플레이어가 있는 방 찾기
        let room_id = data.player_rooms.remove(&player_id)
            .ok_or("어떤 방에도 없음")?;
        
        let room = data.rooms.get(&room_id)
            .ok_or("방을 찾을 수 없음")?
            .clone();
        
        drop(data); // 락 해제
        
        // 방에서 플레이어 제거
        room.leave_player(player_id).await?;
        
        // 방이 비었으면 제거
        if room.player_count().await == 0 {
            let mut data = self.data.write().await;
            data.rooms.remove(&room_id);
            println!("[로비] 빈 방 제거: {}", room_id);
        }
        
        Ok(())
    }
    
    /// 플레이어가 속한 방 ID 조회
    pub async fn get_player_room(&self, player_id: PlayerId) -> Option<RoomId> {
        let data = self.data.read().await;
        data.player_rooms.get(&player_id).copied()
    }
    
    /// 특정 방 가져오기
    pub async fn get_room(&self, room_id: RoomId) -> Option<Room> {
        let data = self.data.read().await;
        data.rooms.get(&room_id).cloned()
    }
    
    /// 활성 방 개수
    pub async fn active_room_count(&self) -> usize {
        let data = self.data.read().await;
        data.rooms.len()
    }
}

impl Clone for Lobby {
    fn clone(&self) -> Self {
        Lobby {
            data: Arc::clone(&self.data),
        }
    }
}
```

로비는 `HashMap`을 사용하여 방들을 관리하고, 플레이어와 방의 매핑 정보를 유지한다. `RwLock`을 사용할 때는 데드락을 방지하기 위해 필요 없어진 락은 `drop`으로 명시적으로 해제한다.

mod tests {

        let (player1, _rx1) = PlayerSession::new(1, "플레이어1".to_string());
        let player1 = Arc::new(player1);
        
        // 입장 후 퇴장
        lobby.join_room(room_id, player1.clone()).await.unwrap();

        assert!(result.is_ok());

        let player_room = lobby.get_player_room(1).await;
        assert_eq!(player_room, None);
        
        // 빈 방은 자동 제거되므로 방 개수 확인
        assert_eq!(lobby.active_room_count().await, 0);
    }
    
    #[tokio::test]
    async fn test_game_auto_start() {
        let lobby = Lobby::new();

        lobby.join_room(room_id, player2).await.unwrap();
        
        // 방 상태 확인
        let room = lobby.get_room(room_id).await.unwrap();
        let state = room.get_state().await;
        assert_eq!(state, RoomState::Playing);
    }
}

## 8.7 메시지 브로드캐스트

방 안의 모든 플레이어에게 메시지를 전송하는 유틸리티 함수를 추가한다.

```rust
// src/room.rs에 추가

impl Room {
    /// 방 안의 모든 플레이어에게 메시지 브로드캐스트
    pub async fn broadcast(&self, message: ServerMessage) {
        let data = self.data.read().await;
        
        for player in &data.players {
            let _ = player.send(message.clone());
        }
    }
    
    /// 특정 플레이어를 제외하고 메시지 브로드캐스트
    pub async fn broadcast_except(&self, exclude_id: PlayerId, message: ServerMessage) {
        let data = self.data.read().await;
        
        for player in &data.players {
            if player.info.id != exclude_id {
                let _ = player.send(message.clone());
            }
        }
    }
    
    /// 특정 플레이어에게만 메시지 전송
    pub async fn send_to_player(&self, player_id: PlayerId, message: ServerMessage) -> Result<(), String> {
        let data = self.data.read().await;
        
        let player = data.players.iter()
            .find(|p| p.info.id == player_id)
            .ok_or("플레이어를 찾을 수 없음")?;
        
        player.send(message)
    }
}
```

## 8.8 연결 끊김 처리

플레이어 연결이 끊어졌을 때 자동으로 방에서 퇴장시키는 로직을 추가한다.

```rust
// src/lobby.rs에 추가

impl Lobby {
    /// 플레이어 연결 끊김 처리
    pub async fn handle_disconnect(&self, player_id: PlayerId) {
        println!("[로비] 플레이어 {} 연결 끊김", player_id);
        
        // 플레이어가 방에 있으면 퇴장 처리
        if let Ok(_) = self.leave_room(player_id).await {
            println!("[로비] 플레이어 {} 자동 퇴장", player_id);
        }
    }
}
```

## 8.9 실전 예제: 로비 시뮬레이션

전체 시스템이 동작하는 것을 확인하는 간단한 시뮬레이션을 작성한다.

```rust
// examples/lobby_simulation.rs
use std::sync::Arc;
use tokio::time::{sleep, Duration};

use omok_server::lobby::Lobby;
use omok_server::player::PlayerSession;

#[tokio::main]
async fn main() {
    println!("=== 로비 시뮬레이션 시작 ===\n");
    
    let lobby = Lobby::new();
    
    // 방 생성
    let room1 = lobby.create_room("초보방".to_string()).await;
    let room2 = lobby.create_room("고수방".to_string()).await;
    
    println!("\n현재 방 목록:");
    for room_info in lobby.list_rooms().await {
        println!("  - {} (ID: {}, {}/{} 명)", 
            room_info.room_name, 
            room_info.room_id,
            room_info.player_count,
            room_info.max_players
        );
    }
    
    sleep(Duration::from_secs(1)).await;
    
    // 플레이어 생성
    println!("\n플레이어 생성");
    let (player1, mut rx1) = PlayerSession::new(1, "철수".to_string());
    let (player2, mut rx2) = PlayerSession::new(2, "영희".to_string());
    let (player3, mut rx3) = PlayerSession::new(3, "민수".to_string());
    
    let player1 = Arc::new(player1);
    let player2 = Arc::new(player2);
    let player3 = Arc::new(player3);
    
    // 메시지 수신 태스크들
    tokio::spawn(async move {
        while let Some(msg) = rx1.recv().await {
            println!("[철수] 받음: {:?}", msg);
        }
    });
    
    tokio::spawn(async move {
        while let Some(msg) = rx2.recv().await {
            println!("[영희] 받음: {:?}", msg);
        }
    });
    
    tokio::spawn(async move {
        while let Some(msg) = rx3.recv().await {
            println!("[민수] 받음: {:?}", msg);
        }
    });
    
    sleep(Duration::from_secs(1)).await;
    
    // 플레이어들이 방에 입장
    println!("\n철수가 초보방에 입장");
    lobby.join_room(room1, player1.clone()).await.unwrap();
    
    sleep(Duration::from_millis(500)).await;
    
    println!("\n영희가 초보방에 입장 (게임 자동 시작)");
    lobby.join_room(room1, player2.clone()).await.unwrap();
    
    sleep(Duration::from_millis(500)).await;
    
    println!("\n민수가 고수방에 입장");
    lobby.join_room(room2, player3.clone()).await.unwrap();
    
    sleep(Duration::from_secs(1)).await;
    
    println!("\n현재 방 목록:");
    for room_info in lobby.list_rooms().await {
        println!("  - {} (ID: {}, {}/{} 명, 게임중: {})", 
            room_info.room_name, 
            room_info.room_id,
            room_info.player_count,
            room_info.max_players,
            room_info.in_game
        );
    }
    
    sleep(Duration::from_secs(1)).await;
    
    println!("\n철수가 방에서 퇴장");
    lobby.leave_room(1).await.unwrap();
    
    sleep(Duration::from_secs(1)).await;
    
    println!("\n시뮬레이션 종료");
}
```

## 8.10 정리

이 장에서는 방 기반 게임 서버의 핵심 아키텍처를 설계하고 구현했다. 주요 내용은 다음과 같다.

`Arc`와 `RwLock`을 사용하여 멀티스레드 환경에서 안전하게 상태를 공유했다. 플레이어 세션을 통해 각 클라이언트 연결을 관리하고, `mpsc` 채널로 메시지를 전송했다. 방 구조를 설계하여 독립적인 게임 세션을 관리하고, 플레이어 입장과 퇴장을 처리했다. 로비를 통해 여러 방을 관리하고, 방 생성과 플레이어 매핑을 추적했다. 2명의 플레이어가 입장하면 자동으로 게임이 시작되도록 구현했다.
