## 목차  
  
## 1부: Rust 표준 라이브러리 네트워크 프로그래밍

### 1장. TCP 소켓 기초
- TcpListener와 TcpStream 개요
- 간단한 Echo 서버 만들기
- 간단한 Echo 클라이언트 만들기
- 바이트 스트림 읽기/쓰기

### 2장. 멀티 클라이언트 처리
- 스레드 기반 동시성
- 스레드 풀을 이용한 클라이언트 처리
- 간단한 채팅 서버 구현 (스레드 기반)

## 2부: 비동기 프로그래밍과 Tokio

### 3장. Rust 비동기 프로그래밍 이해
- async/await 기본 개념
- Future trait 이해
- 동기 vs 비동기 비교

### 4장. Tokio 소개
- Tokio 런타임 구조
- Tokio의 주요 컴포넌트 (runtime, task, io)
- Tokio 설치 및 프로젝트 설정

### 5장. Tokio로 네트워크 프로그래밍
- TcpListener와 TcpStream (Tokio 버전)
- 비동기 Echo 서버 구현
- 비동기 Echo 클라이언트 구현

### 6장. Tokio 고급 기능
- tokio::spawn으로 태스크 생성
- tokio::sync (Mutex, RwLock, mpsc 채널)
- tokio::select! 매크로
- 비동기 채팅 서버 구현

## 3부: 실전 게임 서버 개발

### 7장. 프로토콜 설계
- 바이너리 포맷 정의

- 승리 조건 판정 로직
- 게임 보드 관리

### 10장. 최종 프로젝트: Tokio 오목 게임 서버
- 전체 서버 구조 설계
