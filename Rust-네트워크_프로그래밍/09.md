# 9장. 오목 게임 로직 구현

이 장에서는 오목 게임의 핵심 로직을 구현한다. 게임 보드를 관리하고, 돌을 놓는 규칙을 검증하며, 승리 조건을 판정하는 알고리즘을 작성한다. 이러한 게임 로직은 네트워크 계층과 독립적으로 동작하도록 설계하여 테스트와 유지보수를 쉽게 만든다.

## 9.1 오목 게임 규칙

오목은 바둑판 위에서 두 명의 플레이어가 흑돌과 백돌을 번갈아 놓으면서 진행하는 게임이다. 기본 규칙은 다음과 같다.

**보드 크기**: 일반적으로 15x15 크기의 바둑판을 사용한다.

**돌 놓기**: 플레이어는 자신의 턴에 빈 교차점에 돌을 놓는다. 한 번 놓은 돌은 이동하거나 제거할 수 없다.

**턴 순서**: 흑돌을 가진 플레이어가 먼저 시작하고, 이후 흑과 백이 번갈아가며 돌을 놓는다.

**승리 조건**: 자신의 돌 5개를 가로, 세로, 대각선 중 한 방향으로 연속해서 놓으면 승리한다. 6개 이상 연속으로 놓는 것은 일반적으로 승리로 인정하지만, 룰에 따라 다를 수 있다.

이 구현에서는 15x15 보드를 사용하고, 5개 연속으로 놓으면 승리하는 규칙을 적용한다.

## 9.2 게임 상태 정의

먼저 게임에 필요한 기본 타입들을 정의한다.

```rust
// src/game.rs
use crate::protocol::Stone;

/// 보드 크기
pub const BOARD_SIZE: usize = 15;

/// 보드 위치
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Position {
    pub x: u8,
    pub y: u8,
}

impl Position {
    pub fn new(x: u8, y: u8) -> Option<Self> {
        if x < BOARD_SIZE as u8 && y < BOARD_SIZE as u8 {
            Some(Position { x, y })
        } else {
            None
        }
    }
    
    pub fn is_valid(&self) -> bool {
        (self.x as usize) < BOARD_SIZE && (self.y as usize) < BOARD_SIZE
    }
}

/// 보드 셀 상태
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Cell {
    Empty,
    Black,
    White,
}

impl From<Stone> for Cell {
    fn from(stone: Stone) -> Self {
        match stone {
            Stone::Black => Cell::Black,
            Stone::White => Cell::White,
        }
    }
}

impl Cell {
    pub fn to_stone(&self) -> Option<Stone> {
        match self {
            Cell::Black => Some(Stone::Black),
            Cell::White => Some(Stone::White),
            Cell::Empty => None,
        }
    }
}

/// 게임 보드
#[derive(Debug, Clone)]
pub struct Board {
    cells: [[Cell; BOARD_SIZE]; BOARD_SIZE],
    move_count: usize,
}

impl Board {
    pub fn new() -> Self {
        Board {
            cells: [[Cell::Empty; BOARD_SIZE]; BOARD_SIZE],
            move_count: 0,
        }
    }
    
    /// 특정 위치의 셀 상태 조회
    pub fn get(&self, pos: Position) -> Option<Cell> {
        if !pos.is_valid() {
            return None;
        }
        Some(self.cells[pos.y as usize][pos.x as usize])
    }
    
    /// 특정 위치에 돌 놓기
    pub fn place(&mut self, pos: Position, stone: Stone) -> Result<(), String> {
        if !pos.is_valid() {
            return Err("보드 범위를 벗어남".to_string());
        }
        
        let cell = &mut self.cells[pos.y as usize][pos.x as usize];
        
        if *cell != Cell::Empty {
            return Err("이미 돌이 놓여 있음".to_string());
        }
        
        *cell = stone.into();
        self.move_count += 1;
        
        Ok(())
    }
    
    /// 총 수 개수
    pub fn move_count(&self) -> usize {
        self.move_count
    }
    
    /// 보드가 가득 찼는지 확인
    pub fn is_full(&self) -> bool {
        self.move_count >= BOARD_SIZE * BOARD_SIZE
    }
    
    /// 보드를 문자열로 표현 (디버깅용)
    pub fn to_string(&self) -> String {
        let mut result = String::new();
        result.push_str("   ");
        for x in 0..BOARD_SIZE {
            result.push_str(&format!("{:2} ", x));
        }
        result.push('\n');
        
        for y in 0..BOARD_SIZE {
            result.push_str(&format!("{:2} ", y));
            for x in 0..BOARD_SIZE {
                let symbol = match self.cells[y][x] {
                    Cell::Empty => " .",
                    Cell::Black => " ●",
                    Cell::White => " ○",
                };
                result.push_str(symbol);
                result.push(' ');
            }
            result.push('\n');
        }
        
        result
    }
}
```

2차원 배열을 사용하여 보드를 표현한다. `Position` 타입으로 위치를 나타내고, 유효성 검사를 수행한다.

## 9.3 승리 조건 판정

가장 중요한 부분인 승리 조건 판정 로직을 구현한다. 최근에 놓은 돌을 중심으로 8방향을 검사한다.

```rust
// src/game.rs에 추가

/// 방향 벡터 (8방향)
const DIRECTIONS: [(i32, i32); 4] = [
    (1, 0),   // 가로
    (0, 1),   // 세로
    (1, 1),   // 대각선 \
    (1, -1),  // 대각선 /
];

impl Board {
    /// 특정 위치에 돌을 놓았을 때 승리했는지 확인
    pub fn check_win(&self, pos: Position) -> bool {
        let stone = match self.get(pos) {
            Some(Cell::Black) => Cell::Black,
            Some(Cell::White) => Cell::White,
            _ => return false,
        };
        
        // 4방향 검사 (양방향이므로 4개만 검사)
        for &(dx, dy) in &DIRECTIONS {
            if self.count_consecutive(pos, dx, dy, stone) >= 5 {
                return true;
            }
        }
        
        false
    }
    
    /// 특정 방향으로 연속된 돌의 개수 세기
    fn count_consecutive(&self, pos: Position, dx: i32, dy: i32, stone: Cell) -> usize {
        let mut count = 1; // 현재 위치 포함
        
        // 양방향으로 카운트
        count += self.count_direction(pos, dx, dy, stone);
        count += self.count_direction(pos, -dx, -dy, stone);
        
        count
    }
    
    /// 한 방향으로 연속된 돌의 개수 세기
    fn count_direction(&self, pos: Position, dx: i32, dy: i32, stone: Cell) -> usize {
        let mut count = 0;
        let mut x = pos.x as i32 + dx;
        let mut y = pos.y as i32 + dy;
        
        while x >= 0 && x < BOARD_SIZE as i32 && y >= 0 && y < BOARD_SIZE as i32 {
            let cell = self.cells[y as usize][x as usize];
            if cell != stone {
                break;
            }
            
            count += 1;
            x += dx;
            y += dy;
        }
        
        count
    }
}
```

`check_win` 함수는 최근에 놓은 돌을 중심으로 8방향을 검사하여 5개 이상 연속된 돌이 있는지 확인한다. 이 알고리즘의 시간 복잡도는 O(1)이다 (최대 검사 거리가 제한되어 있으므로).

## 9.4 게임 상태 관리

게임의 전체 상태를 관리하는 구조체를 만든다.

```rust
// src/game.rs에 추가

use crate::player::PlayerId;

/// 게임 상태
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum GameState {
    /// 게임 진행 중
    Playing,
    /// 게임 종료 (승자)
    Finished { winner: Stone },
    /// 무승부
    Draw,
}

/// 오목 게임
pub struct OmokGame {
    board: Board,
    current_turn: Stone,
    black_player: PlayerId,
    white_player: PlayerId,
    state: GameState,
}

impl OmokGame {
    pub fn new(black_player: PlayerId, white_player: PlayerId) -> Self {
        OmokGame {
            board: Board::new(),
            current_turn: Stone::Black, // 흑돌이 먼저
            black_player,
            white_player,
            state: GameState::Playing,
        }
    }
    
    /// 현재 턴의 플레이어 ID
    pub fn current_player_id(&self) -> PlayerId {
        match self.current_turn {
            Stone::Black => self.black_player,
            Stone::White => self.white_player,
        }
    }
    
    /// 특정 플레이어의 돌 색상
    pub fn get_player_stone(&self, player_id: PlayerId) -> Option<Stone> {
        if player_id == self.black_player {
            Some(Stone::Black)
        } else if player_id == self.white_player {
            Some(Stone::White)
        } else {
            None
        }
    }
    
    /// 돌 놓기 시도
    pub fn place_stone(&mut self, player_id: PlayerId, pos: Position) -> Result<(), String> {
        // 게임이 이미 끝났는지 확인
        if self.state != GameState::Playing {
            return Err("게임이 이미 종료됨".to_string());
        }
        
        // 현재 턴의 플레이어인지 확인
        if player_id != self.current_player_id() {
            return Err("현재 턴이 아님".to_string());
        }
        
        // 보드에 돌 놓기
        self.board.place(pos, self.current_turn)?;
        
        // 승리 확인
        if self.board.check_win(pos) {
            self.state = GameState::Finished {
                winner: self.current_turn,
            };
        } else if self.board.is_full() {
            self.state = GameState::Draw;
        } else {
            // 턴 변경
            self.current_turn = match self.current_turn {
                Stone::Black => Stone::White,
                Stone::White => Stone::Black,
            };
        }
        
        Ok(())
    }
    
    /// 게임 상태
    pub fn state(&self) -> &GameState {
        &self.state
    }
    
    /// 현재 턴
    pub fn current_turn(&self) -> Stone {
        self.current_turn
    }
    
    /// 보드 참조
    pub fn board(&self) -> &Board {
        &self.board
    }
    
    /// 보드를 문자열로 출력
    pub fn display_board(&self) -> String {
        self.board.to_string()
    }
}
```

`OmokGame`은 게임의 전체 상태를 관리한다. 턴 관리, 승리 조건 확인, 돌 놓기 검증 등의 로직을 포함한다.

mod tests {

            let pos = Position::new(i, 4 - i).unwrap();
            board.place(pos, Stone::White).unwrap();

        let pos = Position::new(2, 2).unwrap();
        assert!(board.check_win(pos));
    }
    
    #[test]
    fn test_no_win_with_four() {
        let mut board = Board::new();
        
        // 가로로 4개만 놓기
        for x in 5..9 {
            let pos = Position::new(x, 7).unwrap();
            board.place(pos, Stone::Black).unwrap();

        let pos = Position::new(7, 7).unwrap();

        let pos1 = Position::new(7, 7).unwrap();

        assert_eq!(game.current_player_id(), 2);

        assert!(game.place_stone(2, pos).is_err());
        
        // 플레이어 1이 놓으면 성공
        assert!(game.place_stone(1, pos).is_ok());
    }
    
    #[test]
    fn test_game_win_scenario() {
        let mut game = OmokGame::new(1, 2);
        
        // 흑돌(플레이어 1)이 가로로 5개 놓기
        // 백돌(플레이어 2)은 방해하지 않는 위치에 놓기

            game.place_stone(1, black_pos).unwrap();

                game.place_stone(2, white_pos).unwrap();

    fn test_game_after_finish() {
        let mut game = OmokGame::new(1, 2);

        for i in 0..5 {
            let black_pos = Position::new(i, 7).unwrap();
            game.place_stone(1, black_pos).unwrap();
            
            if i < 4 {
                let white_pos = Position::new(i, 8).unwrap();
                game.place_stone(2, white_pos).unwrap();
            }
        }
        
        // 게임이 끝난 후 돌을 놓으려고 시도하면 실패
        let pos = Position::new(10, 10).unwrap();
        assert!(game.place_stone(2, pos).is_err());
    }
}

## 9.6 게임 이력 관리

게임 진행 상황을 추적하기 위해 착수 이력을 관리하는 기능을 추가한다.

```rust
// src/game.rs에 추가

/// 착수 정보
#[derive(Debug, Clone, Copy)]
pub struct Move {
    pub position: Position,
    pub stone: Stone,
    pub move_number: usize,
}

impl OmokGame {
    /// 착수 이력
    moves: Vec<Move>,
    
    // new() 함수 수정
    pub fn new(black_player: PlayerId, white_player: PlayerId) -> Self {
        OmokGame {
            board: Board::new(),
            current_turn: Stone::Black,
            black_player,
            white_player,
            state: GameState::Playing,
            moves: Vec::new(),  // 추가
        }
    }
    
    // place_stone() 함수에서 이력 저장 추가
    pub fn place_stone(&mut self, player_id: PlayerId, pos: Position) -> Result<(), String> {
        if self.state != GameState::Playing {
            return Err("게임이 이미 종료됨".to_string());
        }
        
        if player_id != self.current_player_id() {
            return Err("현재 턴이 아님".to_string());
        }
        
        let stone = self.current_turn;
        self.board.place(pos, stone)?;
        
        // 착수 이력 저장
        self.moves.push(Move {
            position: pos,
            stone,
            move_number: self.moves.len() + 1,
        });
        
        if self.board.check_win(pos) {
            self.state = GameState::Finished { winner: stone };
        } else if self.board.is_full() {
            self.state = GameState::Draw;
        } else {
            self.current_turn = match self.current_turn {
                Stone::Black => Stone::White,
                Stone::White => Stone::Black,
            };
        }
        
        Ok(())
    }
    
    /// 착수 이력 조회
    pub fn get_moves(&self) -> &[Move] {
        &self.moves
    }
    
    /// 마지막 착수
    pub fn last_move(&self) -> Option<&Move> {
        self.moves.last()
    }
}
```

## 9.7 게임 시뮬레이션

실제로 게임이 어떻게 진행되는지 시뮬레이션하는 예제를 작성한다.

```rust
// examples/game_simulation.rs
use omok_server::game::{OmokGame, Position};
use omok_server::protocol::Stone;

fn main() {
    println!("=== 오목 게임 시뮬레이션 ===\n");
    
    let mut game = OmokGame::new(1, 2);
    
    println!("게임 시작!");
    println!("플레이어 1 (흑돌) vs 플레이어 2 (백돌)\n");
    
    // 미리 정해진 수순
    let moves = vec![
        (1, 7, 7),   // 흑
        (2, 7, 8),   // 백
        (1, 8, 7),   // 흑
        (2, 8, 8),   // 백
        (1, 9, 7),   // 흑
        (2, 9, 8),   // 백
        (1, 10, 7),  // 흑
        (2, 10, 8),  // 백
        (1, 11, 7),  // 흑 - 5개 연속으로 승리
    ];
    
    for (player_id, x, y) in moves {
        let pos = Position::new(x, y).unwrap();
        let stone = if player_id == 1 { Stone::Black } else { Stone::White };
        
        println!("플레이어 {} ({:?})가 ({}, {})에 착수", 
            player_id, stone, x, y);
        
        match game.place_stone(player_id, pos) {
            Ok(_) => {
                println!("{}", game.display_board());
                
                // 게임 종료 확인
                match game.state() {
                    omok_server::game::GameState::Finished { winner } => {
                        println!("\n게임 종료! {:?} 승리!", winner);
                        break;
                    }
                    omok_server::game::GameState::Draw => {
                        println!("\n무승부!");
                        break;
                    }
                    _ => {}
                }
                
                println!();
            }
            Err(e) => {
                println!("에러: {}\n", e);
            }
        }
    }
    
    println!("\n착수 이력:");
    for mov in game.get_moves() {
        println!("{}수: {:?} - ({}, {})", 
            mov.move_number, mov.stone, mov.position.x, mov.position.y);
    }
}
```

## 9.8 방과 게임 통합

이제 8장에서 만든 `Room`과 게임 로직을 통합한다.

```rust
// src/room.rs 수정
use crate::game::{OmokGame, Position};

pub struct RoomData {
    pub id: RoomId,
    pub name: String,
    pub state: RoomState,
    pub players: Vec<Arc<PlayerSession>>,
    pub max_players: usize,
    pub game: Option<OmokGame>,  // 게임 인스턴스 추가
}

impl Room {
    pub async fn start_game(&self) -> Result<(), String> {
        let mut data = self.data.write().await;
        
        if data.players.len() != data.max_players {
            return Err("플레이어가 부족함".to_string());
        }
        
        if data.state != RoomState::Waiting {
            return Err("이미 게임이 시작됨".to_string());
        }
        
        data.state = RoomState::Playing;
        
        // 게임 인스턴스 생성
        let black_player = data.players[0].info.id;
        let white_player = data.players[1].info.id;
        data.game = Some(OmokGame::new(black_player, white_player));
        
        // 모든 플레이어에게 게임 시작 알림
        if data.players.len() >= 2 {
            let start_msg = ServerMessage::GameStart {
                black_player: data.players[0].info.name.clone(),
                white_player: data.players[1].info.name.clone(),
            };
            
            for player in &data.players {
                let _ = player.send(start_msg.clone());
            }
        }
        
        println!("[방 {}] 게임 시작", data.id);
        
        Ok(())
    }
    
    /// 돌 놓기 처리
    pub async fn handle_place_stone(
        &self, 
        player_id: PlayerId, 
        x: u8, 
        y: u8
    ) -> Result<(), String> {
        let mut data = self.data.write().await;
        
        let game = data.game.as_mut()
            .ok_or("게임이 시작되지 않음")?;
        
        let pos = Position::new(x, y)
            .ok_or("잘못된 위치")?;
        
        // 게임 로직에서 돌 놓기
        game.place_stone(player_id, pos)?;
        
        // 모든 플레이어에게 보드 업데이트 알림
        let stone = game.get_player_stone(player_id)
            .ok_or("플레이어를 찾을 수 없음")?;
        
        let update_msg = ServerMessage::BoardUpdate { x, y, stone };
        for player in &data.players {
            let _ = player.send(update_msg.clone());
        }
        
        // 게임 상태 확인
        match game.state() {
            crate::game::GameState::Finished { winner } => {
                let winner_name = if *winner == crate::protocol::Stone::Black {
                    data.players[0].info.name.clone()
                } else {
                    data.players[1].info.name.clone()
                };
                
                let game_over_msg = ServerMessage::GameOver {
                    winner: Some(winner_name),
                    reason: crate::protocol::GameOverReason::FiveInRow,
                };
                
                for player in &data.players {
                    let _ = player.send(game_over_msg.clone());
                }
                
                data.state = RoomState::Finished;
            }
            crate::game::GameState::Draw => {
                let game_over_msg = ServerMessage::GameOver {
                    winner: None,
                    reason: crate::protocol::GameOverReason::FiveInRow,
                };
                
                for player in &data.players {
                    let _ = player.send(game_over_msg.clone());
                }
                
                data.state = RoomState::Finished;
            }
            crate::game::GameState::Playing => {
                // 턴 변경 알림
                let current_player_name = if game.current_turn() == crate::protocol::Stone::Black {
                    data.players[0].info.name.clone()
                } else {
                    data.players[1].info.name.clone()
                };
                
                let turn_msg = ServerMessage::TurnChange {
                    current_player: current_player_name,
                };
                
                for player in &data.players {
                    let _ = player.send(turn_msg.clone());
                }
            }
        }
        
        Ok(())
    }
}
```

## 9.9 정리

이 장에서는 오목 게임의 핵심 로직을 구현했다. 주요 내용은 다음과 같다.
