# 6장. Tokio 고급 기능

## 6.1 tokio::spawn으로 태스크 생성

5장에서 `tokio::spawn`을 사용하여 각 클라이언트 연결을 독립적인 태스크로 처리했다. 이번 절에서는 태스크 생성과 관리에 대해 더 깊이 알아본다.

### 태스크란 무엇인가

태스크는 Tokio 런타임에서 실행되는 비동기 작업의 단위다. 스레드와 비슷하지만 훨씬 가볍다. 하나의 OS 스레드에서 수천 개의 태스크를 실행할 수 있다.

`tokio::spawn` 함수는 새로운 태스크를 생성하고 JoinHandle을 반환한다.

```rust
use tokio::time::{sleep, Duration};

#[tokio::main]
async fn main() {
    let handle = tokio::spawn(async {
        println!("태스크 시작");
        sleep(Duration::from_secs(1)).await;
        println!("태스크 완료");
        42
    });
    
    println!("메인 함수 계속 실행");
    
    // 태스크 완료 대기 및 결과 받기
    let result = handle.await.unwrap();
    println!("태스크 결과: {}", result);
}
```

### JoinHandle

`tokio::spawn`이 반환하는 `JoinHandle`은 태스크의 핸들이다. 이를 통해 태스크의 완료를 기다리거나 결과를 받을 수 있다.

```rust
use tokio::task::JoinHandle;

#[tokio::main]
async fn main() {
    let handle: JoinHandle<i32> = tokio::spawn(async {
        // 복잡한 계산
        let mut sum = 0;
        for i in 1..=100 {
            sum += i;
        }
        sum
    });
    
    // 다른 작업 수행
    println!("태스크가 백그라운드에서 실행 중");
    
    // 태스크 완료 대기
    match handle.await {
        Ok(result) => println!("계산 결과: {}", result),
        Err(e) => eprintln!("태스크 에러: {}", e),
    }
}
```

`await`의 결과는 `Result<T, JoinError>`다. 태스크가 성공하면 `Ok(T)`를, 패닉이 발생하면 `Err(JoinError)`를 반환한다.

### 여러 태스크 동시 실행

여러 태스크를 동시에 실행하고 모두 완료될 때까지 기다릴 수 있다.

```rust
use tokio::time::{sleep, Duration};

#[tokio::main]
async fn main() {
    let task1 = tokio::spawn(async {
        sleep(Duration::from_millis(100)).await;
        println!("태스크 1 완료");
        1
    });
    
    let task2 = tokio::spawn(async {
        sleep(Duration::from_millis(200)).await;
        println!("태스크 2 완료");
        2
    });
    
    let task3 = tokio::spawn(async {
        sleep(Duration::from_millis(150)).await;
        println!("태스크 3 완료");
        3
    });
    
    // 모든 태스크 완료 대기
    let result1 = task1.await.unwrap();
    let result2 = task2.await.unwrap();
    let result3 = task3.await.unwrap();
    
    println!("모든 결과: {}, {}, {}", result1, result2, result3);
}
```

벡터에 JoinHandle을 저장하여 동적으로 여러 태스크를 관리할 수도 있다.

```rust
#[tokio::main]
async fn main() {
    let mut handles = vec![];
    
    for i in 0..10 {
        let handle = tokio::spawn(async move {
            tokio::time::sleep(tokio::time::Duration::from_millis(100)).await;
            println!("태스크 {} 완료", i);
            i * 2
        });
        handles.push(handle);
    }
    
    // 모든 태스크 완료 대기
    for handle in handles {
        let result = handle.await.unwrap();
        println!("결과: {}", result);
    }
}
```

### 태스크 중단하기

JoinHandle의 `abort` 메서드를 사용하여 태스크를 중단할 수 있다.

```rust
use tokio::time::{sleep, Duration};

#[tokio::main]
async fn main() {
    let handle = tokio::spawn(async {
        loop {
            println!("작업 중...");
            sleep(Duration::from_millis(500)).await;
        }
    });
    
    // 2초 후 태스크 중단
    sleep(Duration::from_secs(2)).await;
    handle.abort();
    
    match handle.await {
        Ok(_) => println!("태스크 완료"),
        Err(e) if e.is_cancelled() => println!("태스크가 중단됨"),
        Err(e) => println!("에러: {}", e),
    }
}
```

### 태스크 간 데이터 공유

태스크는 독립적으로 실행되지만, 때로는 데이터를 공유해야 한다. `Arc`를 사용하여 여러 태스크 간에 데이터를 공유할 수 있다.

```rust
use std::sync::Arc;
use tokio::time::{sleep, Duration};

#[tokio::main]
async fn main() {
    let data = Arc::new(vec![1, 2, 3, 4, 5]);
    
    let mut handles = vec![];
    
    for i in 0..3 {
        let data = Arc::clone(&data);
        let handle = tokio::spawn(async move {
            sleep(Duration::from_millis(100 * i)).await;
            println!("태스크 {}: {:?}", i, data);
        });
        handles.push(handle);
    }
    
    for handle in handles {
        handle.await.unwrap();
    }
}
```

`Arc`는 원자적 참조 카운팅을 제공하여 스레드 안전하게 데이터를 공유할 수 있게 한다.

### spawn_blocking으로 CPU 집약적 작업 처리

비동기 런타임에서 CPU 집약적인 작업을 수행하면 다른 태스크의 실행을 방해할 수 있다. 이런 경우 `spawn_blocking`을 사용한다.

```rust
use tokio::task;

#[tokio::main]
async fn main() {
    println!("시작");
    
    let blocking_task = task::spawn_blocking(|| {
        // CPU 집약적인 작업
        let mut sum = 0u64;
        for i in 0..1_000_000_000 {
            sum += i;
        }
        sum
    });
    
    // 다른 비동기 작업
    tokio::time::sleep(tokio::time::Duration::from_millis(100)).await;
    println!("비동기 작업 완료");
    
    let result = blocking_task.await.unwrap();
    println!("계산 결과: {}", result);
}
```

`spawn_blocking`은 별도의 스레드 풀에서 작업을 실행하므로 비동기 런타임을 방해하지 않는다.

## 6.2 tokio::sync - 동기화 프리미티브

비동기 환경에서 여러 태스크가 데이터를 안전하게 공유하려면 동기화 메커니즘이 필요하다. Tokio는 비동기 환경에 최적화된 동기화 프리미티브를 제공한다.

### Mutex - 상호 배제

`tokio::sync::Mutex`는 한 번에 하나의 태스크만 데이터에 접근할 수 있도록 보장한다.

```rust
use tokio::sync::Mutex;
use std::sync::Arc;

#[tokio::main]
async fn main() {
    let counter = Arc::new(Mutex::new(0));
    let mut handles = vec![];
    
    for _ in 0..10 {
        let counter = Arc::clone(&counter);
        let handle = tokio::spawn(async move {
            let mut num = counter.lock().await;
            *num += 1;
            println!("카운터: {}", *num);
        });
        handles.push(handle);
    }
    
    for handle in handles {
        handle.await.unwrap();
    }
    
    println!("최종 값: {}", *counter.lock().await);
}
```

`lock()` 메서드는 비동기로 동작한다. 락을 획득할 때까지 기다리는 동안 다른 태스크가 실행될 수 있다.

표준 라이브러리의 `std::sync::Mutex`와 달리, `tokio::sync::Mutex`는 await 포인트를 제공한다. 비동기 환경에서는 반드시 Tokio의 Mutex를 사용해야 한다.

```rust
use tokio::sync::Mutex;
use std::sync::Arc;
use tokio::time::{sleep, Duration};

#[tokio::main]
async fn main() {
    let data = Arc::new(Mutex::new(String::from("초기값")));
    
    let data1 = Arc::clone(&data);
    let task1 = tokio::spawn(async move {
        let mut guard = data1.lock().await;
        println!("태스크 1: 락 획득");
        sleep(Duration::from_secs(2)).await;
        *guard = String::from("태스크 1이 수정");
        println!("태스크 1: 락 해제");
    });
    
    sleep(Duration::from_millis(100)).await;
    
    let data2 = Arc::clone(&data);
    let task2 = tokio::spawn(async move {
        println!("태스크 2: 락 대기 중...");
        let guard = data2.lock().await;
        println!("태스크 2: 락 획득, 값: {}", *guard);
    });
    
    task1.await.unwrap();
    task2.await.unwrap();
}
```

### RwLock - 읽기/쓰기 락

`tokio::sync::RwLock`는 읽기와 쓰기를 구분한다. 여러 태스크가 동시에 읽을 수 있지만, 쓰기는 독점적으로 수행된다.

```rust
use tokio::sync::RwLock;
use std::sync::Arc;

#[tokio::main]
async fn main() {
    let data = Arc::new(RwLock::new(vec![1, 2, 3]));
    
    let mut handles = vec![];
    
    // 여러 읽기 태스크
    for i in 0..5 {
        let data = Arc::clone(&data);
        let handle = tokio::spawn(async move {
            let read_guard = data.read().await;
            println!("읽기 {}: {:?}", i, *read_guard);
            tokio::time::sleep(tokio::time::Duration::from_millis(100)).await;
        });
        handles.push(handle);
    }
    
    // 쓰기 태스크
    let data_write = Arc::clone(&data);
    let write_handle = tokio::spawn(async move {
        tokio::time::sleep(tokio::time::Duration::from_millis(50)).await;
        let mut write_guard = data_write.write().await;
        println!("쓰기: 값 변경");
        write_guard.push(4);
    });
    handles.push(write_handle);
    
    for handle in handles {
        handle.await.unwrap();
    }
    
    println!("최종 값: {:?}", *data.read().await);
}
```

읽기가 많고 쓰기가 적은 경우 RwLock이 Mutex보다 성능이 좋다. 게임 서버에서 플레이어 정보를 조회하는 경우가 대표적인 예다.

### Semaphore - 세마포어

`tokio::sync::Semaphore`는 동시에 접근할 수 있는 태스크의 수를 제한한다.

```rust
use tokio::sync::Semaphore;
use std::sync::Arc;
use tokio::time::{sleep, Duration};

#[tokio::main]
async fn main() {
    // 최대 3개의 태스크만 동시 실행 허용
    let semaphore = Arc::new(Semaphore::new(3));
    let mut handles = vec![];
    
    for i in 0..10 {
        let permit = Arc::clone(&semaphore);
        let handle = tokio::spawn(async move {
            let _guard = permit.acquire().await.unwrap();
            println!("태스크 {} 시작", i);
            sleep(Duration::from_secs(1)).await;
            println!("태스크 {} 완료", i);
        });
        handles.push(handle);
    }
    
    for handle in handles {
        handle.await.unwrap();
    }
}
```

세마포어는 데이터베이스 연결 풀이나 API 요청 제한 등에 유용하다.

### mpsc 채널 - 메시지 전달

`tokio::sync::mpsc`는 Multiple Producer, Single Consumer 채널을 제공한다. 태스크 간 메시지를 전달하는 데 사용한다.

```rust
use tokio::sync::mpsc;

#[tokio::main]
async fn main() {
    let (tx, mut rx) = mpsc::channel(32);
    
    // 송신자 태스크들
    for i in 0..5 {
        let tx = tx.clone();
        tokio::spawn(async move {
            tx.send(format!("메시지 {}", i)).await.unwrap();
        });
    }
    
    // 원본 송신자도 닫기
    drop(tx);
    
    // 수신자 태스크
    while let Some(message) = rx.recv().await {
        println!("받음: {}", message);
    }
    
    println!("모든 메시지 수신 완료");
}
```

채널 생성 시 버퍼 크기를 지정한다. 버퍼가 가득 차면 `send`는 공간이 생길 때까지 대기한다.

unbounded 채널도 사용할 수 있다. 버퍼 제한이 없지만 메모리 관리에 주의해야 한다.

```rust
use tokio::sync::mpsc;

#[tokio::main]
async fn main() {
    let (tx, mut rx) = mpsc::unbounded_channel();
    
    tokio::spawn(async move {
        for i in 0..100 {
            tx.send(i).unwrap();
        }
    });
    
    while let Some(num) = rx.recv().await {
        println!("{}", num);
    }
}
```

### broadcast 채널 - 브로드캐스트

`tokio::sync::broadcast`는 하나의 송신자가 여러 수신자에게 메시지를 전송한다.

```rust
use tokio::sync::broadcast;

#[tokio::main]
async fn main() {
    let (tx, _rx) = broadcast::channel(16);
    
    // 여러 수신자 생성
    let mut rx1 = tx.subscribe();
    let mut rx2 = tx.subscribe();
    let mut rx3 = tx.subscribe();
    
    tokio::spawn(async move {
        loop {
            match rx1.recv().await {
                Ok(msg) => println!("수신자 1: {}", msg),
                Err(_) => break,
            }
        }
    });
    
    tokio::spawn(async move {
        loop {
            match rx2.recv().await {
                Ok(msg) => println!("수신자 2: {}", msg),
                Err(_) => break,
            }
        }
    });
    
    tokio::spawn(async move {
        loop {
            match rx3.recv().await {
                Ok(msg) => println!("수신자 3: {}", msg),
                Err(_) => break,
            }
        }
    });
    
    // 메시지 전송
    for i in 0..5 {
        tx.send(format!("메시지 {}", i)).unwrap();
        tokio::time::sleep(tokio::time::Duration::from_millis(100)).await;
    }
    
    tokio::time::sleep(tokio::time::Duration::from_secs(1)).await;
}
```

브로드캐스트 채널은 채팅 서버에서 모든 클라이언트에게 메시지를 전송할 때 유용하다.

### oneshot 채널 - 일회성 통신

`tokio::sync::oneshot`은 정확히 한 번만 값을 전송한다.

```rust
use tokio::sync::oneshot;
use tokio::time::{sleep, Duration};

#[tokio::main]
async fn main() {
    let (tx, rx) = oneshot::channel();
    
    tokio::spawn(async move {
        sleep(Duration::from_secs(1)).await;
        tx.send("계산 완료!").unwrap();
    });
    
    println!("결과 대기 중...");
    let result = rx.await.unwrap();
    println!("받은 결과: {}", result);
}
```

oneshot 채널은 태스크의 완료를 알리거나 초기화 결과를 전달할 때 사용한다.

## 6.3 tokio::select! 매크로

`select!` 매크로는 여러 비동기 작업 중 하나라도 완료되면 그것을 처리한다. 동시에 여러 이벤트를 기다릴 때 유용하다.

### 기본 사용법

```rust
use tokio::time::{sleep, Duration};

#[tokio::main]
async fn main() {
    let task1 = async {
        sleep(Duration::from_secs(1)).await;
        "태스크 1 완료"
    };
    
    let task2 = async {
        sleep(Duration::from_secs(2)).await;
        "태스크 2 완료"
    };
    
    tokio::select! {
        result = task1 => {
            println!("먼저 완료: {}", result);
        }
        result = task2 => {
            println!("먼저 완료: {}", result);
        }
    }
}
```

이 코드는 두 태스크 중 먼저 완료되는 것을 처리한다. 태스크 1이 1초 후에 완료되므로 그것이 선택된다.

### 여러 브랜치

`select!`는 여러 브랜치를 가질 수 있다.

```rust
use tokio::sync::mpsc;
use tokio::time::{sleep, Duration, interval};

#[tokio::main]
async fn main() {
    let (tx, mut rx) = mpsc::channel(10);
    let mut tick = interval(Duration::from_secs(1));
    
    tokio::spawn(async move {
        sleep(Duration::from_millis(500)).await;
        tx.send("메시지").await.unwrap();
    });
    
    loop {
        tokio::select! {
            Some(msg) = rx.recv() => {
                println!("채널에서 받음: {}", msg);
                break;
            }
            _ = tick.tick() => {
                println!("틱 발생");
            }
        }
    }
}
```

### 조건부 브랜치

`if` 조건을 사용하여 특정 브랜치를 활성화하거나 비활성화할 수 있다.

```rust
use tokio::sync::mpsc;

#[tokio::main]
async fn main() {
    let (tx1, mut rx1) = mpsc::channel(10);
    let (tx2, mut rx2) = mpsc::channel(10);
    
    let enable_rx2 = true;
    
    tokio::spawn(async move {
        tx1.send("채널 1").await.unwrap();
        tokio::time::sleep(tokio::time::Duration::from_millis(100)).await;
        tx2.send("채널 2").await.unwrap();
    });
    
    loop {
        tokio::select! {
            Some(msg) = rx1.recv() => {
                println!("RX1: {}", msg);
            }
            Some(msg) = rx2.recv(), if enable_rx2 => {
                println!("RX2: {}", msg);
            }
        }
        
        tokio::time::sleep(tokio::time::Duration::from_millis(200)).await;
        break;
    }
}
```

### else 브랜치

모든 브랜치가 준비되지 않았을 때 실행할 코드를 지정할 수 있다.

```rust
use tokio::sync::mpsc;

#[tokio::main]
async fn main() {
    let (_tx, mut rx) = mpsc::channel::<i32>(10);
    
    tokio::select! {
        Some(val) = rx.recv() => {
            println!("받음: {}", val);
        }
        else => {
            println!("채널이 비어있음");
        }
    }
}
```

### 타임아웃 구현

`select!`를 사용하여 타임아웃을 쉽게 구현할 수 있다.

```rust
use tokio::time::{sleep, Duration, timeout};

async fn long_operation() -> String {
    sleep(Duration::from_secs(5)).await;
    String::from("완료")
}

#[tokio::main]
async fn main() {
    tokio::select! {
        result = long_operation() => {
            println!("작업 완료: {}", result);
        }
        _ = sleep(Duration::from_secs(2)) => {
            println!("타임아웃!");
        }
    }
}
```

## 6.4 비동기 채팅 서버 구현

이제 배운 내용을 종합하여 실시간 채팅 서버를 만들어보자. 여러 클라이언트가 접속하여 메시지를 주고받을 수 있다.

### 서버 아키텍처 설계

채팅 서버는 다음과 같은 구조를 가진다.

1. 메인 서버: 클라이언트 연결을 수락한다.
2. 브로드캐스트 채널: 모든 클라이언트에게 메시지를 전달한다.
3. 클라이언트 핸들러: 각 클라이언트의 연결을 관리한다.

### 메시지 타입 정의

먼저 주고받을 메시지 타입을 정의한다.

```rust
use std::net::SocketAddr;

#[derive(Clone, Debug)]
enum Message {
    UserJoined(String),
    UserLeft(String),
    Chat { user: String, content: String },
}

impl Message {
    fn format(&self) -> String {
        match self {
            Message::UserJoined(user) => format!("[시스템] {}님이 입장했습니다.", user),
            Message::UserLeft(user) => format!("[시스템] {}님이 퇴장했습니다.", user),
            Message::Chat { user, content } => format!("[{}] {}", user, content),
        }
    }
}
```

### 채팅 서버 구현

```rust
use tokio::net::{TcpListener, TcpStream};
use tokio::sync::broadcast;
use tokio::io::{AsyncBufReadExt, AsyncWriteExt, BufReader};
use std::error::Error;

#[tokio::main]
async fn main() -> Result<(), Box<dyn Error>> {
    let listener = TcpListener::bind("127.0.0.1:8080").await?;
    println!("채팅 서버가 127.0.0.1:8080에서 대기 중");
    
    // 브로드캐스트 채널 생성
    let (tx, _rx) = broadcast::channel::<String>(100);
    
    let mut user_id = 0;
    
    loop {
        let (socket, addr) = listener.accept().await?;
        println!("새 연결: {}", addr);
        
        user_id += 1;
        let username = format!("User{}", user_id);
        
        let tx = tx.clone();
        let mut rx = tx.subscribe();
        
        tokio::spawn(async move {
            if let Err(e) = handle_client(socket, addr, username, tx, rx).await {
                eprintln!("클라이언트 에러: {}", e);
            }
        });
    }
}

async fn handle_client(
    socket: TcpStream,
    addr: std::net::SocketAddr,
    username: String,
    tx: broadcast::Sender<String>,
    mut rx: broadcast::Receiver<String>,
) -> Result<(), Box<dyn Error>> {
    let (reader, mut writer) = socket.into_split();
    let mut reader = BufReader::new(reader);
    let mut line = String::new();
    
    // 입장 메시지 전송
    let join_msg = format!("[시스템] {}님이 입장했습니다.", username);
    tx.send(join_msg)?;
    
    // 환영 메시지
    writer.write_all(b"채팅 서버에 오신 것을 환영합니다!\n").await?;
    writer.write_all(format!("당신의 이름: {}\n", username).as_bytes()).await?;
    
    loop {
        tokio::select! {
            // 클라이언트로부터 메시지 받기
            result = reader.read_line(&mut line) => {
                match result {
                    Ok(0) => {
                        // 연결 종료
                        println!("{} 연결 종료", username);
                        break;
                    }
                    Ok(_) => {
                        let msg = line.trim();
                        if !msg.is_empty() {
                            let chat_msg = format!("[{}] {}", username, msg);
                            tx.send(chat_msg)?;
                        }
                        line.clear();
                    }
                    Err(e) => {
                        eprintln!("읽기 에러: {}", e);
                        break;
                    }
                }
            }
            // 브로드캐스트 메시지 받기
            result = rx.recv() => {
                match result {
                    Ok(msg) => {
                        writer.write_all(msg.as_bytes()).await?;
                        writer.write_all(b"\n").await?;
                    }
                    Err(e) => {
                        eprintln!("브로드캐스트 수신 에러: {}", e);
                        break;
                    }
                }
            }
        }
    }
    
    // 퇴장 메시지
    let leave_msg = format!("[시스템] {}님이 퇴장했습니다.", username);
    let _ = tx.send(leave_msg);
    
    Ok(())
}
```

`select!` 매크로를 사용하여 클라이언트의 입력과 브로드캐스트 메시지를 동시에 처리한다.

### 채팅 클라이언트 구현

```rust
use tokio::net::TcpStream;
use tokio::io::{AsyncBufReadExt, AsyncWriteExt, BufReader};
use std::io::{self, Write};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let stream = TcpStream::connect("127.0.0.1:8080").await?;
    println!("서버에 연결됨");
    
    let (reader, mut writer) = stream.into_split();
    let mut reader = BufReader::new(reader);
    
    // 서버로부터 메시지를 읽는 태스크
    let read_task = tokio::spawn(async move {
        let mut line = String::new();
        loop {
            line.clear();
            match reader.read_line(&mut line).await {
                Ok(0) => {
                    println!("\n서버 연결이 종료되었습니다.");
                    break;
                }
                Ok(_) => {
                    print!("\r{}", line);
                    print!("> ");
                    io::stdout().flush().unwrap();
                }
                Err(e) => {
                    eprintln!("\n읽기 에러: {}", e);
                    break;
                }
            }
        }
    });
    
    // 사용자 입력을 서버로 보내는 태스크
    let write_task = tokio::task::spawn_blocking(move || {
        let stdin = io::stdin();
        let mut stdout = io::stdout();
        
        loop {
            print!("> ");
            stdout.flush().unwrap();
            
            let mut input = String::new();
            stdin.read_line(&mut input).unwrap();
            
            let input = input.trim();
            if input == "quit" {
                println!("종료합니다.");
                break;
            }
            
            if input.is_empty() {
                continue;
            }
            
            let rt = tokio::runtime::Handle::current();
            rt.block_on(async {
                let mut line = input.to_string();
                line.push('\n');
                if let Err(e) = writer.write_all(line.as_bytes()).await {
                    eprintln!("쓰기 에러: {}", e);
                }
            });
        }
    });
    
    tokio::select! {
        _ = read_task => {}
        _ = write_task => {}
    }
    
    Ok(())
}
```

### 개선된 버전 - 사용자 목록 관리

사용자 목록을 관리하는 더 발전된 버전을 만들어보자.

```rust
use tokio::net::{TcpListener, TcpStream};
use tokio::sync::{broadcast, RwLock};
use tokio::io::{AsyncBufReadExt, AsyncWriteExt, BufReader};
use std::collections::HashMap;
use std::sync::Arc;
use std::error::Error;

type UserList = Arc<RwLock<HashMap<usize, String>>>;

#[tokio::main]
async fn main() -> Result<(), Box<dyn Error>> {
    let listener = TcpListener::bind("127.0.0.1:8080").await?;
    println!("채팅 서버가 127.0.0.1:8080에서 대기 중");
    
    let (tx, _rx) = broadcast::channel::<String>(100);
    let users: UserList = Arc::new(RwLock::new(HashMap::new()));
    
    let mut user_id = 0;
    
    loop {
        let (socket, addr) = listener.accept().await?;
        println!("새 연결: {}", addr);
        
        user_id += 1;
        let username = format!("User{}", user_id);
        
        // 사용자 목록에 추가
        users.write().await.insert(user_id, username.clone());
        
        let tx = tx.clone();
        let rx = tx.subscribe();
        let users = Arc::clone(&users);
        
        tokio::spawn(async move {
            if let Err(e) = handle_client(
                socket, 
                addr, 
                user_id,
                username, 
                tx, 
                rx,
                users
            ).await {
                eprintln!("클라이언트 에러: {}", e);
            }
        });
    }
}

async fn handle_client(
    socket: TcpStream,
    _addr: std::net::SocketAddr,
    user_id: usize,
    username: String,
    tx: broadcast::Sender<String>,
    mut rx: broadcast::Receiver<String>,
    users: UserList,
) -> Result<(), Box<dyn Error>> {
    let (reader, mut writer) = socket.into_split();
    let mut reader = BufReader::new(reader);
    let mut line = String::new();
    
    // 입장 메시지
    let join_msg = format!("[시스템] {}님이 입장했습니다.", username);
    tx.send(join_msg)?;
    
    // 환영 메시지 및 명령어 안내
    writer.write_all(b"=== 채팅 서버에 오신 것을 환영합니다! ===\n").await?;
    writer.write_all(format!("당신의 이름: {}\n", username).as_bytes()).await?;
    writer.write_all(b"명령어:\n").await?;
    writer.write_all(b"  /users - 접속 중인 사용자 목록\n").await?;
    writer.write_all(b"  /quit - 종료\n").await?;
    writer.write_all(b"========================================\n").await?;
    
    loop {
        tokio::select! {
            result = reader.read_line(&mut line) => {
                match result {
                    Ok(0) => break,
                    Ok(_) => {
                        let msg = line.trim();
                        if msg.is_empty() {
                            line.clear();
                            continue;
                        }
                        
                        // 명령어 처리
                        if msg.starts_with('/') {
                            match msg {
                                "/users" => {
                                    let user_list = users.read().await;
                                    let list: Vec<String> = user_list
                                        .values()
                                        .cloned()
                                        .collect();
                                    let response = format!(
                                        "[시스템] 접속 중인 사용자 ({}명): {}\n",
                                        list.len(),
                                        list.join(", ")
                                    );
                                    writer.write_all(response.as_bytes()).await?;
                                }
                                "/quit" => {
                                    writer.write_all(b"안녕히 가세요!\n").await?;
                                    break;
                                }
                                _ => {
                                    writer.write_all(b"[시스템] 알 수 없는 명령어입니다.\n").await?;
                                }
                            }
                        } else {
                            let chat_msg = format!("[{}] {}", username, msg);
                            tx.send(chat_msg)?;
                        }
                        
                        line.clear();
                    }
                    Err(e) => {
                        eprintln!("읽기 에러: {}", e);
                        break;
                    }
                }
            }
            result = rx.recv() => {
                match result {
                    Ok(msg) => {
                        writer.write_all(msg.as_bytes()).await?;
                        writer.write_all(b"\n").await?;
                    }
                    Err(_) => break,
                }
            }
        }
    }
    
    // 사용자 목록에서 제거
    users.write().await.remove(&user_id);
    
    // 퇴장 메시지
    let leave_msg = format!("[시스템] {}님이 퇴장했습니다.", username);
    let _ = tx.send(leave_msg);
    
    Ok(())
}
```

이 버전은 `/users` 명령어로 접속 중인 사용자 목록을 볼 수 있다. `RwLock`을 사용하여 사용자 정보를 안전하게 관리한다.

## 6.5 정리

이 장에서는 Tokio의 고급 기능들을 배웠다.

`tokio::spawn`을 사용하여 비동기 태스크를 생성하고 관리하는 방법을 배웠다. JoinHandle을 통해 태스크의 완료를 기다리고 결과를 받을 수 있다. CPU 집약적인 작업은 `spawn_blocking`을 사용하여 별도로 처리한다.

`tokio::sync` 모듈은 비동기 환경에 최적화된 동기화 프리미티브를 제공한다. Mutex와 RwLock으로 공유 데이터를 안전하게 관리하고, mpsc 채널로 태스크 간 메시지를 전달하며, broadcast 채널로 여러 수신자에게 메시지를 브로드캐스트할 수 있다.

`select!` 매크로는 여러 비동기 작업을 동시에 기다리고 먼저 완료되는 것을 처리한다. 타임아웃 구현, 여러 채널 동시 처리 등에 유용하다.

이러한 기능들을 종합하여 실시간 채팅 서버를 구현했다. 브로드캐스트 채널과 `select!` 매크로를 활용하여 여러 클라이언트가 동시에 메시지를 주고받을 수 있는 시스템을 만들었다.

다음 장에서는 프로토콜 설계에 대해 배운다. 바이너리 포맷을 정의하고 serde를 사용하여 메시지를 직렬화/역직렬화하는 방법을 알아볼 것이다. 이는 게임 서버에서 클라이언트와 효율적으로 통신하는 데 필수적이다.
