# 1장. TCP 소켓 기초

## TcpListener와 TcpStream 개요
Rust 표준 라이브러리는 `std::net` 모듈을 통해 네트워크 프로그래밍을 위한 기본 API를 제공한다. TCP 통신을 위해서는 크게 두 가지 타입을 사용한다.

### TcpListener
`TcpListener`는 서버 측에서 클라이언트의 연결 요청을 수신(listen)하는 역할을 한다. 특정 IP 주소와 포트에 바인딩되어 클라이언트의 연결을 기다린다.

주요 메서드는 다음과 같다.  
- `TcpListener::bind(addr)`: 지정된 주소에 리스너를 바인딩한다.
- `listener.accept()`: 새로운 클라이언트 연결을 수락하고 `(TcpStream, SocketAddr)` 튜플을 반환한다.
- `listener.incoming()`: 연결 요청의 이터레이터를 반환한다.
  

### TcpStream
`TcpStream`은 클라이언트와 서버 간의 실제 데이터 통신을 담당하는 양방향 스트림이다. 서버 측에서는 `accept()`를 통해 얻고, 클라이언트 측에서는 `connect()`를 통해 생성한다.

주요 메서드는 다음과 같다.

- `TcpStream::connect(addr)`: 지정된 주소로 연결을 시도한다.
- `Read` trait 구현: 데이터를 읽을 수 있다.
- `Write` trait 구현: 데이터를 쓸 수 있다.
  
</br>  
  

## 간단한 Echo 서버 만들기
Echo 서버는 클라이언트로부터 받은 데이터를 그대로 다시 전송하는 가장 기본적인 서버다. 이를 통해 TCP 통신의 기본 흐름을 이해할 수 있다.

```rust
use std::net::{TcpListener, TcpStream};
use std::io::{Read, Write};

fn handle_client(mut stream: TcpStream) {
    let mut buffer = [0; 512];
    
    loop {
        // 클라이언트로부터 데이터 읽기
        match stream.read(&mut buffer) {
            Ok(0) => {
                // 연결 종료
                println!("클라이언트 연결 종료");
                break;
            }
            Ok(n) => {
                // 읽은 데이터를 그대로 다시 전송 (echo)
                if let Err(e) = stream.write_all(&buffer[..n]) {
                    eprintln!("쓰기 실패: {}", e);
                    break;
                }
                
                // 받은 메시지 출력
                let message = String::from_utf8_lossy(&buffer[..n]);
                println!("받은 메시지: {}", message);
            }
            Err(e) => {
                eprintln!("읽기 실패: {}", e);
                break;
            }
        }
    }
}

fn main() {
    // 127.0.0.1:8080 주소에 리스너 바인딩
    let listener = TcpListener::bind("127.0.0.1:8080")
        .expect("주소 바인딩 실패");
    
    println!("서버가 127.0.0.1:8080에서 실행 중...");
    
    // 클라이언트 연결 수락
    for stream in listener.incoming() {
        match stream {
            Ok(stream) => {
                println!("새로운 클라이언트 연결: {}", 
                    stream.peer_addr().unwrap());
                handle_client(stream);
            }
            Err(e) => {
                eprintln!("연결 실패: {}", e);
            }
        }
    }
}
```

이 서버는 다음과 같이 동작한다.  
  
1. `TcpListener::bind()`로 8080 포트에 바인딩한다.
2. `listener.incoming()`으로 연결 요청을 기다린다.
3. 클라이언트가 연결되면 `handle_client()` 함수에서 처리한다.
4. 512바이트 버퍼를 사용해 데이터를 읽는다.
5. 읽은 데이터를 그대로 클라이언트에게 다시 전송한다.

현재 이 서버는 한 번에 하나의 클라이언트만 처리할 수 있다. 동시에 여러 클라이언트를 처리하려면 스레드를 사용해야 하며, 이는 2장에서 다룬다.
  
</br>  
  

## 간단한 Echo 클라이언트 만들기
이제 위의 Echo 서버와 통신할 수 있는 클라이언트를 만들어본다.

```rust
use std::net::TcpStream;
use std::io::{self, Read, Write, BufRead};

fn main() {
    // 서버에 연결
    let mut stream = TcpStream::connect("127.0.0.1:8080")
        .expect("서버 연결 실패");
    
    println!("서버에 연결됨!");
    println!("메시지를 입력하세요 (종료하려면 'quit' 입력):");
    
    let stdin = io::stdin();
    let mut buffer = [0; 512];
    
    for line in stdin.lock().lines() {
        let line = line.expect("입력 읽기 실패");
        
        if line.trim() == "quit" {
            println!("연결 종료");
            break;
        }
        
        // 서버로 메시지 전송
        if let Err(e) = stream.write_all(line.as_bytes()) {
            eprintln!("전송 실패: {}", e);
            break;
        }
        
        // 서버로부터 응답 받기
        match stream.read(&mut buffer) {
            Ok(0) => {
                println!("서버 연결 종료");
                break;
            }
            Ok(n) => {
                let response = String::from_utf8_lossy(&buffer[..n]);
                println!("서버 응답: {}", response);
            }
            Err(e) => {
                eprintln!("읽기 실패: {}", e);
                break;
            }
        }
    }
}
```

클라이언트는 다음과 같이 동작한다.

1. `TcpStream::connect()`로 서버에 연결한다.
2. 사용자로부터 표준 입력을 받는다.
3. 입력된 텍스트를 서버로 전송한다.
4. 서버로부터 응답을 받아 화면에 출력한다.
5. "quit"을 입력하면 연결을 종료한다.
  
</br>  
  

## 바이트 스트림 읽기/쓰기
TCP는 바이트 스트림 기반 프로토콜이다. 즉, 데이터가 바이트의 연속된 흐름으로 전송된다. Rust에서는 `Read`와 `Write` trait을 통해 이를 다룬다.

### Read trait의 주요 메서드

```rust
use std::io::Read;

let mut stream = TcpStream::connect("127.0.0.1:8080").unwrap();
let mut buffer = [0; 1024];

// 1. read(): 최대 buffer 크기만큼 읽기
let bytes_read = stream.read(&mut buffer).unwrap();

// 2. read_exact(): 정확히 buffer 크기만큼 읽기 (블로킹)
stream.read_exact(&mut buffer).unwrap();

// 3. read_to_end(): EOF까지 모든 데이터 읽기
let mut all_data = Vec::new();
stream.read_to_end(&mut all_data).unwrap();

// 4. read_to_string(): UTF-8 문자열로 읽기
let mut text = String::new();
stream.read_to_string(&mut text).unwrap();
```

### Write trait의 주요 메서드

```rust
use std::io::Write;

let mut stream = TcpStream::connect("127.0.0.1:8080").unwrap();

// 1. write(): 일부 데이터를 쓰고 쓴 바이트 수 반환
let data = b"Hello, Server!";
let bytes_written = stream.write(data).unwrap();

// 2. write_all(): 모든 데이터를 쓸 때까지 반복
stream.write_all(b"Complete message").unwrap();

// 3. flush(): 버퍼에 있는 데이터를 즉시 전송
stream.flush().unwrap();
```

### 실용적인 예제: 길이 접두사 프로토콜
실제 애플리케이션에서는 메시지의 경계를 구분해야 한다. 가장 간단한 방법은 메시지 길이를 먼저 전송하는 것이다.

```rust
use std::io::{Read, Write};
use std::net::TcpStream;

// 메시지 전송: 길이(4바이트) + 데이터
fn send_message(stream: &mut TcpStream, message: &str) -> std::io::Result<()> {
    let bytes = message.as_bytes();
    let len = bytes.len() as u32;
    
    // 길이를 4바이트 빅엔디안으로 전송
    stream.write_all(&len.to_be_bytes())?;
    
    // 실제 데이터 전송
    stream.write_all(bytes)?;
    stream.flush()?;
    
    Ok(())
}

// 메시지 수신: 길이 읽기 -> 데이터 읽기
fn receive_message(stream: &mut TcpStream) -> std::io::Result<String> {
    let mut len_bytes = [0u8; 4];
    
    // 길이 읽기
    stream.read_exact(&mut len_bytes)?;
    let len = u32::from_be_bytes(len_bytes) as usize;
    
    // 데이터 읽기
    let mut buffer = vec![0u8; len];
    stream.read_exact(&mut buffer)?;
    
    Ok(String::from_utf8_lossy(&buffer).to_string())
}
```

### 에러 처리와 부분 읽기/쓰기
TCP 스트림은 `read()`나 `write()` 호출 시 요청한 전체 데이터를 처리하지 못할 수 있다. 이를 처리하는 방법을 살펴본다.

```rust
use std::io::{Read, Write};

// 안전한 전체 쓰기
fn write_all_manual(stream: &mut TcpStream, mut data: &[u8]) -> std::io::Result<()> {
    while !data.is_empty() {
        match stream.write(data) {
            Ok(0) => return Err(std::io::Error::new(
                std::io::ErrorKind::WriteZero,
                "쓰기 실패"
            )),
            Ok(n) => data = &data[n..],
            Err(ref e) if e.kind() == std::io::ErrorKind::Interrupted => continue,
            Err(e) => return Err(e),
        }
    }
    Ok(())
}

// 안전한 전체 읽기
fn read_exact_manual(stream: &mut TcpStream, mut buffer: &mut [u8]) -> std::io::Result<()> {
    while !buffer.is_empty() {
        match stream.read(buffer) {
            Ok(0) => return Err(std::io::Error::new(
                std::io::ErrorKind::UnexpectedEof,
                "연결 종료"
            )),
            Ok(n) => buffer = &mut buffer[n..],
            Err(ref e) if e.kind() == std::io::ErrorKind::Interrupted => continue,
            Err(e) => return Err(e),
        }
    }
    Ok(())
}
```

실무에서는 보통 `write_all()`과 `read_exact()`를 사용하면 되지만, 내부 동작을 이해하는 것이 중요하다.
  

### 타임아웃 설정
네트워크 프로그래밍에서 무한 대기를 방지하기 위해 타임아웃을 설정할 수 있다.

```rust
use std::net::TcpStream;
use std::time::Duration;

let mut stream = TcpStream::connect("127.0.0.1:8080").unwrap();

// 읽기 타임아웃 설정 (5초)
stream.set_read_timeout(Some(Duration::from_secs(5))).unwrap();

// 쓰기 타임아웃 설정 (5초)
stream.set_write_timeout(Some(Duration::from_secs(5))).unwrap();

// 타임아웃 비활성화
stream.set_read_timeout(None).unwrap();
```

이제 TCP 소켓의 기본 개념과 Echo 서버/클라이언트 구현 방법을 이해했다. 다음 장에서는 여러 클라이언트를 동시에 처리하는 방법을 배운다.

## `std::net::TcpStream`의 자주 쓰이는 주요 API


### 1. 연결 만들기

#### `TcpStream::connect`
TCP 서버에 블로킹 방식으로 연결을 맺는 함수다.

```rust
let stream = TcpStream::connect("example.com:80")?;
```

#### `TcpStream::connect_timeout`
지정한 타임아웃 안에만 연결을 시도한다.

```rust
let stream = TcpStream::connect_timeout(&addr, Duration::from_secs(3))?;
```


### 2. 읽기 / 쓰기(I/O)
`TcpStream`은 `std::io::Read`, `std::io::Write` 트레이트를 구현하므로 일반적인 읽기/쓰기 함수들을 그대로 쓸 수 있다.

#### `read`, `read_exact`
수신 데이터를 읽는다.

```rust
stream.read(&mut buf)?;
stream.read_exact(&mut buf)?;
```

#
데이터를 전송한다.

```rust
stream.write_all(b"hello\n")?;
stream.write(b"partial data")?;
```

#### `peek`
스트림에서 데이터를 “엿보기”만 하고 소비하지 않는다.

```rust
let n = stream.peek(&mut buf)?;
```


### 3. 주소 관련

#### `peer_addr`
반대편(원격) 소켓 주소를 얻는다.

```rust
let peer = stream.peer_addr()?;
```

#### `local_addr`
내(로컬) 쪽 소켓 주소를 얻는다.

```rust
let local = stream.local_addr()?;
```
  

### 4. 블로킹 / 논블로킹 설정

#### `set_nonblocking`
스트림을 논블로킹 모드로 전환하거나 해제한다.

```rust
stream.set_nonblocking(true)?;
```

논블로킹 모드에서는 읽기/쓰기 시 `WouldBlock` 에러를 받을 수 있다.

  
### 5. 타임아웃 설정

#### `set_read_timeout`, `set_write_timeout`
읽기/쓰기 시도에 타임아웃을 건다.

```rust
stream.set_read_timeout(Some(Duration::from_secs(5)))?;
stream.set_write_timeout(Some(Duration::from_secs(5)))?;
```

#
현재 설정된 타임아웃을 확인한다.

```rust
let r_to = stream.read_timeout()?;
let w_to = stream.write_timeout()?;
```

  
### 6. Nagle 알고리즘 등 옵션

#### `set_nodelay`, `nodelay`
Nagle 알고리즘 활성/비활성 설정 및 조회다. (작은 패킷 지연 없이 바로 보내고 싶을 때 `true`로 설정한다.)

```rust
stream.set_nodelay(true)?;
let on = stream.nodelay()?;
```

#### `set_ttl`, `ttl`
패킷의 TTL(Time To Live)을 설정/조회한다.

```rust
stream.set_ttl(64)?;
let ttl = stream.ttl()?;
```

#### `set_linger`, `linger`
연결 종료 시 커널이 보내지 못한 데이터를 얼마나 더 보내볼지 설정한다.

```rust
stream.set_linger(Some(Duration::from_secs(1)))?;
let linger = stream.linger()?;
```

#
IPv6 전용 소켓으로 사용할지 설정/조회한다.

```rust
stream.set_only_v6(true)?;
let only_v6 = stream.only_v6()?;
```

  
### 7. 복제 / 분리 / 종료

#### `try_clone`
같은 연결을 공유하는 새로운 `TcpStream` 핸들을 만든다. (스레드에 나눠줄 때 자주 쓰인다.)

```rust
let stream2 = stream.try_clone()?;
```

#### `into_split`
소유권을 읽기/쓰기 절반으로 분리해서 각각 독립적으로 소유하게 한다.

```rust
let (mut r, mut w) = stream.into_split();
```

#### `shutdown`
읽기/쓰기 방향을 부분적으로 또는 완전히 닫는다.

```rust
stream.shutdown(std::net::Shutdown::Both)?;
```

  
### 8. 에러 조회

#### `take_error`
소켓에 축적되어 있던 에러를 한 번 꺼내온다.

```rust
if let Some(err) = stream.take_error()? { println!("{err}"); }
```
